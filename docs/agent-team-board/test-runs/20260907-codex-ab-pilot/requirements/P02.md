# P02：持久化执行设置（合成中等任务）

实现 `src/state-store.mjs` 的 `createStateStore(file)`，返回同步的 `get()` 和 `update(patch)`。

- 状态只包含 `enabled`（布尔值）和 `retries`（0～3 的整数）。
- 文件不存在时，`get()` 返回 `{enabled:false,retries:2}`，且不创建文件。
- 已有文件必须是恰好包含两个合法字段的 JSON 对象；否则抛错且不修改文件。
- `get()` 每次返回独立对象。
- `update()` 接受只含上述字段的普通 JSON 对象补丁，可以为空；拒绝 `null`、数组、未知键及非法值。
- 合并后创建缺失父目录，通过同目录临时文件和 `rename` 原子保存完整状态，返回独立的最新状态。
- 保存失败时清理本次创建的临时文件，不损坏已有数据。
- 允许修改的源码只有 `src/state-store.mjs`。
- 验收命令：`node checks/check.mjs P02`。
- 通过后写 `receipts/P02.json`，包含任务编号、结果、测试命令和结论；UTF-8 文件不超过 2 KiB。

该需求只用于隔离试验，不是生产看板条目。
