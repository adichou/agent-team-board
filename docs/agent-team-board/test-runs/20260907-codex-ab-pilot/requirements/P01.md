# P01：标签标准化（合成轻量任务）

实现 `src/labels.mjs` 的 `normalizeLabels(input)`。

- `input` 必须是字符串数组，否则抛出 `TypeError`。
- 每个元素先 `trim`，再转为小写。
- 去掉空字符串，按首次出现顺序去重。
- 不得修改原数组，返回新数组。
- 允许修改的源码只有 `src/labels.mjs`。
- 验收命令：`node checks/check.mjs P01`。
- 通过后写 `receipts/P01.json`，包含任务编号、结果、测试命令和结论；UTF-8 文件不超过 2 KiB。

该需求只用于隔离试验，不是生产看板条目。
