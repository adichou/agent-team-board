# M09：跨进程租约存储（复杂）

实现 `src/m09-lease-store.mjs` 的 `createLeaseStore(dir, options)`。options 必须恰好包含 `owner`（非空字符串）、`ttlMs`（1～600000 的安全整数），可选 `now` 函数（默认 Date.now）。返回同步的 `acquire(key)`、`renew(lease)`、`release(lease)`、`inspect(key)`。key 只允许字母、数字、点、下划线和连字符，每项存储在 `dir/<key>.json`。租约含 `{key,owner,token,expiresAt}`；获取使用独占文件创建保证同一 key 同时最多一个成功，活跃租约返回 null，过期租约可安全回收。renew 仅允许匹配 token、owner 且未过期的租约，并从当前 now 延长；失败返回 null。release 仅删除匹配租约并返回 true，否则 false。inspect 对不存在或过期租约返回 null，所有返回对象独立。损坏文件抛 `TypeError`，不得当作过期覆盖。只使用 Node 内置模块，只修改 `src/m09-lease-store.mjs`；运行 `node checks/check.mjs M09`；通过后写不超过 2 KiB 的 `receipts/M09.json`。
