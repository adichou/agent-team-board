# M04：汇总任务状态（轻量）

实现 `src/m04-status-summary.mjs` 的 `summarizeItems(items)`。输入必须是数组，每项必须恰好包含非空字符串 `id` 和状态 `submitted`、`accepted`、`in-progress`、`done` 之一，不允许重复 `id`。返回 `{ total, counts, pendingIds }`；`counts` 固定包含上述四个键，`pendingIds` 按输入顺序列出所有非 `done` 项。返回新对象，不修改输入；非法输入抛 `TypeError`。只修改 `src/m04-status-summary.mjs`；运行 `node checks/check.mjs M04`；通过后写不超过 2 KiB 的 `receipts/M04.json`。
