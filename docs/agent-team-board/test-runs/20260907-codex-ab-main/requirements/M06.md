# M06：读取 NDJSON 事件（中等）

实现 `src/m06-ndjson-events.mjs` 的同步函数 `readEvents(file, options = {})`。忽略空行；每个非空行必须是恰好含 `sequence`、`type`、`payload` 的 JSON 普通对象，sequence 从 1 开始严格连续，type 为非空字符串。先校验完整文件，再按 `options.fromSequence`（默认 1）和可选的唯一非空字符串数组 `options.types` 过滤。options 只允许这两个键。JSON 或结构错误抛 `TypeError`，消息包含物理行号；文件系统错误原样抛出。只修改 `src/m06-ndjson-events.mjs`；运行 `node checks/check.mjs M06`；通过后写不超过 2 KiB 的 `receipts/M06.json`。
