# M08：带校验的原子快照（中等）

实现 `src/m08-snapshot.mjs` 的同步函数 `writeSnapshot(file, state)` 与 `readSnapshot(file)`。state 必须是 JSON 可序列化的普通对象，递归拒绝非有限数字、undefined、函数、symbol、BigInt、访问器、稀疏数组、循环引用和非普通对象。对对象键递归排序后生成规范 JSON；文件信封恰好为 `{version:1,checksum,state}`，checksum 是规范 state JSON 的 SHA-256 小写十六进制。写入须创建父目录，用同目录独占临时文件加 rename 原子替换，失败时清理自己的临时文件且不损坏旧文件；成功后返回与已写状态相等的独立对象。文件不存在时读取返回 null；信封、校验或状态非法时抛 `TypeError`。所有返回值不得共享可变引用。只修改 `src/m08-snapshot.mjs`；运行 `node checks/check.mjs M08`；通过后写不超过 2 KiB 的 `receipts/M08.json`。
