# M07：重试决策器（中等）

实现 `src/m07-retry-policy.mjs` 的 `decideRetry(failure, policy)`。failure 必须恰好包含 `attempt`（从 1 开始的安全整数）、`errorCode`（非空字符串）、`idempotent`（布尔）；policy 必须恰好包含 `maxAttempts`（1～20）、`baseDelayMs`、`maxDelayMs`（非负安全整数且 max 不小于 base）和唯一非空字符串数组 `retryableCodes`。非幂等、不可重试错误或次数耗尽时分别返回 `{action:'stop',reason:'non-idempotent'|'non-retryable'|'attempts-exhausted'}`；否则返回 `{action:'retry',delayMs}`，延迟为 `min(maxDelayMs, baseDelayMs * 2 ** (attempt - 1))`，不得溢出安全整数。非法输入抛 `TypeError`。只修改 `src/m07-retry-policy.mjs`；运行 `node checks/check.mjs M07`；通过后写不超过 2 KiB 的 `receipts/M07.json`。
