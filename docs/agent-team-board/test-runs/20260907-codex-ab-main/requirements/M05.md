# M05：签名分页游标（中等）

实现 `src/m05-cursor-codec.mjs` 的 `createCursorCodec(secret)`，返回 `encode(value)` 与 `decode(token)`。`secret` 必须是非空字符串。游标值必须恰好包含 `offset`（非负安全整数）、`query`（最长 100 个 Unicode 字符的字符串）和 `sort`（`asc` 或 `desc`）。编码格式为 `base64url(UTF-8 JSON).base64url(HMAC-SHA256)`；JSON 键顺序固定为 offset、query、sort。解码须验证格式、签名和载荷，不泄露 secret，失败统一抛 `TypeError`，返回独立新对象。只使用 Node 内置模块，只修改 `src/m05-cursor-codec.mjs`；运行 `node checks/check.mjs M05`；通过后写不超过 2 KiB 的 `receipts/M05.json`。
