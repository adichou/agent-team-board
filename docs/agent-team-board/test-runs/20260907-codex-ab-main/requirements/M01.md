# M01：规范化需求编号（轻量）

实现 `src/m01-item-id.mjs` 的 `canonicalizeItemId(input)`。输入必须是字符串；允许编号前后空白，主体格式为大小写不敏感的 `REQ-YYYYMMDD-NNN` 或 `BUG-YYYYMMDD-NNN`。日期必须是实际存在的公历日期，序号范围为 001～999。返回 `{ id, type, date, sequence }`：`id` 为大写规范编号，`type` 为 `requirement` 或 `bug`，`date` 为 `YYYY-MM-DD`，`sequence` 为数字。非法输入抛 `TypeError`。只修改 `src/m01-item-id.mjs`；运行 `node checks/check.mjs M01`；通过后写不超过 2 KiB 的 `receipts/M01.json`。
