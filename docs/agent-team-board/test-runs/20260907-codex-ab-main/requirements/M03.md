# M03：日志字段脱敏（轻量）

实现 `src/m03-redact.mjs` 的 `redactFields(record, blockedKeys)`。`record` 必须是仅含可枚举字符串数据属性的普通对象；`blockedKeys` 省略时为 `authorization`、`cookie`、`token`，传入时必须是非空字符串数组。按 ASCII 大小写不敏感匹配键名，将命中值替换为 `[REDACTED]`。保持原有键顺序和未命中值，返回新对象，不修改输入；非法输入抛 `TypeError`。只修改 `src/m03-redact.mjs`；运行 `node checks/check.mjs M03`；通过后写不超过 2 KiB 的 `receipts/M03.json`。
