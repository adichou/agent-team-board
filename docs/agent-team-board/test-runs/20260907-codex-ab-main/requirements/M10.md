# M10：运行事件恢复（复杂）

实现 `src/m10-run-recovery.mjs` 的 `rebuildRuns(events)`。事件必须恰好含 `sequence`（从 1 开始的安全整数）、`runId`（非空字符串）、`type`、`at`（有效 ISO 时间字符串）和 `data` 普通对象；全局 sequence 必须连续。允许相同 sequence 的完全相同相邻重放并忽略，冲突重复或缺号抛 `TypeError`。状态机为：不存在→reserved；reserved→claimed/released；claimed→reported/blocked/failed。reserved 的 data 恰含 taskId，claimed 恰含 owner，reported 恰含 result，其他三类 data 必须为空对象。相同 runId 在同一状态收到 type 和 data 完全相同的新事件视为幂等，不考虑 sequence 和 at，且不更新 `updatedAt`；否则非法。返回 `{runs,actionable}`：runs 按首次出现顺序，项目为 `{runId,taskId,status,owner,result,updatedAt}`，缺失的 owner/result 省略；actionable 按相同顺序列出状态为 reserved 或 claimed 的 runId。不得修改输入或共享可变引用。只修改 `src/m10-run-recovery.mjs`；运行 `node checks/check.mjs M10`；通过后写不超过 2 KiB 的 `receipts/M10.json`。
