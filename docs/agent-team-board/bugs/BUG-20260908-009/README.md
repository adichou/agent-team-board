# BUG-20260908-009 任务界面去掉任务这个标题

- 状态：submitted（待人工接受）
- 归属：独立 Bug（引入来源见 design.md）
- 创建：2026-09-08T11:45:51.470Z

## 现象

Web 看板的「任务」模块里，模块名「任务」被重复展示：

- 第二行模块导航（`scripts/web/index.html` 中 `data-view="runs"` 的 view-tab）已用高亮 Tab 标识当前处于任务模块；第三行按 REQ-20260907-004「第三行不显示模块大标题，仅展示一句副标题」的约定显示副标题「进度、队列与结果集中在这里」（`scripts/web/app.js` 的 `MODULE_SUB.runs`）。
- 但任务面板头部（`scripts/web/app.js` 的 `renderBatchDrawer()`，模板内 `batch-title` 区块）仍渲染了一个 `<h2>任务</h2>` 大标题，样式来自 `scripts/web/style.css` 的 `.drawer-head h2`。
- 结果是同一屏内「任务」两个字出现两次（导航 Tab 一次、面板头部大标题一次），模块名重复，与 REQ-20260907-004 的整体布局去重方向不一致。

该 `<h2>任务</h2>` 是任务模块页面化（原批量抽屉头部）沿留下来的模块名大标题，除重复标识模块外无信息增量。

## 复现步骤

1. 启动看板服务：`node scripts/server.mjs`（默认 `http://127.0.0.1:8888`，端口可用 `ATB_PORT` 覆盖）；或 `npm run app` 经 Electron 壳打开同一界面。
2. 在项目切换下拉中选择任一已初始化看板的项目。
3. 点击第二行模块导航的「任务」Tab，进入任务模块。
4. 观察任务面板头部：在「批量完善 / 批量开发」两个子面板 Tab 的上方、「✕」关闭按钮左侧，出现大标题「任务」，与顶部导航 Tab 文案重复。

## 期望行为

- 去掉任务面板头部的 `<h2>任务</h2>` 大标题（`scripts/web/app.js` `renderBatchDrawer()` 中 `batch-title` 内的 h2）。
- 头部其余元素全部保持现状：
  - 当前项目标识 span（`state.project`，`title` 提示完整内容）继续在头部显示；
  - 「✕」关闭按钮（`#batchClose`）保留，点击仍返回需求模块（现有绑定 `setView('status')`）；
  - 「批量完善 / 批量开发」子面板 Tab 保持在头部下方原位，切换行为不变。
- 模块归属标识由第二行导航高亮 Tab「任务」与第三行副标题承担即可，任务模块内不再出现重复的模块名大标题。
- 无障碍标签不动：`#runsView` 的 `aria-label="任务"`、`#batchDrawer` 的 `aria-label="任务面板"` 属非可见辅助信息，保留原样。
- 范围边界：本单仅去掉任务模块的「任务」大标题；设置模块头部另有 `<h2>项目设置</h2>`（`renderSettingsView()`），文案与导航 Tab（设置）不同，不在本单处理范围。

## 验收说明

- 进入任务模块，分别切到「批量完善」与「批量开发」子面板：面板头部均不再显示「任务」大标题。
- 头部的项目标识与「✕」关闭按钮仍显示；点「✕」返回需求模块，行为与修复前一致。
- 「批量完善 / 批量开发」Tab 切换、面板内容渲染、任务搜索与进入模块时的刷新轮询均不受影响。
- 宽屏与窄屏（含 ≤720px 时 `.batch-drawer` 无边框布局）下头部不塌陷、项目标识与「✕」不重叠；深浅色主题下无残留样式。
- 其余模块（讨论 / 需求 / 文件 / 设置）头部展示不受影响。
- 回归方式：人工按上文复现步骤在浏览器或 Electron 壳内逐项检查（本单为纯展示调整，无数据与状态流转变更）。
