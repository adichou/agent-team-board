# BUG-20260908-008 设置界面去掉项目设置这个标题

- 状态：submitted（待人工接受）
- 归属：独立 Bug（引入来源见 design.md）
- 创建：2026-09-08T11:36:57.259Z

## 现象

设置模块页面顶部重复出现「项目设置」大标题，与全局布局口径不一致。

- 看板整体布局（REQ-20260907-004）已明确「第三行移除页面标题，仅保留模块副标题」：当前模块由第二行模块导航页签（讨论 / 需求 / 任务 / 文件 / 设置，`scripts/web/index.html` 中 `data-view="settings"` 的「设置」页签）+ 第三行模块副标题标识；设置模块的副标题为「当前项目的派发默认值」（`scripts/web/app.js` 的 `MODULE_SUB.settings`）。
- 但设置视图内部又渲染了一个视图级大标题：`scripts/web/app.js` 的 `renderSettingsView()` 输出 `header.batch-head > .batch-title`，其中含 `<h2>项目设置</h2>`（约 4023 行）与并排的项目路径 `span.path`。同一屏内「设置」页签、「当前项目的派发默认值」副标题、「项目设置」大标题形成三重模块标识，标题冗余。
- 对比：任务模块抽屉（`renderBatchDrawer()`）的 `<h2>任务</h2>` 属抽屉头部结构，不在本 Bug 范围；本 Bug 仅针对设置视图内的「项目设置」标题。

## 复现步骤

1. 在项目目录启动看板服务：`node scripts/atb.mjs serve --open`（默认端口 8888，可用 `--port N` 覆盖）。
2. 浏览器打开看板地址（默认 http://localhost:8888）。
3. 点击第二行模块导航行末的「设置」页签，进入设置模块。
4. 观察设置视图内容区顶部：第三行副标题「当前项目的派发默认值」下方，第一块内容是 `header.batch-head`，其中左侧显示「项目设置」大标题及其右侧的项目路径文本 —— 即本 Bug 所述冗余标题。

## 期望行为

1. 设置视图内不再渲染 `<h2>项目设置</h2>` 标题；模块归属由第二行「设置」页签与第三行副标题「当前项目的派发默认值」承担，与 REQ-20260907-004「第三行不显示模块大标题」口径一致。
2. 标题旁的项目路径文本（`span.path`，悬停提示为完整项目路径）是否随标题一并移除：待确认（默认建议随标题一并移除整个标题头，路径信息仍可从顶栏项目选择器悬停提示获得；若保留则位置与样式不变）。
3. 设置视图其余内容与功能不受影响：说明文案、「批量任务」分区（REQ-20260908-020）、「模型与推理强度」、CLI 路径 / 单项时限 / 网络重试次数 / 重启后自动继续 / 允许非 Git 项目执行等字段、「保存设置」「保存批量任务设置」按钮、运行环境静态检查均原样可用。
4. 其他模块的视图内标题（如任务模块的「任务」）不在本 Bug 范围，保持现状。

## 验收说明

- `renderSettingsView()` 生成的设置视图 HTML 中不再出现文本为「项目设置」的标题元素；按复现步骤进入设置模块，视图内容自说明文案 /「批量任务」分区开始，无重复大标题。
- 第二行「设置」页签高亮、第三行副标题「当前项目的派发默认值」正常显示；深浅主题与 1024 / 736 / 360px 宽度下设置视图顶部布局无空洞、无错位。
- 回归：设置加载失败时的「重试」入口、「保存设置」（成功仍提示「✓ 已保存项目设置（用于后续新执行）」，该 toast 属操作反馈文案，不在本 Bug 去除范围）、「保存批量任务设置」、运行环境静态检查均工作正常。
- 其他模块（讨论 / 需求 / 任务 / 文件）的标题与布局不受本次改动影响。
