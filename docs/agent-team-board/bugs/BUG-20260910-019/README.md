# BUG-20260910-019 全选和全不选的图标要使用更标准的图标

- 状态：以 status.json 与看板实时状态为准（本文仅完善说明）
- 归属：独立 Bug（引入来源见文末「关联」）
- 创建：2026-09-10T15:16:41.107Z

## 现象

需求列表头单行工具栏（`#reqCaption`）左起前两个图标按钮——「全选」（`#selectOperable`，字形 `☑` U+2611 BALLOT BOX WITH CHECK）与「全不选」（`#selectNone`，字形 `☐` U+2610 BALLOT BOX）——使用 Unicode「投票框」字符充当图标，不是业界通用的标准「全选 / 全不选」图标形态：

- **形态不稳定**：`☑` / `☐` 属文字字形而非图标资产，实际渲染取决于操作系统 / 浏览器 / 主题的系统字体回退链，不同环境下线宽、方框圆角、勾形粗细各不相同（部分环境渲染出衬线或近 emoji 风格），同一产品在不同机器上观感不一致。该字形「近满 em 见方、渲染不可控」的特性已被 BUG-20260910-017 证实——当时为对齐视觉尺寸，被迫对两字形单独降字号至 11px（`scripts/web/style.css` 第 388 行 `.req-caption .btn.icon-act.icon-check { font-size: 11px; }`），是治标修补。
- **非标准语汇**：常见 UI 图标体系（如通用 check-square / square 复选框图标、各主流图标库的 select-all 入口）对「全选 / 全不选」均有约定俗成的标准形态（带勾方框 / 空方框，等线宽描边）；现状投票框字形与这些标准形态不对应，用户需要靠 `title` 悬浮提示才能确认含义。

代码核对（现状依据）：

- `scripts/web/index.html` 第 124-125 行：两按钮内容为 `☑` / `☐` 字形，class 均为 `btn small quiet icon-act icon-check`（REQ-20260910-026 图标化产物 + BUG-20260910-017 修饰类）。
- `scripts/web/style.css` 第 381-388 行：`.req-caption .btn.icon-act` 盒规格（26×24 定宽等高、13px 字号）与第 482 行卡片操作图标口径 `.req-row .row-acts .btn.icon-act` 一致，但两投票框字形另以 `icon-check` 降为 11px——尺寸问题已修、字形本身仍非标准图标。
- 项目 Web UI 目前**没有任何图标资产体系**（无图标字体、无内联 SVG 图标库），全部图标均为 Unicode 字形（✓ / ✎ / ⧉ / 🗑 / ▶ 等，见 `scripts/web/app.js` 列表渲染与 `index.html`）。

本单登记时无截图；具体在何种环境看到何种「不标准」的呈现（登记人所见）待确认，但不影响「字形渲染依赖字体回退、非受控图标」的判定。

## 复现步骤

1. 启动 Status Board 服务（`scripts/server.mjs`，默认端口 8888）并在浏览器打开看板；深浅色主题均可复现。
2. 切换到任一可选择档：待接受 / 已接受 / 已计划（非选择档不显示选择控件，BUG-20260909-008）。
3. 观察列表头工具栏左起两个图标按钮：`☑`（全选）、`☐`（全不选）——两枚均为投票框文字字形。
4. 换一台不同操作系统 / 浏览器的机器（或调整系统字体）重复第 3 步：`☑` / `☐` 的线宽、方框样式、勾形随字体回退链变化，呈现形态不受产品控制；与常见标准 UI 的「带勾方框 / 空方框」等线宽复选框图标对比，形态、粗细、观感均不一致。
5. （对照）观察同屏的卡片操作图标（`⧉` 复制，各状态均有；待接受另有 `✓` / `✎` / `🗑`）：全选 / 全不选两枚投票框字形在整套界面中是唯一以「投票框」语汇呈现的图标，无标准图标体系归属。

## 期望行为

- **换用更标准的图标呈现「全选 / 全不选」语义**：采用业界通用复选框图标语汇——「带勾的方框」表示全选、「空方框」表示全不选，等线宽描边、跨平台渲染一致。倾向自绘内联 SVG（两枚图标即够、无外网依赖、彻底摆脱字体回退），最终形态与实现手段（内联 SVG 或其他标准图标方案）无视觉稿，待确认；若评估引入开源图标库，按 REQ-20260909-015 的选型与 License 白名单规则在开发阶段 design.md 论证，本文只约束结果、不预设唯一方案。
- **既有契约零回退**：
  - 语义契约（REQ-20260910-026）：`type=button`、`aria-label="全选" / "全不选"`、`title` 悬浮提示口径不变，键盘可 Tab 到达、焦点轮廓可见。
  - 视觉契约（BUG-20260910-017）：两图标与卡片操作图标（⧉ / ✓ / ✎ / 🗑）视觉重量、尺寸统一；若换 SVG 后不再需要 `icon-check` 降字号修补规则，允许移除（属开发阶段同步事项）。
  - 盒规格：沿用 `.btn.icon-act` 26×24 小方格口径与工具栏单行布局（REQ-20260910-008 / 026 不回退）。
- **功能行为零变化**：全选仅勾选当前筛选档内可见的可操作条目（叠搜索范围，REQ-20260908-027）；全不选仅取消当前档勾选、其他档保留（BUG-20260907-016 契约）；零勾选禁用全不选、无可操作条目禁用全选；任一批量操作进行中两者与复选框防误触禁用；非选择档（开发中 / 待测试 / 已完成）两按钮整体隐藏（BUG-20260909-008）。
- **测试同步**：以下测试中「按钮内容恰为 `☑` / `☐` 字形」的静态断言需随图标方案同步修正，属开发阶段事项——`scripts/tests/caption-toolbar-icons-20260910-026.test.mjs`（T1 / T5）、`scripts/tests/bug-caption-select-icon-size-20260910-017.test.mjs`（T2）、`scripts/tests/selection-lane-scope.test.mjs`（第 86-87 行 `>☑` 正则）；`scripts/web/app.js` 第 2961-2962 行注释中的「☐」表述一并核对。

## 界面展示

- 布局：列表头工具栏左起为全选、全不选两个等宽图标按钮，其后为「已选 N 项」计数与当前档批量动作、快捷入口靠右；列表卡片首行右侧为 ⧉ / ✓ / ✎ / 🗑 操作图标，供视觉重量对照。缺陷形态两按钮为 ☑ / ☐ 投票框字形；修复后形态为标准复选框语汇图标（带勾方框 / 空方框，演示以自绘内联 SVG 作示意，最终方案待开发确认）。
- 交互：可切换「缺陷现象 / 修复后（示意）」对照两种图标形态，两形态共享同一交互逻辑；可实际点击勾选、全选（仅当前档可见可操作项）、全不选（仅清当前档，其他档保留）；批量按钮按档显隐，进行中变「接受中… / 移出中…」并禁用全选 / 全不选 / 复选框；可切换待接受 / 已接受 / 已计划 / 开发中档位（非选择档无选择控件）。
- 状态反馈：正常——计数即时更新、零选择时批量动作组隐藏；空——列表空态说明、全选禁用；加载——列表加载中、选择控件禁用；失败——结果区显示逐条失败清单（`编号：错误信息`）且部分成功口径保留；另含深 / 浅色主题切换。另设「字形渲染不稳定」对照区：同一 ☑ / ☐ 字形在不同字体栈下呈现差异，而 SVG 图标在各字体栈下恒定一致，直观说明缺陷根因与修复价值。

[打开可交互演示](./ui-demo.html)。单文件离线演示，对照呈现缺陷现象（☑ / ☐ 投票框字形、渲染随字体回退漂移）与期望修复后状态（标准复选框图标、跨字体恒定；图标为示意，最终形态待确认）；演示数据与加载 / 失败反馈均为模拟，不写入看板。

## 验收说明

- [ ] 全选 / 全不选按钮不再使用 `☑` / `☐` 投票框文字字形，改用标准复选框语汇的图标（带勾方框 / 空方框），跨操作系统 / 浏览器 / 深浅色主题渲染形态一致、不随系统字体回退漂移；记录验证环境（操作系统 / 浏览器 / 主题）。
- [ ] 图标语义契约保持：`aria-label="全选" / "全不选"`、`title` 悬浮提示、`type=button` 不变，键盘可 Tab 到达、焦点轮廓可见，屏幕阅读器仍念出「全选 / 全不选」。
- [ ] 视觉契约保持：两图标与卡片操作图标（⧉ / ✓ / ✎ / 🗑）视觉尺寸、重量统一（BUG-20260910-017 成果不回退）；`icon-check` 降字号修补规则若随方案移除，须确认视觉不回退。
- [ ] 功能零回归：全选仅勾当前档可见可操作项（叠搜索范围）、全不选仅清当前档且其他档保留、零勾选禁用全不选 / 无可操作项禁用全选、批量进行中防误触、非选择档两按钮整体隐藏。
- [ ] 工具栏布局不回退：常规宽度单行结构、批量动作组与「▶ 开始完善 / 开始开发」恒定同行、窄宽度无横向滚动与裁切（REQ-20260910-008 / 026 口径）。
- [ ] 既有回归测试语义通过：涉及 ☑ / ☐ 字形静态断言的 `caption-toolbar-icons-20260910-026` / `bug-caption-select-icon-size-20260910-017` / `selection-lane-scope` 等按新图标方案同步修正后通过。
- [ ] ui-demo.html 可离线直接打开：无外网依赖、无构建步骤，可操作缺陷 / 修复对照、档位与状态切换、全选 / 全不选及批量动作。
