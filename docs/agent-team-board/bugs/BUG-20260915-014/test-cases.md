# 测试用例 — BUG-20260915-014 点击发布按钮后提示发布模块已被隐藏，需修复

自动化：`node scripts/tests/bug-release-tab-inplace-20260915-014.test.mjs`（vm 假 DOM 口径同
`build-ui.test.mjs` / `build-release-card-items-search-20260915-003.test.mjs`）。
既有回归：`node scripts/tests/build-release-card-items-search-20260915-003.test.mjs`（R2 按新口径更新）、
`node scripts/tests/i18n-coverage.test.mjs`、`node scripts/tests/i18n-dict.test.mjs`。

## R1 右侧详情「概况 / 发布」页签

- R1a 详情标题下出现两页签（概况、发布），默认概况：原有描述 / 关联条目与 commit /
  合并反馈 / 管理记录块均在概况内；发布页签内容不出现在概况。
- R1b 点「发布」页签切到发布视图，点「概况」切回；左侧版本列表与模块页签不受影响。

## R2 「查看发布记录」就地切换（不再跳隐藏模块）

- R2a 卡片「查看发布记录」：选中该卡片版本并激活其详情发布页签；不再派发
  `atb:goto-view`（旧跳转即缺陷根因）。
- R2b 未选中卡片的「查看发布记录」以所在卡片版本为准，不受右侧原选中态影响；
  概况原有选中态与内容不丢失（切回概况可见）。

## R3 创建发布落点与失败路径

- R3a 创建成功（201 + run.id）：留在构建模块，当前版本详情自动切到发布页签并选中新草稿。
- R3b 创建失败（4xx + error）：弹层保留、输入与错误可见、不切页签；创建中确认键禁用
  （不发第二次请求）。

## R4 发布记录按项目与版本隔离

- R4a 列表只含 `bldId === 选中版本` 的运行；接口返回其他版本运行不混入。
- R4b 切换版本清空旧记录、选中与错误（旧版本运行 ID 不再出现）；切回需重新加载。
- R4c 切换项目重置页签与发布数据；旧项目慢返回响应不覆盖新项目/新版本内容
  （身份 + seq 双重防串）。
- R4d 旧版本详情请求慢返回不覆盖新选择的运行详情。

## R5 状态反馈

- R5a 加载：右侧发布区显示加载提示；页签与版本选择仍可点。
- R5b 读取失败：显示「发布记录读取失败：<原因>」+ 只读重试按钮；重试只发 GET
  state；概况页签仍可访问。
- R5c 空态：无运行显示「当前版本暂无发布记录」；未合并版本创建入口禁用并提示
  「请先完成合并入 main」，已合并可用（打开既有创建弹层）。
- R5d 详情展示运行 ID、发行版本号、状态、阶段、Web App / 官网目标结果与错误信息；
  字段缺失显示「未提供」；草稿状态标签不显示为已发布。

## R6 动作入口沿用现有发布流程

- R6a draft：预检 / 重新冻结 / 预览发布计划（未预检禁用）；failed：重试失败阶段 /
  重新冻结；prechecking|running：取消后续阶段；任意状态：刷新状态。
- R6b 预览计划走 GET plan 并弹确认窗；「确认启动发布」才 POST start，取消不发。
- R6c 动作执行中动作区禁用防重复；完成仅刷新（GET state + GET run）。
