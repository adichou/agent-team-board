## 复现步骤

前置：启动本项目 Status Board（`node scripts/server.mjs`），选择任意项目；无需已保存设置、无需运行中任务。

1. 点击主导航「设置」进入设置页。
2. 待加载完成（状态行显示「已加载设置」），查看「批量任务」分区标题下方的通用说明——一段约 119 字、含两个长句与括号补语的文字。
3. 查看「完善完成后自动转入计划」复选框下方的说明——又一段约 93 字的长句。
4. 鼠标悬停开关文字：浏览器浮层显示约 73 字的 `title` 提示，内容与第 3 步可见说明开头几乎逐字重复。
5. 刷新页面、在设置与其他模块间切换再返回，重复观察：文案稳定显示，与任务是否运行无关；窄窗口下长段说明折行更多，复杂观感更明显。复现只需观察文案，不必修改任何值或点击保存。

## 期望行为

1. **精简文案、语义不丢**：「批量任务」分区的每处说明压缩为一句短句，`title` 悬停提示与可见说明不再两处重复长文；精简后仍可读出四个语义要点——（a）两类批量任务均为子代理模式；（b）子代理模型跟随主调度会话；（c）开关默认关闭 = 人工移入计划，开启 = 完善完成后自动移入计划；（d）保存/开关仅对后续新任务（后续完善回执）生效、不追溯。建议形态（演示与验收示意，最终文案待开发阶段确认）：
   - 分区说明（119 字 → 约 39 字）：如「两类批量任务均为子代理模式，子代理模型跟随主调度会话；保存仅对后续新任务生效。」
   - 开关说明（93 字 → 约 27 字）：如「开启后完善完成即自动移入计划；默认关闭＝人工移入计划。」（`title` 提示与可见说明统一为该短句或仅保留其一）
2. **仅改文案、不改行为**：开关默认关闭与已开启回显、切换草稿提示「有未保存的更改」、保存仅提交 `refine.autoPlanAfterDone`、保存中按钮禁用防重复、成功/失败 toast、加载中骨架「正在加载任务设置」、加载失败 + 重试、`aria-label`「完善完成后自动转入计划」全部保持现状。
3. **术语口径不回退**：不重新引入已删除的按 Agent 配置说明（REQ-20260909-011）；不回归旧「智能档建议」类文案。
4. **测试同步**：精简后若契约测试锁定的关键词（「子代理模式」「跟随主调度会话」「可在任意一种 Agent 会话粘贴执行」「默认关闭 = 人工移入计划」）被压缩，需同步更新断言；不得为通过测试而保留冗余长句。

### 范围与待确认

- 最终文案措辞与是否设字数硬上限（如分区说明 ≤ 40 字、开关说明 ≤ 30 字）待开发阶段确认。
- 「可在任意一种 Agent 会话粘贴执行」口径压缩后是否仍需保留在某处（或彻底删除）待确认。
- 保存成功 toast「已保存批量任务设置（流转开关仅对后续完善回执生效）」与 CLI 提示（`atb.mjs` 的「未开启自动转入计划：需人工移入计划…」）是否一并精简待确认——本单标题为设置界面描述，默认不含 CLI 与 toast。

## 界面展示

界面布局与状态反馈的文字说明（对照缺陷现状与精简后形态）：

- 界面布局：设置页仅「批量任务」一个分区 = 标题 + 一句精简说明 +「完善完成后自动转入计划」开关 + 一句短说明 +「保存批量任务设置」按钮与就近状态行；无重复长段、无悬停与可见两处长文。
- 正常：开关回显已保存值（默认关闭）；状态行初始「已加载设置」，切换开关即提示「有未保存的更改」。
- 空 / 初始：项目从未保存过设置时开关默认不勾选，说明文案同样为精简版；存量已保存设置加载后正常回显。
- 加载中：沿用「正在加载任务设置」骨架，不渲染编辑与保存控件。
- 失败：任务设置加载失败显示分区级错误 + 重试；保存失败就近提示、草稿保留可重试，不误报成功。
- 可交互演示：[./ui-demo.html](./ui-demo.html)——单文件无外网依赖、浏览器直接打开，并排对照缺陷现状（三段冗长文案，119 / 73 / 93 字）与精简建议形态（39 / 27 字），可切换开关、点击保存（成功 / 失败 / 防重复提交）、切换 加载中 / 加载失败 / 正常 状态，深浅色随系统并可手动切换。本演示为验收口径示意，非已实现效果。
