# 验收场景

1. 正常开发：测试通过后 report、提交本单源码/测试/文档/状态、核验本轮待测试与 hash。
2. 混合工作区：别的任务修改与暂存内容不混入；本单未跟踪文件不能遗漏。
3. 例外授权：仅当前条目可通过工具状态收尾，其他条目挂起不解除；执行端拒绝则报告阻塞。
4. report 成功但提交失败：说明待测试但交付未完整，不宣称完成、不擅改状态。
5. loop：每项完成核验再取下一项；提交/上报失败停止扩大现场。
6. 没有覆盖率或非 Git 项目：不伪造数字/hash，不自行初始化仓库。
