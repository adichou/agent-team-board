## 分析与结论

1. 数据有效性：采集覆盖、父子汇总去重、失败用量、模型和基线是否可比。
2. 质量：两组完成范围、成功率、新增回归，以及未执行条目的原因。
3. Token：每轮增幅、合并总量比值、主调度占比、轻/中/复杂任务差异；缓存和费用单列。
4. 上下文：主会话随任务位置曲线、两组 worker 起始上下文、压缩和人工重开；估算必须标明。
5. 稳定性：两轮是否同方向；样本不足、模型服务波动及组间配置差异。
6. 决策：有限批次是否适合 A、持续派发是否保留 B、是否需要扩展实验；建议仅限实测范围。
