# REQ-20260910-005 支持项目管理

- 状态：accepted（已接受；以 status.json 为准）
- 创建：2026-09-10T00:40:03.167Z

## 描述

在看板右上角项目切换区域提供项目管理入口，支持初始化项目、导入已有项目及移出项目。移出仅让项目不再出现在项目切换列表，必须保留项目目录及其中需求、Bug 等文档；之后可重新导入。

### 已核实的现状与范围

- `scripts/server.mjs` 已有项目注册表、`POST /api/register` 和 `POST /api/init`。注册会校验绝对目录路径存在，按真实路径去重；当前注册并不要求目录已初始化。
- `scripts/lib/core.mjs` 的 `initData` 创建看板数据目录及初始配置，遇已有数据会拒绝重复初始化；可能采用 Git 根目录或向上找到已有数据目录。
- `scripts/web/app.js` 的项目选择器显示项目短名称，项目切换会更新 URL、记忆当前项目并清理旧项目视图。当前列表渲染还会补入当前项目，服务端请求解析也可能注册项目；开发时须避免这些流程使已移出的项目自动重现。
- 本需求是在这些能力上完善用户入口及移出语义；以下交互是目标行为，不代表当前已经实现。不包含删除磁盘项目、删除条目、修改条目状态或终止运行任务。

### 界面布局

右上角保留项目切换器，旁边增加「管理项目」。打开管理面板后，顶部显示标题和关闭按钮；操作区提供「初始化项目」「导入项目」切换、项目根目录绝对路径输入和提交按钮；下方列出项目名称、完整路径、当前项目标记及「切换」「移出」。同名目录通过完整路径区分。窄屏按行堆叠，路径可换行，操作不得被截断。

### 交互行为

1. 初始化：输入已存在的项目目录，展示实际将写入的目标位置，确认后创建看板数据并加入列表、切换至该项目。已有数据不覆盖，提示改用导入；目录不存在、权限不足等情况不显示成功。不得因 Git 根目录或向上查找而静默写入用户未确认的位置。
2. 导入：输入已有看板数据的项目根目录，验证后加入并切换，保留全部原始条目及状态。重复导入同一真实路径不新增重复项，可切换到已有项；未初始化目录提示使用初始化。子目录、符号链接须明确显示解析后的目标。
3. 移出：弹出确认区展示项目名称和完整路径，并说明「仅从列表移出，目录及需求、Bug 文档保留」。取消不改变列表；确认成功后移除该项。移出非当前项目不切换当前上下文；移出当前项目后切换至列表首个剩余项目，最后一个移出后显示无项目引导，并清理当前项目选择与旧条目画面。
4. 成功的列表变更刷新后仍有效；普通轮询不得重新注册被移出的当前项目。重新导入后原文档和条目状态不变。过期深链访问已移出项目的具体提示方式待确认，但不得无提示恢复注册。
5. 涉及活动批次、子代理或其他会话正在使用项目时的阻止/提示策略待确认；移出操作本身不得终止任务或修改其账本。

### 状态反馈

- 正常：项目列表、当前标记与切换器一致，成功操作给出具体项目反馈。
- 空：提示「暂无项目」，提供初始化和导入入口，不展示上个项目的条目。
- 加载/提交：显示操作进度文字，禁用重复提交及冲突操作，完成后恢复。
- 失败：显示可读原因与重试入口；输入保留，不能误报成功或丢失既有项目列表。若初始化已完成但加入列表失败，应说明已完成的步骤并允许导入恢复，禁止重复覆盖数据。
- 路径为空、非绝对路径在提交前提示；目录存在性、数据合法性与权限由实际校验结果反馈，不编造成功结果。

## 验收标准

- [ ] 右上角可打开项目管理；列表显示完整路径和当前标记，同名项目能区分，窄屏可操作。
- [ ] 对存在且未初始化的目录，用户确认实际目标后初始化成功，生成看板数据、加入切换列表并切换；重复初始化不覆盖已有数据。
- [ ] 导入已有项目后其需求、Bug、配置及条目状态保持原样；同一真实路径重复导入只保留一项；未初始化目录提示初始化。
- [ ] 空路径、相对路径、目录不存在、不可读或不可写等失败均说明原因；保留输入和原列表，允许纠正后重试。
- [ ] 移出前明确显示目标路径和保留文档说明；取消无变化，确认后仅移出注册展示，不删除或修改项目目录、文档及条目状态。
- [ ] 移出非当前项目不切换；移出当前项目自动选剩余首项；移出最后一项进入空态，URL/记忆选择不再指向旧项目，旧项目条目不残留。
- [ ] 移出后刷新或轮询不会自行重新出现；重新导入可以恢复展示且保留原文档。过期链接不得静默重新注册。
- [ ] 加载时禁用重复及冲突操作，成功/失败反馈清楚；部分完成场景明确说明，重试不覆盖数据。
- [ ] 管理操作不终止活动任务；开发前确认活动任务与多会话策略、深链提示以及目录解析确认方式。
- [ ] `ui-demo.html` 单文件、无外网依赖、直接打开可操作，包含正常/空/加载/失败切换及主要管理流程。
