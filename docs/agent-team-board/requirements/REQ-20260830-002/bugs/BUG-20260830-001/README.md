# BUG-20260830-001 顶栏「看板/文件」按钮在窄窗口遮挡路径文字

- 状态：submitted（待人工接受）
- 归属需求：REQ-20260830-002
- 创建：2026-08-29T17:20:08.078Z

## 现象

窗口较窄时，顶栏（`.topbar`）中间的「看板」「文件」视图切换按钮（`.view-tabs`）遮挡左侧品牌区底部的项目路径文字（`#dataDir`），更窄时按钮组自身溢出顶栏、互相错位。已截图复现：

- **760px（状态视图）**：「看板」按钮左缘压住路径 `/Users/.../agent-team-board/...` 尾部，路径被硬切断（看不到省略号），路径完整内容无法读取。
- **760px（文件视图）**：按钮组与路径区域几乎无间距，且按钮组垂直溢出顶栏背景条。
- **640px（文件视图）**：两个按钮互相堆叠错位（「文件」叠在「看板」上），路径文字被覆盖。

1280px 宽度下正常，问题只在窗口收窄后出现——内置浏览器面板等窄场景必现。

## 复现步骤

1. 打开 Status Board（http://127.0.0.1:7736）；
2. 把窗口/面板宽度拖窄到约 760px（或更窄，如 640px）；
3. 观察顶栏：路径文字被「看板/文件」按钮遮挡、截断；640px 下按钮组溢出错位。

## 根因分析（初步）

`scripts/web/style.css`：

1. `.path` 的 `max-width: 46vw`（style.css:92）在窄窗口下仍占 ~350px+，留给中间按钮组的空间不足；
2. `.brand-text` 是 `.brand`（flex 容器）的子项，未设 `min-width: 0`（min-width 默认 auto，不可收缩），路径省略号来不及生效，内容从 `.brand` 溢出到右侧，被不透明的 `.view-tabs` 背景盖住——flex 布局本身不重叠，但溢出的文字钻到了按钮下面；
3. `.view-tabs` / `.top-actions` 未设 `flex: none`，极窄宽度下自身被压缩，按钮溢出容器导致 640px 下的堆叠错位；
4. `.topbar` 为 `flex-wrap: nowrap`（style.css:66），无窄窗口降级策略。

## 期望行为（验收标准）

- [ ] 任意窗口宽度下，路径文字要么完整可读、要么以省略号（…）截断，绝不被按钮遮挡
- [ ] 「看板/文件」按钮组与左右区域保持安全间距（建议 ≥12px），按钮自身不变形、不堆叠、不溢出顶栏背景
- [ ] 极窄宽度（≤640px）下顶栏有降级策略（允许换行、隐藏路径或收纳进菜单），无元素互相遮挡
- [ ] 状态视图与文件视图两种状态下均满足上述表现
- [ ] 深色 / 浅色模式下均正常
