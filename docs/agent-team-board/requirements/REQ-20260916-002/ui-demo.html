产品介绍What is it

ZCode 插件：需求 / Bug 的文件化管理 + Agent TDD 开发流程 + 本地网页状态板。

Project Board文件为事实源，随项目进 git，不依赖特定会话
Discussion Board/req /bug /dev /board 四命令 + skill 行为规范
Status Board本地网页状态板（127.0.0.1:8888），人机操作入口

核心能力Capabilities

文件化事实源

docs/agent-team-board 随 git 版本化：人读 markdown，机器读写 status.json，任何会话可随时接续。

状态机人机分工

单向流转，接受 / 确认完成仅限人工，PreToolUse 钩子确定性拦截 Agent 越权。

submitted → accepted → in-progress → done

TDD 两阶段流程

认领即实施：先写测试跑红，再实现跑绿，atb report 上报测试报告待人工确认。

批量开发 / 批量完善

队列化批量推进多个需求 / Bug 的开发与文档完善，无需逐条值守。

构建 · 版本 · 发布

dev / main 分支协作，版本计划合并后一键预检、构建、回验、发布。

待人工决策（hold）闭环

开发中遇到需要人工拍板的问题即挂起并列出选项，决策后继续，不静默猜测。

English Summary

What. Agent Team Board is a ZCode plugin that brings file-based requirement / bug management, an agent-driven TDD workflow, and a local web status board (Project Board / Discussion Board / Status Board).

Capabilities. Files as the single source of truth (docs/agent-team-board, versioned with git); a one-way state machine where accept / done are human-only actions enforced by PreToolUse hooks; claim-and-implement two-phase TDD (tests red → code green → report); batch develop and batch refine; build → version plan → publish pipeline; a hold loop that pauses for human decisions instead of guessing.

Run. Status Board: node <plugin>/scripts/atb.mjs init, then node <plugin>/scripts/server.mjs and open http://127.0.0.1:8888 (optionally atb cli install). Desktop app: npm install then npm run app; package with npm run dist (macOS dmg / Windows nsis). Current release: 1.0.0.
