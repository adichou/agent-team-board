## 描述

- 列标题下放置「全选」复选框、已选数量和「接受所选」按钮；范围为当前项目待接受列内的条目，现有看板没有类型筛选器。

- 轮询保留有效选择并移除已变更状态或消失的条目；新到条目不自动勾选。切换项目清空选择和结果，已发出的请求绑定原项目，尚未发送的操作停止。
