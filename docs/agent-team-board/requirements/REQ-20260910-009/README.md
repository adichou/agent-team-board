# REQ-20260910-009 搜索模块优化

- 创建：2026-09-10T00:52:10.195Z
- 状态以 status.json 为准，由看板 CLI 维护。

## 描述

原始诉求：当前搜索模块布局需重新优化，先分析当前存在的问题。本需求优化当前模块搜索的布局、范围辨识和反馈，使用户能明确“在哪里搜、搜到了什么、接下来怎么做”。

### 当前实现与问题分析

依据 `scripts/web/index.html` 的 pageHead/docHits、`scripts/web/style.css` 的 module-search/hits-strip，以及 `scripts/web/app.js` 的 SEARCH_PLACEHOLDER、runSearch、renderDocHits、renderFileHits：

- 搜索框位于模块副标题右侧，宽度按 320px 收缩，最小 140px；对象主要由占位符说明，输入后占位符消失，搜索范围不够显性。这里是代码布局分析，真实用户使用频次和典型窗口尺寸待确认。
- 需求搜索把条目过滤在列表里、文档放在独立结果条带，文件命中只提示去文件视图查看。入口与结果分散，容易混淆总命中与当前状态筛选后的可见条目。
- 加载提示主要是图标后省略号，失败使用 toast，缺少结果区域内持久的失败说明和重试入口。结果条带在无响应时显示“搜索中”，需要明确区分加载与失败。
- 讨论、任务、全局采用前端过滤；需求和文件使用 /api/search。布局优化应保留这些搜索范围和数据来源，不能把当前模块搜索误称为全站搜索。

### 界面布局

保留现有模块导航顺序和搜索所在的模块标题区域。宽屏标题在左、搜索在右；搜索框旁始终展示当前模块范围标签，输入框、清除按钮组成一组。窄屏标题与搜索分行，输入组占满可用宽度，按钮与状态文字可换行，无页面横向溢出。

搜索区域下方紧邻显示关键词、当前范围与结果反馈，随后才是当前模块内容。需求结果分为“条目”和“文档”两组，分别标明数量；当前状态筛选后可见数量与搜索条目总命中数分开说明。文件命中显示数量和“在文件查看”入口；文件模块展示路径列表及返回需求查看相关命中的入口。长标题、路径省略展示并可获取完整文本；结果过多在区域内滚动，保留服务端截断提示，不把前 50 条称为全部结果。

### 交互行为

输入沿用现有防抖搜索；Enter 立即执行当前关键词，Esc 或清除按钮清空并恢复当前模块原有内容，焦点留在搜索框。清空不关闭已打开详情。模块切换保留关键词、更新范围并按模块重新解释；设置模块隐藏搜索，项目切换沿用既有项目范围规则，全局模块保持跨项目语义。

点击条目打开条目详情；文档命中打开对应条目和对应文档；文件命中打开文件预览。跨模块入口保留关键词并切换目标模块。旧请求不能覆盖新关键词、清空或切换模块后的结果。讨论、任务、全局不因界面调整新增远程搜索依赖。

### 状态反馈

- 未输入：显示范围提示与模块原有内容，不显示“无匹配”。
- 加载：搜索区域显示“正在搜索”，保留输入和清除入口；若保留旧结果则标为旧结果，不能呈现为新词的完成结果。
- 正常：显示关键词、分类命中数及可执行结果；状态筛选造成零可见条目时说明筛选影响。
- 空结果：显示“未找到匹配结果”，提供修改关键词、清除搜索；不能与模块本身无数据混为一谈。
- 失败：区域内持续显示失败说明和重试按钮，保留关键词；重试使用当前词，成功后移除错误。
- 截断：明确仅显示部分结果，并建议缩小关键词。

### 边界与待确认

仅完善搜索交互布局，不新增全文索引、排序算法、跨项目搜索范围或搜索历史。搜索精度、服务端性能目标、最终视觉尺寸以及真实用户常用窗口尺寸待确认；本条未定义新的延迟指标。design 和 test-cases 留待开发阶段补充。

## 验收标准

- [ ] 模块搜索范围标签在输入前后均可见；五个模块语义与既有 SEARCH_PLACEHOLDER/搜索数据源一致，设置隐藏搜索。
- [ ] 宽屏标题与搜索对齐，窄屏可换行；在 375px 与 1280px 演示宽度下输入、清除、重试和结果均可操作且无页面横向溢出。
- [ ] 输入防抖、Enter 立即搜索、Esc/清除恢复原内容可用；清空保留输入焦点且不关闭详情。
- [ ] 切换模块或项目按原范围重新搜索，跨模块结果入口保留关键词；过期响应不覆盖当前状态。
- [ ] 条目、文档、文件数量可区分；需求状态筛选下的可见数量不冒充总命中数；截断结果提示明确。
- [ ] 条目和文档命中能打开对应内容，文件命中能打开预览；长标题/路径可获得完整文本。
- [ ] 未输入、加载、正常、空结果、失败状态互不混淆；失败保留关键词并能重试，加载可清空。
- [ ] 主要操作可通过键盘完成，有可见焦点和输入标签；状态反馈可由辅助技术读取。
- [ ] ui-demo.html 离线直接打开可交互，覆盖布局、结果点击及正常/空/加载/失败切换，README 含有效相对链接；不将演示数据宣称为真实结果。
