## 描述

效果页按项目、渠道、实验及日期筛选。指标分曝光（展示/播放）、互动（点赞/评论/收藏）、持续关注（粉丝/订阅/Star）、使用（访客/下载/激活/留存）、商业（付费人数/收入/退款）。指标定义包含单位、存量/期间增量/事件次数/独立人数、适用对象、时间窗口和去重口径。主指标可选已有定义。

每笔观察记录项目、渠道/实验/行动归属、指标键、值、单位/币种、起止日期、时区、来源、采集方式、采集时间、修订号。未知值用空值表示，真实零可录入；禁止把粉丝、订阅、Star 汇总成去重总人数。存量指标不跨日期相加；来源相同的手工与同步记录不重复计算。第一版只对同口径、同币种、可加的互斥数据求和，其余分开呈现。

手工录入支持修改理由和修订历史。CSV 提供模板、UTF-8 导入、字段映射、预览及逐行错误；日期/数字/指标/归属不合法则阻止提交，全部校验通过才原子提交。同一文件重复导入为无变化；相同观察键但值不同要求明确选择修订或跳过，不静默相加。

提供指标表及趋势图；关联数据具备一致观察范围时才显示转化率，分母为零或口径不一致显示“不可计算”及原因。复盘记录观察期、目标与实际、依据快照、结论及下一步；无数据可保存“数据不足”，不伪造改善幅度。

## 界面展示

布局：顶部日期范围、渠道/实验筛选与录入/导入按钮；中部分类指标卡片，下面趋势图、原始观察表与复盘记录。卡片显示来源及更新时间。
交互：点指标查看定义和原始记录；导入打开字段映射→预览校验→确认结果流程；点击新建复盘选择观察期和依据，保存后关联实验。
反馈：区分未录入、真实零、不可计算、加载中和读取失败；错误行显示行号和原因；导入失败保留当前页面且不部分写入；修订可追溯。

```text
[近30天] [渠道] [实验] [录入指标] [导入CSV]
曝光：未录入  订阅新增：0  激活：12  收入：未录入
[趋势图]   来源：手工记录  更新时间：…
指标 | 期间 | 值 | 口径 | 来源 | 修订
[新建复盘] 目标 / 实际 / 依据 / 下一步
```

可交互演示：[ui-demo.html](./ui-demo.html)（单文件、内联 CSS/JS、无外网依赖、浏览器直接打开）。演示以顶部「演示状态」切换正常 / 空（新项目）/ 加载中 / 读取失败四种页面状态，可操作内容包括：

- 分类指标卡片（区分未录入 / 真实零 / 数值与口径徽标），点卡片展开指标定义、原始记录与修订历史（含修改理由）；
- 手工录入 / 修订弹层：非法值、非法日期、归属不完整、修订缺理由均被拒绝并给出原因；
- CSV 导入向导：选择样例（合法 / 含错误 / 重复导入 / 值冲突）→ 字段映射 → 预览校验（错误行显示行号与原因，存在错误时禁止提交、不部分写入）→ 提交结果；重复导入为无变化（幂等），值冲突需逐行选择修订或跳过；
- 派生指标区：转化率仅在口径一致且分母有效时计算，分母未录入 / 分母为零 / 口径不一致分别显示「不可计算」及原因；
- 新建复盘弹层：绑定观察快照保存，或保存为「数据不足」；复盘卡片标注依据快照，后续数据修订不改变历史复盘依据。

演示内置深浅色切换与 Esc 关闭弹层；实际实现沿用宿主深浅色与键盘行为。

## 验收标准

- [ ] 未知与零显示不同，存量与增量明确，跨平台关注不展示伪去重总数。
- [ ] 手工录入、修订、重载均保留来源、周期和历史；非法值与归属被拒绝。
- [ ] 合法 CSV 经预览一次提交成功；错误 CSV 显示具体行号且不写入部分数据。
- [ ] 重复导入不增加记录；冲突值需明确修订或跳过，不能重复累计。
- [ ] 不同币种、时区或指标口径不混算；分母为零及范围不一致有解释。
- [ ] 复盘关联固定快照或修订版本，后续数据修订不静默改变历史复盘依据。
