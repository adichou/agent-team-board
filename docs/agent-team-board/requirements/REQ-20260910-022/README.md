## 描述

新增项目增长工作流 skill，提供“梳理定位 / 分析定价 / 制定渠道计划 / 生成内容 / 复盘”五类入口。第一版沿用现有外部 Agent 会话工作方式：界面生成可复制提示词，用户在可访问项目文件的会话执行，通过统一 CLI/API 写入营销草稿与记录，不新增常驻模型服务。

提示词携带明确项目路径、营销资料位置、目标任务、输入版本、读取历史结果和统一保存规则。按需复用 coreyhaines31/marketingskills 的 product-marketing、marketing-plan、pricing、launch、content-strategy、copywriting、social、analytics、attribution、ab-testing；先固定审查版本并记录许可证与来源，不安装整套后默认全部加载。共享上下文以 ATB 档案为事实源，外部 skill 所需上下文由适配层导出，不能维护两份相互漂移的主档案。

Agent 输出事实/假设/待确认、证据引用、候选行动、缺失信息、建议理由和验证方法；复盘引用实际指标快照，数据不足先建议补采。候选价格不能自动生效，候选渠道不能自动变为已验证。用户可逐项编辑并采纳；未采纳保留草稿。候选行动通过显式采纳形成正式记录。

每次运行保存任务 ID、来源会话（可得时）、输入引用及版本、输出摘要、草稿引用、写入时间和执行结果，支持重复保存幂等和跨会话接续。没有回执不宣称已保存，文件内容变化时提示基线过期并重新校对。已授权任务可以继续生成本地草稿，对外发布、发送及付费需要明确授权。

## 界面展示

布局：各页右上角放对应 AI 辅助按钮；弹出任务面板显示使用的项目资料和复制提示词按钮。返回草稿在右侧展示事实、假设、证据及逐项采纳操作；效果页提供“生成复盘草稿”。
交互：复制提示词仅产生剪贴板内容；回执到达后显示草稿，用户编辑/采纳后更新正式档案。点击继续任务复制含历史引用的接续提示词。
反馈：未安装技能时列缺失能力及手工提示词兜底；等待回执显示“尚未收到结果”；保存失败、过期输入和无法读取文件分别提示，保留旧成果。

```text
[分析定价] -> 输入：档案v3 / 定价v1 / 结果快照
[复制任务提示词]  尚未收到结果
返回草稿：事实 | 假设 | 待确认 | 证据
候选方案A  [编辑] [采纳]   候选方案B [保留草稿]
[复制继续任务提示词]
```

可交互演示：[ui-demo.html](./ui-demo.html)（单文件、内联 CSS/JS、无外网依赖、无构建步骤、浏览器直接打开）。演示以顶部「演示状态」切换正常 / 技能缺失 / 空项目 / 输入过期 / 保存失败五种场景，可操作内容包括：

- 布局：宿主模块导航与营销四页签（概览 / 定位与定价 / 渠道与行动 / 效果与复盘），各页右上角对应 AI 入口按钮（梳理定位 / 分析定价 / 制定渠道计划 / 生成内容 / 生成复盘草稿）；任务面板显示将使用的项目资料（输入引用及版本、与当前版本一致性）、技能可用性与目标任务；复盘入口可选观察期（有指标快照 / 无观察记录）。
- 交互：复制任务提示词仅写入剪贴板不执行（含项目路径、资料目录与版本、历史结果引用、输出要求与统一保存协议）；复制后登记 agent-runs 并显示「尚未收到结果」；「模拟回执到达」为演示模拟控件（真实回执由外部会话经统一 CLI/API 写入，命令为规划示意）；回执草稿分区展示事实 / 假设 / 待确认、证据引用与缺失信息，候选行动（含建议理由、验证方法、写入目标）逐项编辑 / 采纳 / 保留草稿；「复制继续任务提示词」生成含历史草稿与采纳记录引用的接续任务；运行记录可查看任务 ID、来源会话、输入引用及版本、输出摘要、草稿引用、写入时间与执行结果。
- 反馈：候选定价采纳后仅写入候选版本并提示「不自动成为当前方案」；候选渠道保持「待验证假设」；复盘草稿绑定 metrics@r2 快照，无指标观察期输出「数据不足」与补采建议、不生成虚构结论；相同任务重复回执幂等跳过不重复保存；输入基线过期时回执被拒绝（未写入、不覆盖他人更新）并可按当前版本重建任务；保存失败提示错误并保留草稿可重试；技能缺失列出能力缺口并提供手工提示词兜底（不假称已运行外部 skill）；空项目提示「无法读取项目资料」并提供仅基于 README 的兜底提示词；深浅色随系统并可手动切换，Esc 关闭弹层。

## 验收标准

- [ ] 五类入口提示词包含正确项目归属、输入版本、资料路径及保存协议。
- [ ] 技能缺失时说明能力缺口并提供兜底，不假称已运行外部 skill。
- [ ] 输出区分事实与假设，价格及策略采纳前不改变正式方案；不自动对外发布。
- [ ] 相同任务回执重复提交幂等；过期输入与跨项目写入被识别，不覆盖他人更新。
- [ ] 新会话能按任务引用读取已有资料继续，写入成功有可核验回执。
- [ ] 无指标场景输出数据不足与补采建议，不生成虚构业绩或因果结论。
