# REQ-20260830-001 根据当前会话所在项目自动切换看板项目

- 状态：submitted（待人工接受）
- 创建：2026-08-29T16:20:18.675Z

## 描述

现状：Status Board 服务（server.mjs）启动时以 process.cwd() 绑定单一项目的 docs/agent-team-board，多项目并行开发时只能看到启动目录那个项目的看板，换项目必须重启服务或开多个端口。需求：当会话执行 /board 或调用 API 时，能根据当前会话的工作目录（即该会话所在项目）自动切换看板数据源，展示对应项目的需求/Bug 数据，无需为每个项目单独启动服务或手动切目录。

## 验收标准

- [ ] 单个 Status Board 服务实例可展示多个项目（各自的 `docs/agent-team-board/`）的数据，不要求每个项目单独启动 server 或占用不同端口。
- [ ] 会话执行 `/board`（或前端操作）时，看板自动定位到该会话工作目录所属项目的数据，无需手动重启服务或改启动目录。
- [ ] 前端有清晰的项目标识（当前展示哪个项目），并支持手动切换项目作为兜底。
- [ ] 状态流转操作（接受/确认完成/驳回）作用于当前展示项目的条目，不串项目。
- [ ] 未初始化 `docs/agent-team-board/` 的项目有明确提示（如引导初始化），而不是报错或空白。

## 补充说明

- 现有绑定逻辑在 `scripts/server.mjs`：启动时取 `process.cwd()`，经 `core.dataDirFrom(cwd)` 固定为单一数据源；多项目方案（单服务多项目切换 vs 其他形态）待 design.md 阶段确定。
- 兼容性：现有单项目用法（一个服务管一个项目）不应被破坏。
