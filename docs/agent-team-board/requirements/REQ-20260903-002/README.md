# REQ-20260903-002 看板页面重新设计，现在竖屏操作，每个类别的单只能看见一条，多的就要下拉滚动条，不友好

- 状态：in-progress（Agent 实施中）
- 创建：2026-09-02T23:48:37.683Z

## 描述

手机/窄窗口竖屏使用看板时（≤640px），四个状态列按行竖排、四行均分看板区高度，
每列只分到约 1/4 视口高度，一列里往往只能看到 1 张卡片；看同类其余条目要在小窗口里
反复下拉，对比不同状态的条目还要在四个小窗口之间来回滚，非常低效。

### 界面布局（≤1020px 重设计；v5：横滑布局扩展到全部中窄窗口）

- **适用范围 ≤1020px**（v5 前仅 ≤640，中窄窗口会退回旧 2×2 网格，验收反馈已废除）：
  四个状态列**横向排列、左右滑动切换**：
  - 每列占满看板区全高，列内卡片纵向排布、列内滚动；
  - 一屏可见卡片数从约 1 张提升到 3–6 张（取决于卡片高度与窗口宽度）；
  - 滑动按列吸附（scroll-snap），一次手势只翻一列，不会滑过头；
  - 列宽上限 560px：窄屏占满可视区，中宽窗口右缘露出下一列预览提示可滑。
- 看板**左缘为竖排 tab 条（管风琴风格）**：4 个竖长 tab 并立（类似风琴管/书脊），
  每个竖 tab 内状态名竖排（自上而下）、下方显示该列计数；吸附位右移让列内容不被 tab 条遮挡。
- **顶栏紧凑化（v4）**：项目路径（数据目录）不再显示；操作区（项目切换 / 实时指示 / ＋新建）
  与标题同排靠右，放不下时整体换到次行右对齐；项目切换器按内容自适应宽度（不截断当前选中项）。
- **左侧统一工具栏（v6）**：「需求 / 文件」视图切换竖排固定到左缘、顶栏正下方，
  看板列 tab 条紧随其下（按视图组高度自动让位），构成一条左工具栏；底部横条导航取消。
  文件视图下左栏保留（状态列 tab 随看板隐藏），可随时切回；桌面顶栏布局不变（视图切换仍横排）。
- 桌面（>1020px）保持四列网格不变。

### 交互行为

- 左右滑动手势或点击左缘竖 tab 切换状态列；滑动停止后自动吸附到最近列。
- 横滑时 tab 条用 sticky 钉在左缘不动，列从其下方滑过；tab 高亮始终跟随当前列。
- 列内仍可上下滚动查看全部卡片；列头（状态名 + 计数）随列固定在列顶部。
- 拖拽改状态仍按现状用鼠标操作（触摸端 HTML5 拖拽本就不可用，不回归也不新增）。

### 状态反馈

- 当前列对应竖 tab 高亮（品牌色底、白字），其余为面板色底灰字；带 `aria-current` 与可读名称。
- tab 计数随轮询实时刷新。
- 竖屏顶栏不显示项目路径（空间让给操作区）；「● 实时」连接指示保留显示。
- tab 条仅在竖屏（≤640px）看板视图显示：桌面宽度、文件视图、未初始化空状态下均不显示
  （tab 条是看板容器的子元素，随看板一同隐藏）。
