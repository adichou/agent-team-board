# REQ-20260909-014 需求模块详细页面的说明，设计，测试用例文档支持右键菜单“讨论”

## 描述

需求模块详情抽屉自 REQ-20260909-006 起为五页签布局（基本信息 / 说明 / 设计 / 测试用例 / 讨论纪要，`scripts/web/app.js` 的 `renderDrawer` / `activateDrawerTab` / `loadDoc`），其中说明 / 设计 / 测试用例三份文档以 Markdown 渲染态展示在 `#docView`（约 2243–2245、2389–2404 行）。用户阅读这三份文档时，经常需要就某段内容与 Agent 讨论：现有途径要么进「讨论纪要」页签用 REQ-20260909-003 的「文档讨论」成套流程（仅覆盖 README.md，且要先「开始讨论」生成编号才能复制引用），要么去文件模块查看源码点行号复制——都绕开了用户正在阅读的位置。本需求在文档页签内提供一个**免流程的轻量右键入口**：

1、点击“讨论”后，将当前所选文字，及其所在文件路径，行数拷贝到剪贴板，方便用户复制到会话中和 Agent 讨论
2、如果没有选中文字，则把当前文件路径和鼠标所在行号复制。

口径说明：

- 原文「行数 / 行号」按**源码行号（1 基，Markdown 源文件行；跨多行时为行范围）**理解，与 req-disc 阅读模式（`scripts/web/req-disc.js` `parseBlocks` / `onReaderSelect`）和文件模块查看器 `fileLineRef` 的 `路径:行号` 口径一致；文档页签是渲染态、无视觉行号，行号由前端源码映射得到（实现方式 design.md 定稿）。
- 「鼠标所在行号」指右键落点对应内容的源码行（或行范围）；「文件路径」为该文档在磁盘上的路径，口径 `<项目根>/docs/agent-team-board/requirements/<单号>/<文档名>`（同 req-disc 引用复制的 `docPath` 拼法，`req-disc.js` 约 509 行）。
- 本需求是**纯剪贴板轻量入口**：不生成 DISC 编号、不保存引用快照、不落任何讨论记录；需要成套讨论流程时仍走 REQ-20260909-003 的「文档讨论」区块，两者并存互不影响。

### 现状依据（基于当前代码）

- 文档页签渲染：`scripts/web/app.js` `DOC_LABEL`（77–82 行）、`DRAWER_FIXED_DOC_TABS = ['README.md','design.md','test-cases.md']`（87 行）、`activateDrawerTab`（2293 行起，缓存回填 + 缺失空态「尚未创建，开发阶段补充。」+ 加载占位「加载中…」）、`loadDoc`（2389 行起，`GET /api/item/:id/doc/:name` → `renderMd` 渲染到 `#docView`）。文档页签仅渲染态，无源码态切换、无行号展示。
- 前端目前**无任何 contextmenu 处理**（`scripts/web/*.js` 检索无果）；Electron 壳（`electron/main.mjs`）也未注册 webContents 右键菜单，壳内右键默认无系统菜单，页面自定义菜单即最终行为。
- 可复用能力：`copyPlain`（app.js 1038 行，navigator.clipboard 优先 + execCommand 降级）、`toast` 反馈、`fileLineRef`（app.js 1033 行）；REQ-20260909-003 的 `req-disc.js` 已有 Markdown 源行块解析 `parseBlocks`（约 561 行起，按 heading / para / fence / list / table 等分块记录 1 基源行号）与选文 → 源行映射（`onReaderSelect`，段落 / 代码内按换行计数映射；列表 / 表格内选文不映射，引导整段引用）。
- 相邻能力边界：REQ-20260909-003「文档讨论」为成套流程（DISC 编号、版本与引用快照、纪要归档、README 草稿应用），仅服务 README.md；本需求覆盖说明 / 设计 / 测试用例三份文档的日常阅读场景，复制即结束。

### 目标口径

1. 纯前端剪贴板能力：不新增后端 API、不写任何文件 / 记录、不改状态机；复制成功即结束（toast 反馈），粘贴到哪个会话由用户自理。
2. 作用域限定在需求详情抽屉的文档内容区（说明 / 设计 / 测试用例页签的 `#docView` 内）：右键文档内容弹出自定义菜单；文档区外（列表、基本信息、讨论纪要、页签行等）右键保持浏览器原生行为。
3. 复制内容须自包含：Agent 不打开看板也能凭剪贴板定位——至少含 文档路径 + 源码行号（范围）+ 所选文字（无选中时为路径 + 行号）。
4. 行号必须与源文件一致（以 `/api/item/:id/doc/:name` 返回的源码为准），不因渲染换行产生偏差。

## 界面布局

不改抽屉整体布局，仅新增一个轻量菜单浮层（fixed 定位，出现在右键坐标处）：

```
┌ 需求详情抽屉（#drawer）─────────────────────────────┐
│ REQ-20260909-014                                ✕   │
│ [基本信息][说明][设计][测试用例][讨论纪要]             │
│ ┌ #docView（渲染态 Markdown）──────────────────────┐ │
│ │ ## 描述                                          │ │
│ │ ……（选中一段文字后右键）……                        │ │
│ │                          ┌──────────┐           │ │
│ │                          │ 💬 讨论   │ ← 右键菜单 │ │
│ │                          └──────────┘           │ │
│ └─────────────────────────────────────────────────┘ │
└─────────────────────────────────────────────────────┘
```

- 菜单为单项「讨论」（是否带图标 / 辅助说明见待确认），宽约 160–200px，样式沿用看板现有面板 / CSS 变量体系，不新引入配色；具体视觉 design.md 定稿。
- 菜单出现在右键坐标附近，靠近视口边缘时自动内收，不溢出、不遮挡落点内容。
- 深浅色沿用现有变量；窄屏（抽屉覆盖层形态）同样定位正确。

## 交互行为

1. **唤起**：在当前激活的文档页签内容区（`#docView` 内）右键 → 弹出菜单「讨论」。文档处于加载中 / 未创建空态 / 加载失败态时不弹菜单（或等效不可用反馈，见待确认）。链接（`./ui-demo.html` 演示链接、外链）与图片上的右键是否放行原生菜单见待确认。
2. **有选中文字**：点「讨论」→ 复制 所选文字原文 + 文档路径 + 所选内容对应的源码行号（范围）到剪贴板。
3. **无选中文字**：点「讨论」→ 复制 文档路径 + 右键落点（鼠标所指内容）对应的源码行号（行或行范围）。
4. **复制与回退**：走 `copyPlain` 双回退（navigator.clipboard + execCommand）；成功 toast 反馈；失败给出手动复制引导（文本选中 / 展开）。
5. **选文映射降级**：选择跨块或位于列表 / 表格等无法精确映射源行的元素时，按 req-disc 既有口径处理（复制可确定的行范围或提示改选），具体降级规则 design.md 定稿。
6. **菜单收起**：点菜单项执行后关闭；点击菜单外任意处、Esc、滚动文档、切换页签、关闭抽屉——关闭菜单且不执行；再次右键时菜单位置跟随更新，同一时刻至多一个菜单。菜单打开期间不阻止文档正常滚动与文字选择。
7. **三份文档一致**：README.md / design.md / test-cases.md 三个页签行为一致；与 REQ-20260909-003「文档讨论」区块并存互不影响。

## 状态反馈

- **正常**：右键即弹菜单；点「讨论」后菜单关闭，toast 展示已复制内容的摘要（如「已复制 引用：README.md 第 12–18 行」），用户可直接去 Agent 会话粘贴。
- **空**：文档未创建（「尚未创建，开发阶段补充。」）时右键不弹菜单（或菜单项置灰，见待确认）。
- **加载**：文档「加载中…」占位期间右键不弹菜单。
- **失败**：复制失败 toast 错误 + 手动复制引导（选中已展开的文本）；文档加载失败（toast 报错）后右键不弹菜单。
- 菜单本身为纯前端浮层，无网络请求、无异步态。
