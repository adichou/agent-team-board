# REQ-20260906-006 单号复制能力要通过一个“复制”按钮提供出来，去掉点击单号复制按钮的能力，太隐晦了。

- 状态：以 status.json 为准
- 创建：2026-09-06T02:58:25.754Z

## 描述

在看板卡片、详情标题和下属 Bug 列表的单号旁显示独立「复制」按钮。单号本身不再绑定复制行为；点击卡片或 Bug 行仍按原规则打开详情。用于跳转条目或执行记录的单号链接保留导航功能。

点击按钮仅复制该单号，不触发卡片打开或列表跳转。复制成功后按钮短暂显示「已复制 ✓」再恢复「复制」，单号文字始终保留；失败提示手动框选，允许重试。按钮支持键盘操作、明暗主题和窄窗口布局。

## 验收标准

- [ ] 三个现有复制入口均改为可见的独立按钮。
- [ ] 点击单号不复制；点击复制按钮不打开详情或跳转。
- [ ] 成功反馈在按钮上显示，单号保持不变；失败可重试。
- [ ] Clipboard API 与原有降级路径均可用，原有导航不受影响。
