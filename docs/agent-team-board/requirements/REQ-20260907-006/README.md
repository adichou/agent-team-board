- 状态：in-progress（zcode-batch-007-1 实施中）

## 描述

需求模块（全部需求列表）当前在第四行提供状态筛选条（REQ-20260907-004 引入）：
「全部 / 待接受 / 已接受 / 开发中 / 待测试 / 已完成」六档 chips 带计数，点击后
列表只显示该档条目。本需求**去掉这条状态筛选**：

- 需求模块不再渲染第四行筛选条（`#filterBar` 节点与 chips 全部移除），页面不保留
  空占位行；
- 列表始终显示全部需求与 Bug（含各状态），不再有按状态过滤的交互；
- 第三行模块搜索行为不变：仍按关键词过滤当前列表，清空恢复，零结果空态文案
  不再提「筛选」（仅提搜索）；
- 列表行状态标签（待接受/已接受/开发中/待测试/已完成）、详情页、勾选与批量
  工具条、状态流转等业务能力不受影响；
- 讨论模块自身的状态筛选（oncall filters）与任务模块筛选不在本次范围，保持现状。

（登记时仅标题。实施解读依据：REQ-20260907-004 引入的「第四行：需求状态筛选」是
代码中唯一对应「全部需求的过滤条件」的常驻过滤条；本批次同期登记的
REQ-20260907-007 亦为同风格删减需求。）
