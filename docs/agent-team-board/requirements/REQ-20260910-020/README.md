## 描述

渠道按项目维护：平台、账号/社区链接、目标受众、市场语言、内容形式、优先级、选择理由、每周投入、获取数据方式及可用能力。默认提供可编辑空模板；渠道建议是待验证假设，不预设所有项目适合相同平台。

区分三层：渠道是长期触点；实验是一个推广假设及验证目标；行动是一篇内容或一次发布。实验记录假设、主指标、观察起止时间、成功标准、预算/实际支出、预计/实际工时、定价版本和最终决策。行动记录渠道、内容草稿、素材引用、计划时间及时区、发布链接、实际发布时间、负责人、下一步和关联 REQ。

行动状态为草稿→待发布→已发布→观察中→已复盘；未复盘状态可停止，记录原因。已复盘或已停止后通过「复制为新实验」再尝试，保留历史；误操作更正记录原因与历史。标记已发布必须有发布时间和发布链接，无法提供公开链接时填发布凭据说明。已复盘需记录结果依据及继续/调整/停止决策，数据不足也可结束并注明“暂不能判断”，不能等同验证成功。

通过人工点击「创建开发需求」将落地页/埋点等工作转为 submitted REQ 并双向关联，重试不重复创建；不自动接受或实施。第一版支持复制文案和人工登记发布结果。

## 界面展示

布局：渠道与行动页上方渠道筛选、实验筛选及新建入口，中部为行动状态列；点击卡片从右侧打开详情抽屉，分基本信息/内容素材/结果与关联。窄屏改状态筛选后的列表。
交互：卡片显示渠道、计划时间、主指标和负责人；通过明确的状态按钮推进，缺少必填信息时留在原状态。内容可编辑与复制，创建关联需求后可跳转。实验可有多条行动。
反馈：空态提供新建渠道/实验；无匹配结果可清除筛选；保存和复制成功有轻提示；失败保留草稿；过期未发布只提示逾期，不自动发布。

### 可交互演示

[./ui-demo.html](./ui-demo.html)——单文件、内联 CSS/JS、无外网依赖、无构建步骤，浏览器直接打开即可交互；示例数据仅用于演示，不写入真实项目。演示覆盖：

- 布局：工具栏（渠道筛选 / 实验筛选 / 新建入口）+ 实验条 + 六状态列看板（草稿 / 待发布 / 已发布 / 观察中 / 已复盘 / 已停止）；点击卡片从右侧打开详情抽屉，分基本信息 / 内容素材 / 结果与关联；窄屏自动切换为状态筛选后的列表。
- 交互：新建渠道（可编辑空模板）、新建实验（含币种 / 零预算 / 定价版本绑定）、新建行动（渠道 / 实验 / 计划时间与时区）；状态推进校验（待发布需内容草稿、已发布需发布时间 + 链接或凭据说明、复盘需依据与决策、「暂不能判断」不等同验证成功）；停止与更正均记录原因并入操作历史；已复盘 / 已停止后可「复制为新实验」（新 ID、保留来源、行动置为草稿）；「创建开发需求」进入 submitted 并双向关联，重试不重复创建；「复制文案」仅写剪贴板不发送，人工登记后才展示已发布。
- 反馈：正常 / 空（引导建渠道 / 实验）/ 加载骨架 / 失败（读写失败保留草稿可重试）状态切换；无匹配结果可一键清除筛选；保存与复制成功有轻提示；过期未发布仅显示「逾期」提示，不自动发布；深浅色随系统并可手动切换。


## 验收标准

- [ ] 能创建渠道→实验→多条行动，刷新后关联保持，按渠道及实验正确筛选。
- [ ] 状态推进校验发布凭据和复盘依据；缺失时状态不改变并显示具体错误。
- [ ] 不同市场、时区、币种和零预算实验可正确保存；费用按币种独立展示。
- [ ] 修改当前定价不会改变历史实验绑定版本；复制实验产生新 ID 并保留来源。
- [ ] 文案复制或标记待发布不发送内容；人工登记后才展示已发布。
- [ ] 人工创建 REQ 进入 submitted，双向关联可追溯，同次重试不重复创建。
