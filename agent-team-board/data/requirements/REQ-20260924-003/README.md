### 布局目标

弹窗检查列表由 7 条精简为 3 条，仅呈现整体审查阶段真实执行、有状态反馈的检查项：

1. 各语言内容语义一致（以已审核默认语言为基准）——「运行自动检查」
2. 所有文档内链接真实可达（README 按语言互链：同语言 CHANGELOG 与 FEATURES，链接必须真实可达）——「运行自动检查」
3. 默认语言错别字与行文规范（AI 校对自动上报）——「AI 校对」

①② 为进入整体审查的系统门禁，在阶段条/步骤区已有呈现，本弹窗不再重复；⑥⑦ 属于人工确认口径的静态说明，不构成本弹窗的检查动作，从列表移除（相关口径如需保留，可收敛进弹窗底部提示文案，不单占检查行）。

### 交互行为（保持不变）

- 「运行自动检查」按钮：对 ③④ 执行语义一致性与链接可达性检查（只读、不设门禁、结果即时呈现）。
- 「AI 校对」按钮：派发 Agent 核查默认语言文档错别字与行文规范，结果经 docscheck 账本自动回执到 ⑤。
- 逐条状态图标（完成 / 未运行 / 进行中等七态）与明细展开、悬浮说明保持现状。
- 「取消 / 确认完结」按钮与完结回退规则（范围变化使完结失效回退）保持现状。

### 状态反馈

- 精简后每条检查项的状态图标、子状态文案与明细展开逻辑与现状一致，仅列表条目减少。
- 弹窗高度随条目减少自然缩短，不再出现静态占位行。
