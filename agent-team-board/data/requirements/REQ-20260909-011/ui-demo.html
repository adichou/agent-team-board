  • 「执行 Agent」下拉、空占位「选择执行 Agent…」（BUG-20260908-016）与「设置中已隐藏全部执行 Agent」禁用提示全部移除；无候选时启动仍禁用并说明原因。
  • 提示词粘贴到任意一种 Agent 会话均可执行；会话 / 子会话命名由提示词内的通用指令描述（见视图三）。
