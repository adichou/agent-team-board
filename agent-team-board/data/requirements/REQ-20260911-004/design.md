# 设计 — REQ-20260911-004 在设置中支持对 commit 到 git 的目录进行设置，默认只 commit 源代码相关目录

> 由 Agent 在 /dev 开发前补充，人可随时批注。

## 背景

批量 commit（REQ-20260910-013）的调度提示词与 done 核验均无目录级约束：任何目录的改动只要能归因到候选单
就可能被提交（`output/` 素材、`.zcode/` 运行痕迹、插件元数据目录没有防线）。本设计为批量 commit 增加可配置的
「提交目录范围」（白名单），贯通三层：设置存储 → 批次创建时冻结进调度提示词 / 领取摘要 → done 回执核验兜底。

## 方案

### 待确认结论（README §待确认 1–5）

1. **默认清单**：顶层目录白名单，规范形为「顶层目录名 + 尾斜杠」。默认勾选 =
   `scripts/ bin/ commands/ electron/ hooks/ skills/ docs/` **+ 根级文件**（路径不含 `/` 的文件，
   如 `package.json`、`README.md`、`.gitignore`，独立开关，默认开）。默认不勾选（可选）=
   `output/`（素材·生成物）、`.codex-plugin/ .zcode/ .zcode-plugin/`（插件元数据 / 会话数据）。
   该清单是**插件级约定目录**（非按各仓库 `git ls-files` 探测——探测会让默认值随仓库漂移、不可测）；
   其他项目可通过保存自定义顶层目录进入白名单（存储与 API 支持，设置页 v1 不提供自定义输入框，
   已保存的自定义目录会显示在「其他目录」组并标注「自定义」）。
2. **`docs/` 默认纳入**（README 待确认 2 的第二种口径：条目文档仍默认提交，仅排除 `output/` 等其余
   非源代码目录）。理由：①「条目目录内文档改动属 doc 类提交」是现行核心核验项，批量 commit 的正常
   流程包含条目文档提交；②默认排除会使 done 单的条目文档默认滞留工作区，破坏看板以 git 历史承载的
   条目可追溯性；③既有端到端断言（`commit-batch-20260910-013` / `commit-serve-20260910-014` 的
   业务/测试/条目文档三组提交）不回归。README 演示核对路径 5 已预留「默认清单以本结论为准」。
   「默认只 commit 源代码相关目录」按「源代码目录 + 条目文档（docs/，doc 类）+ 根级文件」执行。
3. **配置形态**：允许清单（白名单）。目录 token 校验：单个顶层目录名（`[A-Za-z0-9._@-]+`，可带尾斜杠，
   落盘规范为带尾斜杠），拒绝嵌套路径（含 `/` 的多级）、绝对路径、空串、`.`、`..`；重复项去重。
   根级文件为独立布尔开关（默认 true）。**范围全空**（目录为空且根文件关闭）整体拒绝保存
   （「将无内容可提交」，界面同步禁用并引导恢复默认）。
4. **核验口径：严格拒绝**。done 回执核验（`validateItemCommits`）发现任一 commit 含范围外文件 →
   整体拒绝，错误信息列出越界文件与允许范围，与既有核验（消息格式 / 单号 / 描述长度 / 测试业务分离 /
   条目文档归类）同口径，不允许静默通过。子代理不得 reset，被拒后可改走 `commit fail --reason` 交人工处理。
   创建批次时**不做**工作区超范围改动前置提示（范围约束由提示词传达；前置提示属增强，不在本单）。
5. **存储位置**：`<dataDir>/tasks/settings.json` 新增 `commit` 分区，沿用
   `loadTaskSettings` / `saveTaskSettings` 的读写 / 校验 / 缺省合并回退通道（「非法值整体拒绝、
   缺省宽松读」精神不变）；`commits/settings.json` 保持纯幂等计数器账本用途，不混放用户设置。

### 数据形态

```jsonc
// <dataDir>/tasks/settings.json
{ "version": 1, "agents": {...}, "models": {...}, "refine": {...},
  "commit": { "dirs": ["scripts/","bin/","commands/","electron/","hooks/","skills/","docs/"],
              "rootFiles": true } }
```

- 读取宽松：`commit` 分区缺失 / 损坏 / 字段非法 → 回退默认清单（含根文件开），不阻断批量 commit；
  加载结果带 `configured` 标记（保存过 = true），供设置页展示「未配置 · 默认生效」空态。
- 保存严格：`patch.commit = { dirs?, rootFiles? }` 局部合并；非法值整体拒绝（不产生半截配置）。

### 生效链路（同一事实源：批次创建时冻结）

1. **批次创建**（`createCommitBatch`）：读 `commitScopeOf(loadTaskSettings(dataDir))`，把规范化的
   `{ dirs, rootFiles }` 冻结进 `batch.scope`，并把范围约束行注入 `buildCommitPrompt` 生成的调度提示词
   （提示词随 batch.json 冻结）——「保存后仅对新创建批次生效」天然成立，与批量任务设置口径一致。
2. **领取**（`nextCommitItem`）：提交规范摘要（spec）由静态常量改为按批次冻结范围生成，
   与提示词口径一致（在途批次不读当前设置，不含过期范围）。
3. **回执核验**（`finishCommitRun` → `validateItemCommits`）：按批次冻结范围校验每个 commit 的变更文件
   （`git show --name-only`）：根级文件受 `rootFiles` 控制，子目录文件按首个路径段匹配白名单；
   越界 → 拒绝。存量批次无 `scope` 字段 → 回退默认清单（不读当前设置，在途行为可预期）。

### 界面（设置页「批量 Commit」分区，沿用批量任务分区的加载/失败/草稿交互）

- 位置：设置页「批量任务」分区之后；共享 `state.tasks` 的加载骨架 / 加载失败 + 重试（同一数据源
  `/api/tasks/settings`）。
- 内容：标题「批量 Commit」+ 一句说明（范围仅约束批量 commit 的提交；范围外改动保留在工作区；
  保存仅对后续新创建的批量 Commit 任务生效）+ 两组复选框：
  「源代码相关目录（默认勾选）」= `scripts/ bin/ commands/ electron/ hooks/ skills/` + 根级文件开关；
  「其他目录」= `docs/`（条目文档与看板数据，默认勾选）、`output/`（素材·生成物）与
  `.codex-plugin/ .zcode/ .zcode-plugin/`（插件元数据，默认不勾选）+ 已保存自定义目录（标注「自定义」）。
- 交互：勾选变更 → 状态行「有未保存的更改」；「恢复默认（源代码目录与条目文档）」一键回默认清单；
  全空 → 空态警示 + 保存禁用；保存 → 按钮禁用「保存中…」→ 成功（状态行 + toast「仅对后续新创建的
  批量 Commit 任务生效」）/ 失败（错误就近显示、草稿保留可重试）。未配置态显示
  「未配置 · 默认生效」信息条。目录清单常量在 app.js 内置（服务端校验为唯一事实源，UI 常量仅展示用）。
- 服务端：`POST /api/tasks/settings` 透传 `body.commit`；GET 返回含合并默认后的 `commit` 分区。

### 开源选型（REQ-20260909-015）

自研。理由：**引入成本高于自研**——本需求是纯配置读写 + 字符串前缀匹配 + 提示词注入，全部落在既有
`task-settings` / `commit-store` 通道上（约百余行），无第三方库可替换的实质工作量；不引入任何新依赖，
不创建条目 licenses.md。

## 风险与边界

- **默认含 `docs/` 与标题字面的偏差**：已在待确认结论 2 记录裁量理由（条目文档归类核验与既有断言不回归
  优先）；如人工裁定改为默认排除，只需调整默认清单常量与设置页默认勾选，链路不变。
- **存量在途批次**：无 `scope` 字段的批次按默认清单核验——极端情况下存量批次此前可提交的越界文件
  （如 `output/`）在回执时被拒；属收紧方向的预期行为，账本不回写。
- **根级文件语义**：白名单只约束顶层目录粒度 + 根级文件开关；目录内部不做更细粒度（README 未要求）。
  根级文件默认放行是为兼容既有根文件类提交（package.json 等）。
- **`validateItemCommits` 签名扩展**：新增可选 `scope` 参数（缺省 = 默认清单），既有调用零改动。
- **不做的事**：不提供 push / 目录探测 / 工作区前置提示 / 自定义目录输入框（v1）；不改动
  `commits/settings.json` 账本语义；REQ-20260911-003 的隐藏口径不动（CLI / `/api/commit/*` 全保留）。
