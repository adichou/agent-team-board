# REQ-20260908-001 任务看板的批次记录上，需要显示每个单的标题，放到单号的后面

- 状态：submitted（待人工接受）
- 创建：2026-09-07T23:47:49.323Z

## 描述

Status Board（任务看板）任务模块的批次面板中，「批次记录」列表（「查看批次记录」展开的运行记录）
每行目前只有结果标记、单号（REQ-/BUG- 编号）、执行器与时间、原因。单看单号无法知道每个单做了什么，
需要在**单号后面显示该单的标题**，与「当前条目」行「单号 + 标题」的展示口径一致。

具体行为：

- 批次记录每行渲染顺序：结果标记 → 单号 → **条目标题** → 执行器 · 时间 → 原因（如有）。
- 标题取自条目 `status.json` 的 `title`；标题过长时截断显示，悬停可看全文（title 属性）。
- 条目已删除/读取失败时标题留空，不影响记录行其他字段展示。
- 任务搜索过滤（REQ-20260907-004）同步覆盖标题：按标题关键字可过滤批次记录。

不涉及 UI 布局/交互的其它改动。

## 验收标准

- [ ] `/api/batch/records`（及 `/api/batch/current` 的 `records`）每条记录包含 `title` 字段，值为对应条目标题；条目缺失时为空串且接口不报错。
- [ ] 批次记录列表单号后面渲染条目标题，超长截断、悬停显示全文。
- [ ] 任务搜索按标题可命中批次记录。
- [ ] 既有批次记录接口字段（runId/itemId/owner/result/reason/reportRef/at）不受影响。
