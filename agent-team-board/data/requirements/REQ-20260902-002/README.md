# REQ-20260902-002 提供 CI Board，支持一些常见项目的构建自动化命令，例如自动重启 server，更改服务端口

- 状态：accepted
- 创建：2026-09-02T14:38:09.211Z

## 描述

在 Status Board 中新增「CI」模块（第六个视图，与 讨论/需求/任务/文件/设置 并列），
把常见的构建自动化操作集中到看板上一键执行。首期覆盖两类场景：

**1. 看板服务自运维（内置能力，标题中「自动重启 server、更改服务端口」）**

- 「看板服务」卡展示当前服务端口、进程 PID、启动时间；
- 一键「重启服务」：自动拉起新进程并替换旧进程，页面无需手动刷新即可恢复访问；
- 「更改端口」：输入新端口（1–65535）后自动以新端口重启服务，端口写入持久化配置
  （`~/.agent-team-board/server.json`），之后 `atb serve` 冷启动也沿用该端口；
  改端口后页面提示并自动跳转到新地址。

**2. 项目构建任务（自定义命令，标题中「常见项目的构建自动化命令」）**

- 按项目（`docs/agent-team-board/ci/`）维护构建任务列表：名称 + 工作目录（绝对路径）+ 命令行；
- 任务可创建 / 编辑 / 删除，可一键运行；
- 每次运行产生一条运行记录：状态（运行中 / 成功 / 失败）、退出码、开始/结束时间、输出日志；
- 日志在看板内查看（追加显示，超大输出截断保护；超时上限 10 分钟自动判失败）。

界面布局：顶栏视图切换新增「CI」页签；页面自上而下为「看板服务」卡 + 「构建任务」列表，
每张任务卡含操作按钮（运行 / 日志 / 编辑 / 删除），运行中状态在卡片上实时可见；
日志以展开面板/抽屉形式查看。状态反馈：按钮操作有 loading 与结果提示，失败原因直接展示。
