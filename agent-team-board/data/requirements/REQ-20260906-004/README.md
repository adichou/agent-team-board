# REQ-20260906-004 File Board 文件详情栏过窄：支持拖拽分隔条调宽并记忆

- 创建：2026-09-06T02:47:17.566Z

## 描述

文件看板（File Board）中，左侧文件树固定 300px、右侧详情内容栏占剩余空间且不可调节；窗口不够宽时详情栏过窄，长行代码频繁折行/横向滚动，阅读困难。界面与交互设计：1) 布局保持左右分栏（左树/右详情），在两栏之间增加约 6px 可拖拽分隔条，hover 高亮提示可拖；2) 交互：拖拽分隔条实时调整两栏宽度，文件树可调范围 180px 至视口 50%，详情栏自适应占剩余空间；双击分隔条恢复默认 300px；拖拽结束把树宽写入 localStorage，刷新/重开窗口后保持；3) 状态反馈与异常：拖动流畅无内容溢出遮挡，极窄窗口下树最小 180px、详情栏保底可读最小宽；未选文件时详情栏保留现有空态提示文案；深浅色主题下分隔条样式一致。

## 验收标准

- [ ] 树与详情栏之间有约 6px 可拖拽分隔条，鼠标悬停高亮、光标变为左右箭头（col-resize）
- [ ] 拖拽分隔条实时调整两栏宽度，文件树可调范围 180px 至视口 50%，详情栏自适应占剩余空间
- [ ] 双击分隔条恢复默认 300px
- [ ] 拖拽结束把树宽写入 localStorage，刷新 / 重开窗口后保持
- [ ] 极窄窗口下文件树最小 180px，详情栏保底可读最小宽（不出现内容溢出遮挡）
- [ ] 未选文件时详情栏保留现有空态提示文案
- [ ] 深浅色主题下分隔条样式一致（用主题变量，不写死颜色）

### 追加（2026-09-06 人工反馈）

- [ ] 文件树层级缩进由 20px/级压缩为 12px/级，深层文件名获得更多可读宽度；同级文件与目录标题保持对齐
