# BUG-20260905-002 default-port 测试 V7 在 8888 被占用时必失败，应像 V6 一样跳过

- 状态：in-progress（已认领 zcode-port-v7-skip）
- 归属需求：REQ-20260905-003
- 创建：2026-09-05T09:18:02.701Z

## 现象

现象：Status Board 运行于 8888 时，node scripts/tests/default-port.test.mjs 的 V7「ATB_PORT=7737 覆盖仍生效」失败；断言 await portBusy(8888) === false（「未设默认端口时不应再占 8888」）无条件要求 8888 空闲，而同文件 V6 对 8888 占用情形已做跳过处理（「⚠ 8888 已被占用，跳过」），行为不一致。复现：看板服务运行中执行 npm test。期望：V7 检测到 8888 被占用时跳过该断言（仅保留 7737 探活断言），与 V6 行为一致。

## 复现步骤

1. 让 Status Board 运行在 8888（默认端口，看板服务启动即占）；
2. 项目根执行 `node scripts/tests/default-port.test.mjs`（或 `npm test`）；
3. V7 失败：`未设默认端口时不应再占 8888`，1/8 用例失败，退出码 1；V6 同环境正常跳过。

## 根因分析

`scripts/tests/default-port.test.mjs` V7（引入于 REQ-20260905-003）末尾断言
`assert.equal(await portBusy(8888), false, '未设默认端口时不应再占 8888')` 无条件要求 8888 空闲。
该断言意图是验证「被测服务器以 ATB_PORT=7737 启动时不会去占默认端口 8888」，但当 8888 已被
外部进程占用（最常见的正是运行中的看板服务本身）时，断言把外部占用误判为被测代码缺陷。
同文件 V6 已确立占用跳过策略（8888 被占则整例跳过并说明），V7 未复用，行为不一致。

## 期望行为（验收标准）

- [x] 8888 被占用时 V7 不失败：跳过「不再占 8888」断言并输出跳过说明，保留 7737 探活与 `port=7737` 断言
- [x] 8888 空闲时该断言保留，仍验证被测服务器未占用默认端口
- [x] 8888 被占环境下 `node scripts/tests/default-port.test.mjs` 8/8 全绿、退出码 0

## 修复

V7 开测时先探测一次 `portBusy(8888)`：被占则打印跳过说明、仅执行 7737 断言；空闲则保留原断言。
8888 探测前置到起服之前，避免与被测服务器自身状态混淆。
