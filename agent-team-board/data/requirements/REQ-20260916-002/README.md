## 描述

发布执行器（`scripts/lib/build-publish.mjs`）只识别两种 Web App 形态：冻结源码仓库根存在 `index.html` 的静态站，或 vite/astro/CRA/vue-cli/nuxt 的 `build` 脚本产物。本项目无打包器，Web 端由 `scripts/server.mjs` 动态服务，冻结 main 两者皆无，发布 BLD-20260914-001（版本 1.0.0）预检报「冻结源码没有可识别的 Web App 构建或根 index.html」。

采用静态入口方案：新增**仓库根 `index.html`**，作为产品落地页（Web App 形态 = 静态站）。页面为单文件自包含静态页：内联 CSS/JS、无外网依赖、无构建步骤，浏览器直接打开可用。内容包含：

- **产品介绍**：Agent Team Board（智能体团队看板）是什么——ZCode 插件，需求/Bug 的文件化管理 + Agent TDD 开发流程 + 本地网页状态板；三栏协作（Project Board / Discussion Board / Status Board）。
- **核心能力**：文件化事实源（docs/agent-team-board 随 git）、单向状态机人机分工（接受/确认完成仅人工，PreToolUse 钩子拦截越权）、认领即实施的 TDD 两阶段流程（测试跑红→实现跑绿→report 待测试）、批量开发/批量完善、构建→版本计划→发布流水线、待人工决策（hold）闭环。
- **如何启动 Status Board 服务**：`node <插件>/scripts/atb.mjs init` 初始化；`node <插件>/scripts/server.mjs` 起本地服务，浏览器打开 `http://127.0.0.1:8888`；可选 `atb cli install` 安装终端命令。
- **如何启动 Electron 桌面 App**：`npm install` 后 `npm run app`；打包分发 `npm run dist`（mac dmg / win nsis）。
- **双语**：页面主体中文，附英文摘要区（页内锚点导航），满足项目双语资源要求。
- **版本标识**：页面正文（含页脚）包含当前发行版本号字符串 **1.0.0**——发布回验会 GET 首页并检查该版本号（`webapp-verify` 阶段 `body.includes(run.version)`）。

**交互行为**：页面为纯静态展示型，无表单、无网络请求；顶部「English」锚点平滑滚动到英文摘要区；代码块右上角提供「复制」按钮（内联 JS，优先 `navigator.clipboard`，非安全上下文或旧浏览器降级 `execCommand('copy')`）。

**状态反馈**：复制成功后按钮短暂显示「已复制」（约 1.5 秒后还原为「复制」）；复制失败（剪贴板不可用 / 权限被拒）时降级为自动选中文本并弹出提示，引导手动 ⌘C / Ctrl+C；深浅色默认跟随系统 `prefers-color-scheme`（演示页另提供手动主题与视口切换，便于验收各状态）。
