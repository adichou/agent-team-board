## 描述

Status Board 看板卡片上的条目单号（REQ-/BUG-YYYYMMDD-NNN）支持一键复制：点击/点按单号即复制纯单号到剪贴板，并给出「已复制」类即时反馈。目的：单号是 /dev、atb 命令与沟通中的高频输入，当前需要手动框选小号字体文本，体验差且易选错。

## 验收标准

- [ ] 看板卡片上的单号点击/点按即复制纯单号（如 `REQ-20260830-005`，无多余空白/换行），实现优先复用浏览器原生 Clipboard API（127.0.0.1 属安全上下文），不引入第三方库。
- [ ] 复制成功有即时可见反馈（单号处短暂变为「已复制」或等效提示），失败时提示可手动框选。
- [ ] 复制交互不干扰卡片既有行为：拖拽换列、状态按钮点击、2 秒轮询刷新后反馈状态不残留。
- [ ] 单号可复制的位置覆盖所有展示单号的卡片（需求列、Bug 卡片、弹层详情若含单号）。
- [ ] 深色/浅色模式下反馈样式均清晰可读。
- [ ] File Board 与状态流转等既有功能不受影响。
