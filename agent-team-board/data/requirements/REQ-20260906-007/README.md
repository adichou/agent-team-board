# REQ-20260906-007 文件看板的目录树要改成横幅呈现，参考 codex 的文件右侧面板

- 状态：in-progress（Agent 已认领）
- 创建：2026-09-06T03:35:21.169Z

## 描述

文件看板当前是「左侧 Wunderbaum 目录树 + 竖向分隔条 + 右侧文件内容」的布局。
层级深时树纵向占用过高、层级感过深（见 2026-09-06 用户反馈与 F13 缩进压缩），且与
codex 桌面端文件面板的浏览习惯不一致。

参考 codex 的文件右侧面板，把目录树改为**横幅（banner）呈现**：

- 顶部为路径面包屑（项目根 › 一级目录 › 二级目录 …），每段可点击回跳；
- 面包屑下方为「层级条带堆栈」：每进入一层目录，就在下方追加一条横向可滚动的
  条带，条带内以 chip 形式平铺该目录的直接子项（目录在前、文件在后，沿用
  /api/fs 的排序）；点击目录 chip 进入下一层，点击文件 chip 在下方查看内容；
- 回跳面包屑或点击更浅层的目录 chip 时，其下更深的所有条带移除；
- 文件内容区占满剩余高度（原竖向分隔条随树一起退役）。

## 验收标准

- [ ] 文件看板不再渲染 Wunderbaum 目录树与竖向分隔条；页面不再加载
      wunderbaum.umd.min.js / wunderbaum.css / splitter.js。
- [ ] 顶部面包屑显示当前层级路径，每段可点击回跳，回跳后更深层条带移除。
- [ ] 每层目录渲染为一条横向滚动条带，chip 平铺直接子项；目录 chip 可进入下一层，
      文件 chip 打开文件并高亮选中态。
- [ ] 保持默认展开到 `docs/agent-team-board`（与旧树行为一致）。
- [ ] 新增一层条带时自动滚入视野；横幅区域多层堆叠时可纵向滚动且不挤压文件内容区。
- [ ] 亮/暗双主题下 chip、条带、面包屑均取主题变量配色；滚动条主题适配保留。
- [ ] 层栈状态机抽为独立纯逻辑模块（banner.js，UMD 双通道），Node 下可单测。
- [ ] 旧树/分隔条相关契约测试同步退役（file-board F10/F11/F13、file-splitter S5–S7
      改为退役守卫），全量 `npm test` 通过。
