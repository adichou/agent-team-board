# REQ-20260911-005 支持英文国际化资源

- 状态：in-progress（开发中 · zcode-i18n-en，Agent 已上报，待人工测试）
- 创建：2026-09-11T07:59:15.151Z

## 描述

Status Board 界面全量支持英文文案，并按系统语言自动切换中/英文。界面布局、交互流程、数据与状态机零改动——本需求只做「文案层」国际化。

### 界面布局（现状保持不变）

- 顶栏：产品标题 + 模块页签（需求 / 任务 / 设置）+ 项目切换器 + 管理项目 / 全局 / 待处理 / 快捷键 / ＋新建按钮；**新增语言切换按钮**（位于「快捷键 ?」左侧，图标按钮，中文界面显示 `EN`、英文界面显示 `中`）。
- 第三行定位组：模块副标题 + 列表排序下拉 + 模块搜索框（范围标签 + 占位符 + 清除按钮）。
- 需求视图：左缘状态筛选栏（待接受/已接受/已计划/开发中/待测试/已完成，带计数）+ 列表工具栏（全选/全不选/批量动作/档位快捷入口）+ 卡片列表 + 右侧详情抽屉（文档页签、状态流转按钮、历史）。
- 任务视图：批量完善 / 批量开发面板；设置视图：批量任务分区。
- 侧拉面板：新建条目、编辑条目、项目管理；居中弹窗：快捷键帮助；全局任务面板；toast 提示与确认弹窗。

### 交互行为

1. **自动切换**：首次打开按系统语言检测——`navigator.languages` 含任意 `en-*` 项即显示英文，否则默认中文（保持现状）。
2. **手动切换**：点击顶栏语言按钮在中/英文间即时切换；选择记忆在 `localStorage`，手动选择优先于自动检测，后续打开沿用。
3. **即时生效**：切换不需要刷新；界面已渲染文案与之后 2 秒轮询刷新出的动态内容（卡片、计数、状态标签、toast）均按当前语言渲染。
4. **无障碍同步**：切换时 `<html lang>` 与文档标题同步更新，便于读屏与浏览器翻译识别。

### 状态反馈

- 语言按钮常显当前可切换到的目标语言（见上文），悬浮提示说明当前语言与点击效果。
- 词典未收录的文案**优雅降级**：保持原文显示，不出现空白、错位或占位符残留。
- 含数字的动态文案（如「已选 3 项」「待接受 7」）英文下按英文语序输出（如 `7 pending`、`3 selected`）。

## 范围与边界

- **覆盖**：当前可见界面全部文案——需求 / 任务 / 设置三模块、顶栏、第三行定位组、新建 / 编辑 / 项目管理 / 全局任务面板、快捷键帮助、toast 与确认弹窗；含悬浮提示（title）与无障碍标签（aria-label / placeholder）。
- **不翻译**：用户数据（条目标题、描述、文档 markdown 内容）保持原文；只翻界面文案。
- **暂态隐藏模块**（讨论 / 文件 / 营销 / 发布，见 REQ-20260911-002）：同一词典机制天然就绪，恢复上线时按同一词典补录文案（边界，恢复条目内完成）。
- 服务端与 CLI 输出（atb 终端命令）不在本需求范围（终端受众为 Agent/开发者，保持中文）。

## 验收标准

- [ ] 系统语言为 `en-*` 的浏览器首次打开 → 可见界面全英文（含动态轮询内容）
- [ ] 系统语言非英文 → 默认中文，行为与现状完全一致（零回归）
- [ ] 顶栏语言按钮点击即时切换中/英文，选择记忆，手动选择优先于自动检测
- [ ] 可见面文案（按钮 / 标签 / 提示 / 占位符 / 悬浮提示 / aria-label）均有英文对应；源码新增中文文案有测试卡点（必须同步词典或显式豁免）
- [ ] 含数字的动态文案在英文下语序 / 复数正确
- [ ] 切换语言后，2 秒轮询刷新出的新内容仍为当前语言
- [ ] 切换时 `<html lang>` 与文档标题同步更新
- [ ] 词典未收录文案优雅降级（原文显示，不空白不错位）
