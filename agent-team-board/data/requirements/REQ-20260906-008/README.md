# REQ-20260906-008 需求和文件切换栏移到智能体团队看板右侧，使用切换样式

- 状态：accepted（批次实施：batch-20260906-002 / run-20260906-005）
- 创建：2026-09-06T03:37:14.692Z

## 描述

Status Board（`scripts/web/`）桌面端顶栏现状：`品牌区（左）—「需求 / 文件」视图切换栏（中）— 操作区（右：项目选择器 + 新建按钮）`，
切换栏悬在顶栏中部，与右侧操作控件割裂。本需求把它移到顶栏右侧，并入右侧操作组，并保持「切换控件（分段切换）」样式。

**界面布局**：顶栏左侧只保留品牌区；右侧为 `视图切换栏（需求 / 文件）＋ 项目选择器 ＋ ＋新建`，
即 `nav.view-tabs` 移入 `.top-actions` 首位（DOM 上位于 `#projectSel` 之前）。

**交互行为**：点击「需求 / 文件」tab 切换看板视图与文件视图，逻辑不变（`setView`：active 同步、
`?view=` 深链同步、文件视图懒初始化均保留）。

**状态反馈**：沿用 REQ-20260906-001 的分段切换控件样式——淡靛蓝底槽、胶囊 tab、激活项靛蓝填充白字、
未激活项透明底靛蓝字；本需求为 tab 增加平滑过渡动画，切换时有明确的视觉反馈。

**窄屏（≤1020px）不回归**：切换栏固定左缘竖排的既有设计（REQ-20260903-002 v6）与 `--viewrail-h`
让位机制保持不变。

## 验收标准

- [ ] 桌面端（>1020px）「需求 / 文件」切换栏位于顶栏右侧 `.top-actions` 内（`#projectSel` 之前），顶栏中部不再有切换栏
- [ ] 保持分段切换样式：`.view-tabs` 淡靛蓝底槽（`--viewrail-accent-soft`）、`.view-tab` 胶囊（99px 圆角）、激活态 `--viewrail-accent` 填充白字
- [ ] tab 切换有平滑过渡（`transition`），激活态切换不跳变
- [ ] 窄屏 ≤1020px 不回归：切换栏仍 fixed 左缘竖排、`--viewrail-h` 机制保留、看板列 tab 条让位正常
- [ ] 视图切换交互不变：点击切换、active 同步、`?view=files` 深链
- [ ] 新增契约测试 `scripts/tests/view-tabs-right.test.mjs` 全部通过；既有相关测试（view-tabs-style / topbar-overflow / portrait-board 等）不回归
