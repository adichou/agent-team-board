# 设计 — REQ-20260929-001

## 方案

已完成且未占用的候选均可选择，创建和追加共用面板逻辑。无提交行显示「暂无关联提交（仍可纳入版本）」；全选包含这些条目，提交数量为零，不展开提交清单。中英文同步。

数据落盘固定为 `commits: []`，无首个提交时不写 `commit` 别名；旧 `commit` 单值读取继续兼容。显式传入非法数组元素或非数组 commits 仍拒绝。版本仍至少包含一个条目。

Git 合并按实际提交展开，因此空提交不产生 cherry-pick；finishMerge 对空提交条目记完成，避免没有逐提交结果被误判失败。发布文档按版本条目装配，保留空提交条目；关联列表与名称描述提示词显示「暂无关联提交」。

## 选型与边界

修改现有归一、面板和合并结果聚合逻辑即可；引入外部库的成本高于本次局部实现，不新增依赖。已完成过滤、跨版本占用、发布确认锁均保持。

## 实施验证

新增真实临时仓库测试覆盖空提交创建、追加、非法形态、旧字段、空重放与合并状态；旧 UI 回归更新为全选包含空提交。先验证空数组创建失败及合并结果错误为 failed，再实现跑绿。真实老项目数据不作变更，以同构临时仓库复现并验证。
