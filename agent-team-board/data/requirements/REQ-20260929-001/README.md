# REQ-20260929-001 版本计划关联放宽：已完成条目暂无关联提交也可纳入版本

## 描述

版本计划「新建版本 / 关联条目」面板中，暂无关联提交的已完成（done）条目复选框被置灰并标注「暂无关联提交（先完成开发提交）」，无法纳入版本。需求：只要条目为 done，无论有无关联提交均可勾选纳入版本计划；条目关联提交允许为空（0 个提交），后续合并 / 发布流程对空提交条目按无提交贡献处理。动机：兼容老项目没有提交记录的条目（如经迁移或人工确认完成的存量单）。
