# REQ-20260830-002 File Board：浏览项目相关文件夹并支持语法高亮

- 状态：submitted（待人工接受）
- 创建：2026-08-29T16:26:55.516Z

## 描述

在看板体系内新增 File Board 页面：浏览当前项目相关文件夹（docs/agent-team-board 等）中的文件，查看内容并支持语法高亮。约束：不自己发明轮子，前端高亮/文件树等能力优先复用成熟开源库（按现有 vendor 模式引入，如 marked.min.js），选型需上网调研后在 design.md 记录对比结论。

## 验收标准

- [ ] Status Board 新增 File Board 视图（与现有看板同服务、同端口，无需额外启动步骤）。
- [ ] 以树形结构浏览当前项目相关文件夹：默认打开 `docs/agent-team-board/`，可导航到项目根下其他目录；`node_modules/`、`.git/` 等不做展开。
- [ ] 点击文件可在页面内查看内容，按扩展名/内容自动做语法高亮（至少覆盖 md / js / mjs / json / css / html / sh）。
- [ ] 文件树与语法高亮均复用成熟开源库（vendor 引入），不手写解析/高亮算法；选型依据见 design.md。
- [ ] 服务端文件读取仅限项目根目录内（防路径穿越），且服务仍只绑定 127.0.0.1。
- [ ] 二进制/超大文件（>1MB）不渲染内容，给出明确提示而非报错。
- [ ] 现有 Status Board 功能（看板、状态流转）不受影响。
