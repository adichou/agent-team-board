演示要点

  • 三类批量任务（批量开发 / 批量完善 / 批量 Commit）启动区的「开发人员」输入框整体删除；
  • 「启动」仍为创建任务 + 复制主调度提示词，流程不变，只是不再有开发人员这一步；
  • 创建成功后的展示侧（运行面板状态行 / 排队批次行 / 全局任务行）不再出现「开发人员」；提示词不再含会话命名指令；
  • 状态反馈保持既有口径：无候选启动禁用并说明原因、加载中、加载失败可重试；
  • 现状形态下输入的开发人员会「记忆」（模拟 localStorage atb.batch.dev），删除后该链路不存在。

操作日志

    本演示为纯前端静态模拟（单文件、无外网依赖、无构建），不访问项目账本与网络；布局与文案按 scripts/web/app.js 现状复刻，仅用于需求评审。
