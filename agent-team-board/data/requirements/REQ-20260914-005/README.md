本需求改回界面控件行为并做文案微调（去掉「开始」），界面结构本身不变：

- 界面布局：沿用看板「需求」视图——一级导航（需求 / 任务 / 设置）与轮询指示「●」；第四行档位筛选条（待接受 / 已接受 / 已计划 / 开发中 / 待测试 / 已完成，带计数）；第三行列表头工具条，左侧全选 / 全不选与批量动作组，右侧快捷入口按钮（已接受档「▶ AI 分析」/ 已计划档「▶ AI 开发」，其余档隐藏）；下方条目列表行。
