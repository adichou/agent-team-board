### 目标与范围

分类标签已经展示各档数量，移除列表头重复的「N 个条目」；将全选、全不选、已选数量与当前档批量操作上移，与排序放入同一个工具栏。调整适用于待接受、已接受、已计划、开发中、待测试、已完成所有分类。

现有依据：`scripts/web/index.html` 的 reqCaption 当前分为 caption-info 与 selectRow 两行；`scripts/web/app.js` 的 syncAcceptance 按档位显示选择和快捷入口。此次仅改变布局和重复信息展示，保持现有排序、按档隔离选择、批量操作与导航语义。

### 界面布局

- 顶部分类标签保留名称和数量。列表头左起为排序、全选、全不选、已选数量、批量动作；已接受「开始完善」、已计划「开始开发」快捷入口保留在同一工具栏，空间足够时靠右。
- 宽度足够时工具栏单行排列，取消固定的第二行选择区域及多余空白。空间不足时按完整控件/动作组自然换行，不能重叠、裁切或把按钮文字挤断；分类标签也应可换行或横向滚动，确保六档均可到达。
- 开发中、待测试、已完成不显示选择区，也不留空行。空选择保留全选/全不选，已选数量与批量动作隐藏；出现首项选择时在可容纳的宽度下不增加工具栏行数。
- 删除普通重复总数时，保留已完成默认截断的必要提示（显示范围、总量与搜索更早条目的说明）；搜索命中数若与分类总数不同，应以明确的搜索结果提示承载，不能把分类总数误称为命中数。

### 交互行为

- 排序沿用最新更新、最早更新、最新创建、最早创建、单号及现有偏好记忆。排序或切档不能把按钮移出可操作区域。
- 全选仅勾选当前分类与搜索范围内可操作项；全不选清除当前档选择。切档后显示该档选择数量和操作，不混用其他档位的选择。
- 待接受显示「接受所选」；已接受显示「移入计划」「驳回待接受」；已计划显示「移出计划」。快捷入口只导航到对应任务面板，与勾选数量无关。

### 状态反馈

- 正常：复选框与已选数量即时同步，批量动作仅在选择非零时显示。
- 空列表：显示当前分类无条目或无搜索结果；全选禁用，零选择时全不选禁用，排序仍可见。
- 加载/批量处理中：提供可见进度文案并禁用可能重复提交的选择与批量操作控件，保持工具栏布局稳定。
- 失败：保留可读错误与失败条目标识，提供恢复或重试途径；沿用既有部分成功处理，不因布局调整吞掉反馈或清除未处理选择。
