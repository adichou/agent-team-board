## 描述

在营销概览提供“全部项目”入口，打开独立只读总览面板，不更改当前项目。仅遍历已登记项目；未初始化营销的项目显示未建立档案，不能读时保留该行并提示原因。

每行展示项目、产品阶段、主指标及近30天值、主要渠道、实际投入（工时与费用分开）、最新复盘日期、下一步行动及数据新鲜度。不同项目使用不同主指标时显示指标名称与单位，不用单一数值排名，不跨币种或异质指标汇总。关注指标仍按来源分开。

支持项目名称、阶段和是否有下一步筛选；按最新复盘时间排序，未知值排末尾。点击项目名称跳到对应营销页；进入前处理当前未保存编辑。聚合结果不是新事实源，不回写项目指标。

## 界面展示

布局：沿用现有右侧面板模式，顶部标题、关闭和搜索，中部筛选，主体项目列表；窄屏显示可展开卡片。
交互：打开与关闭保持原项目上下文；点击项目显式导航；刷新聚合仅重读文件。
反馈：无项目、无营销档案、部分读取失败和全部失败分别显示；可读项目仍正常展示，显示最近成功刷新时间。

```text
营销概览 [全部项目]
| 全部项目增长                     [关闭] |
| [搜项目] [阶段] [有下一步]             |
| A | 验证 | 激活12 | 下一步：演示       |
| B | 上线 | 订阅0  | 下一步：访谈       |
| C | 未建立档案                        |
```

当前为创建阶段线框；进入完善阶段后，本条目需补单文件、可交互、无外网依赖的 ui-demo.html，并在此链接。

## 验收标准

- [ ] 读取已登记项目且区分同名不同路径；无档案不自动初始化。
- [ ] 主指标名称、单位、来源及周期可见；异质指标和不同币种不求总数或排名。
- [ ] 某项目损坏或失联不阻断其他项目，错误行和最后更新时间可见。
- [ ] 打开关闭不改变当前项目，点击项目可正确导航，未保存内容受到保护。
