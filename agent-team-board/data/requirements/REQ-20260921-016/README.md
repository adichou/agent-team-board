# REQ-20260921-016 版本计划列表中的操作按钮优化

- 状态：submitted（待人工接受）
- 创建：2026-09-21T10:56:25.104Z

## 描述

1、AI 完善按钮去掉，在详情页面的版本计划页面中增加 AI 完善按钮，在编辑按钮左边。
2、合并入 main、创建并预检、查看发布记录按钮去掉，因为详情页面已经有了
3、删除按钮移至版本计划标题处的右侧对齐。

### 目标与范围

精简发布模块左侧版本计划列表，把需要阅读上下文的操作集中到右侧详情。列表每张版本计划卡片移除「AI 完善」「合并入 main」（含失败时的重试入口）「创建并预检」「查看发布记录」四个按钮；删除仍属于各自版本卡片，迁至该卡片标题行最右侧。这里的标题指各版本名称所在行，不是整个列表栏目标题，不引入批量删除。

右侧详情的「版本计划」步骤，在描述块头部右侧显示「AI 完善」「编辑」，前者紧邻后者左边。合并入口仍在「合并入 main」步骤，创建并预检与发布记录仍在「正式发布」步骤。仅调整入口，不增加自动执行 AI、合并或发布的行为。

### 项目事实与行为边界

已核对 `scripts/web/build.js` 的 `renderVersionList`、`renderDetail` 描述块、`openAnswerModal`、`renderDeleteConfirm` 及详情五步导航：列表现有五类操作，详情已有编辑、合并与正式发布内容。AI 完善现有流程是复制提示词、粘贴回答、解析及应用回填，入口迁移后复用该流程并绑定当前详情版本。

AI 完善在合并中或已推送正式发布时禁用并显示原因；草稿、合并失败、已合并但未推送时保持可用。编辑保持其原有合并中禁用规则，不因 AI 完善禁用而一并改变。删除沿用合并中或全局正在合并时禁用的规则，以及现有不可撤销确认框；迁移按钮不能直接删除、误选其他版本或触发卡片选择事件。具体像素尺寸及窄屏断点待确认，开发时沿用项目现有样式与响应式约束即可，不影响上述布局语义。

### 界面布局

- 左栏保留搜索、版本选择、标题、状态、计划号及关联数量等信息；标题和状态在左，弱化危险样式的「删除」在右，移除原卡片底部操作行留下的空白。
- 右栏保留五步导航。「版本计划」步骤描述区头部左侧是「描述」，右侧从左到右为「AI 完善」「编辑」。进入编辑时沿用现有就地编辑表单与保存/取消行为，退出后恢复两个入口。
- 长版本名允许换行或截断并提供完整名称提示；删除按钮可见且不被挤出卡片；窄屏按钮组可整体换行，仍保持 AI 完善位于编辑左侧。

### 交互行为与状态反馈

点击卡片选择对应版本并查看详情；切换版本后 AI 完善必须针对新选中版本。点击删除仅打开该卡片版本的确认框，取消保留原选中版本与数据；确认成功后列表与详情同步更新，失败保留卡片并展示可重试错误，提交期间禁止重复操作。

正常态按上述布局展示；无版本或搜索无匹配时显示相应空态且无悬空 AI 完善/编辑/删除入口；未选择版本时详情显示选择提示。加载时显示加载反馈，不允许操作尚未取得的数据；读取失败显示错误与重试，不能沿用错误版本的可操作按钮。AI 弹窗沿用复制失败、解析失败、应用中及应用结果反馈；禁用原因可通过文字说明或现有提示机制获知。保持中英文文案同步与键盘可访问性。

## 验收标准

- [ ] 每张版本卡片不再显示 AI 完善、合并/重试合并、创建并预检、查看发布记录，原操作区无多余留白。
- [ ] 每张卡片删除按钮位于自身标题行右侧，长名称和窄屏下仍可识别和操作，不出现全局删除歧义。
- [ ] 详情「版本计划」描述头部存在 AI 完善，紧邻编辑左侧；切换版本后弹窗中的版本号和回填对象正确，其他步骤不重复增加该入口。
- [ ] AI 完善完整保留复制、粘贴、解析、编辑回填及应用反馈；合并中和已推送禁用原因明确，已合并未推送仍可用；编辑原有规则不变。
- [ ] 删除仍需确认并正确显示目标版本；点击不误触卡片选中，取消无变化，成功刷新，失败可重试，忙碌时不可重复提交，原禁用规则仍有效。
- [ ] 详情合并、正式发布步骤仍可到达现有合并、创建并预检和发布记录功能，门禁与动作含义不变。
- [ ] 正常、空列表/搜索无结果、未选择、加载、失败状态反馈完整，无失效版本操作入口；中英文同步，键盘可操作且焦点可见。
- [ ] README 的界面展示链接可打开本目录 ui-demo.html，断网可运行并切换状态、选择版本、打开 AI/编辑及删除确认；不调用真实发布或删除接口。
