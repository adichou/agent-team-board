# 设计 — REQ-20260910-021 营销与增长：手工指标、CSV 导入与效果复盘

> 由 Agent 在 /dev 开发前补充，人可随时批注。

## 背景

依赖 REQ-20260910-019（marketing-store 骨架、定价版本）与 REQ-20260910-020（渠道 / 实验 / 行动档案）已交付。本条交付第一版 P0 第三块：效果页（指标字典、手工观察与修订、CSV 导入、聚合口径、派生转化率、复盘快照）。

## 方案

### 数据契约（<dataDir>/marketing/ 内，与 019/020 同域）

```text
metrics/definitions.json      指标字典：首次读取播种默认（五分类 / 四种类），自定义追加不覆盖
metrics/observations/obs-*.json  观察记录：值 + 单位币种 + 周期 + 归属 + 来源 + 时区 + revision + 修订历史
reviews/rev-*.json            复盘：观察期 + 目标 / 实际 + 结论 + 下一步 + 固定观察快照
```

- 相对总体规划（`metrics/observations/` 按周期分片、`experiments/<id>/reviews/`）的调整：观察以单文件一条记录存储（分片的边界语义由观察键承担）；复盘收敛到 `marketing/reviews/` 平铺（experiments 为单文件实体，不引入同名目录），快照内嵌于复盘文件。schemaVersion / 稳定 ID（`obs-` / `rev-` + 4 字节 hex）/ createdAt / updatedAt / revision 齐全。
- 损坏文件只读占位（`corrupt: true`）、写拒绝；definitions.json 损坏抛错不静默重建。

### 观察键与修订语义

- 观察键 = 指标 + 起止日期 + 渠道 / 实验归属（**来源不入键**）：同键同值幂等（重复导入无变化、来源不静默改写）；同键不同值为冲突——手工录入走修订（必填修改理由，revision+1 入历史，保留旧值），CSV 导入逐行选择修订（需理由）或跳过，不静默相加。
- 值 `null` = 未知、`0` = 真实零（均可录入）；金额类指标（`money: true`）必须带币种。
- CSV：表头别名自动映射 + 人工映射覆盖（必填：开始 / 结束 / 指标 / 值）；预览逐行校验（日期日历合法、数字 ≥0、指标存在、归属存在、文件内同键去重），错误行带物理行号，存在错误原子拒绝（零写入）；支持带引号的简单 CSV；模板经 `GET /api/marketing/import/template`（UTF-8 text/csv）。

### 聚合口径（readEffect，第一版只对同口径、可加的互斥数据求和）

- 存量（stock）：同归属取最新周期，不跨日期相加，跨归属分开呈现。
- 关注类（following）：同归属跨周期求和，跨平台分开呈现（禁止伪去重总数）。
- 独立人数（unique）：按去重口径按「归属 + 周期」分开呈现，不跨范围相加。
- 期间增量 / 事件次数：同单位（币种）跨互斥周期与归属求和；不同币种 / 单位分开呈现，不默认换算。
- 派生转化率（v1：激活率 = 激活 / 访客）：仅同周期 + 同归属配对才计算；分母为零 / 分母未录入 / 口径不一致分别返回「不可计算」及原因。

### 复盘快照

- createReview 校验（周期日历合法、结论必填、目标 / 实际成对，实验存在）；保存时捕获周期内观察的当前值与修订号内嵌 `snapshot`；后续观察修订不改变已存快照。观察期内无数据且未勾选「数据不足」→ 拒绝；勾选后可保存（不伪造目标 / 实际与改善幅度）。

### 接口与前端

- `GET /api/marketing/effect?from&to&channel&experiment`、`GET /api/marketing/import/template`、`POST /api/marketing/{metric,observation,import/preview,import/commit,review}`；字段校验失败 400 `fields` 定位（沿用 boardPost 分流）。
- marketing.js「效果与复盘」页签启用（替换占位）：工具栏筛选 + 分类指标卡（未录入 / 真实零徽标 / 数值 / 分开呈现 + 来源与更新时间）+ 派生区 + 指标详情（定义 / 原始记录 / 修订历史含理由 / 趋势柱）+ 原始观察表 + 复盘卡（依据快照固定标注）；弹层：录入 / 修订、CSV 四步向导（粘贴 → 字段映射 → 预览校验 → 结果）、新建复盘（数据不足勾选）、自定义指标。浏览态进刷新快照；弹层填写计入未保存守卫；沿用宿主深浅色与 Esc 关闭。

## 开源选型（REQ-20260909-015）

未引入外部依赖：CSV 解析（带引号单行级）、日历校验、按口径聚合与快照均为 <100 行自有逻辑，成熟库（如 csv-parse / papaparse）的引入成本高于自研，且无传染许可风险。未使用开源库，故不创建 licenses.md。

## 风险与边界

- CSV 原子提交为「先全量校验后逐文件写入」：校验失败零写入；进程在写入中途崩溃的极端场景可能留部分文件（与既有渠道 / 行动多文件写一致），由 revision / 修订历史与重复导入幂等兜底。
- 派生指标第一版仅内置激活率一对；自定义派生、多期趋势去重口径留给后续需求。
- 关注类跨周期求和按「互斥时间片」假设（同一账号新增只计一次的精确去重需跨平台身份，第一版不做）。
