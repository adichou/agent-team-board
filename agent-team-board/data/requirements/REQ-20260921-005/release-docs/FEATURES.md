# 功能特性（FEATURES）

agent-team-board 当前版本：**20260920-001 全功能基线版**（版本计划 BLD-20260920-001，2026-09-20）。本页列出该版本已交付的用户能力与使用入口；版本变化历史见 [CHANGELOG.md](./CHANGELOG.md)。

## 总览：三栏协作体系

| 栏 | 载体 | 进入方式 |
| ---- | ---- | ---- |
| Project Board | ZCode 自带项目 / 会话列表 | 无需安装，文件为事实源 |
| Discussion Board | 聊天窗口 + 命令 | `/req` `/bug` `/dev` `/board` |
| Status Board | 本地网页看板（默认端口 8888） | `node scripts/server.mjs`；桌面端 `npm run app` 自动拉起 |

## 需求与缺陷管理

- 用 `/req` `/bug` 或看板表单创建需求 / Bug（支持截图、讨论单），创建后自动定位到新条目。
- 条目状态由人机分工驱动：Agent 只能创建、认领、上报；**接受、移入计划、确认完成仅限人工**（看板按钮或终端 `atb status`），越权操作被状态守卫确定性拦截。
- 待接受 / 已接受列表支持批量接受、批量移入计划、驳回、删除、修改标题与描述；操作免二次确认且可撤销。
- 详情页页签式布局（说明 / 设计 / 测试用例等），支持上一条 / 下一条快速浏览。
- 列表排序、全局搜索（需求 / Bug / 讨论与文档）、已完成默认最新 100 项。
- 单号一键复制；条目截图在详情页展示、双击放大。

## AI 分析与 AI 开发（任务模块）

- **AI 分析**：对已接受条目批量补全说明文档与可交互 UI Demo（单文件 html，浏览器直接打开）；完善后可自动转入计划（默认手动，可配置）。
- **AI 开发**：从已计划队列实时取单，按 TDD 流程实施；Zcode（轻量主调度 + 每单一个子代理）与 Codex（后台独立会话）双通道，提示词 Agent 无关。
- 每单开发到待测试由系统自动收口提交到 dev 分支，条目上可查提交号；执行记录支持查看、续跑与终止。
- 全局任务看板汇总当前在执行的批量任务状态。

## 人工介入

- **待人工决策（hold）**：Agent 实施受阻时声明问题清单，条目持久呈现在看板「待人工确认」区；人工逐项作答（可存草稿）后一键复工，条目回队列重新取单。
- **挂起确认**：自动提交不完整时挂起条目并暂停队列；人工在面板核对提交归属与文件差异后确认继续，队列恢复。

## 开放式讨论

- 讨论单创建（富文本 + 截图）、批量 / 单条派单给 zcode 或 codex 回复。
- 讨论逐轮持久化、跨会话续聊、文档资产展示；纪要一键生成需求或 Bug。
- 需求 / Bug 的说明、设计、测试用例文档右键「讨论」，生成带文档上下文的提示词，可直接去新建对应 Agent 会话粘贴。

## 构建与版本发布

- **构建模块**（需求与任务模块之间）：BLD 版本计划管理——关联已完成条目与提交、AI 完善版本名称与描述（可修改后保存）、版本删除、合并入 main（逐条 `--no-ff`，`--first-parent` 观感）。
- **分支浏览**：本地 / 远端分支列表、和远端同步（先 fetch 后 push）、当前分支提交记录搜索；main 缺失时兼容 master。
- **产品发布（PREL）**：从已合并版本计划发起跨仓库产品发布（源码同步 → 官网构建 → 核验 → 材料 → 部署 → 回验）并跟踪结果；官网目标支持 Vite + Vue 站点。
- 版本提示词与回答回填：条目 / 提交支持全选，提示词可复制或一键去新建对应 Agent 会话。

## Status Board 看板

- 零依赖 Node 服务，默认端口 8888（`ATB_PORT` 覆盖）；单服务多项目，`?project=<项目根绝对路径>` 切换数据源。
- 2 秒轮询实时刷新；深浅色主题；看板快捷键；项目管理（多项目登记、失效目录检测一键移出）。
- API 带 Origin / Host 校验，防跨站代替人工操作（CSRF）。

## 桌面端（Electron）

- `npm run app` 启动桌面壳（自动拉起 Status Board 服务）；`npm run dist` 打包 macOS dmg / Windows nsis。
- 标题栏拖动、Cmd+R 刷新后回到刷新前界面、窗口交通灯避让。

## CLI（atb）

- `node scripts/atb.mjs <子命令>`；`atb cli install` 后终端直接敲 `atb …`。
- 常用：`init` 初始化项目、`new req|bug` 创建、`list / show` 查询、`claim / report` 认领与上报、`batch / refine` 批量任务、`hold` 待人工决策、`commit log|which` 提交索引、`migrate` 旧布局迁移、`rebuild` 从 git 历史重建状态、`pack` 插件分发打包。

## 工程与质量

- 运行时零 npm 依赖（桌面打包链除外）；`npm test` 全量回归（scripts/tests/ 聚合执行，任一失败即非零退出）。
- 用户数据（`agent-team-board/data/`，进 git）与应用数据（`agent-team-board/runtime/`，本地留存）物理分离；单设备使用口径。
- 中英文界面资源成对维护；开源引入遵循友好 License 白名单并在条目目录登记 licenses.md。
