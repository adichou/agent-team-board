# 更新日志（CHANGELOG）

记录 agent-team-board 各版本的发布内容。条目级明细（需求 / 缺陷单据、设计、测试报告）保存在看板用户数据 `agent-team-board/data/`，随版本进 git；本文件只做版本级归纳。功能清单见 [FEATURES.md](./FEATURES.md)。

## [20260920-001] 全功能基线版：需求看板 · AI 分析和开发 · 版本发布（2026-09-20）

首个全功能基线版本：整合 2026-08-29 至 2026-09-20 的 339 项已交付条目（需求 164、缺陷 175，90 个提交），版本计划 BLD-20260920-001。

### 需求看板（条目管理）

- 条目状态分类定稿：待接受 / 已接受 / 已计划 / 开发中 / 待测试 / 已完成；接受、移入计划、确认完成等人工专属流转由状态守卫确定性拦截 Agent 越权。
- 新增批量接受、批量移入计划、驳回回待接受、待接受删除、修改标题与描述、创建并接受；操作免二次确认并提供撤销。
- 详情页升级为页签式布局，支持上一条 / 下一条快速浏览；列表与详情 1:2 分栏。
- 新增列表排序、全局搜索（需求 / Bug / 讨论与文档）、已完成列表默认最新 100 项（其余经搜索获取）。
- 条目描述与讨论支持截图（详情展示、双击放大）；单号一键复制按钮。
- 看板页面自适应铺满与横屏布局重设计；新增项目管理（多项目、失效目录检测一键移出）、看板快捷键、会话所在项目自动切换看板。

### 任务模块（AI 分析 / AI 开发）

- 「批量完善 / 批量开发」演进为 **AI 分析 / AI 开发**：去掉批次概念，从启动到结束实时执行当前任务队列；新接受 / 新置计划条目自动入队。
- 执行通道：Zcode 轻量主调度（每单一个子代理、文件化回执）与 Codex 后台自动派发（独立会话、日志追踪与进程回收）；提示词统一为 Agent 无关的通用描述，模型配置与主调度会话一致。
- 新增待人工决策（hold）闭环：受阻条目持久呈现、人工补决策、复工回队列；新增挂起确认闭环：自动提交不完整时挂起条目并暂停队列，人工确认后恢复。
- 每单开发到待测试由系统自动收口提交到 dev（手动 /dev 与批量同口径）；执行记录、续跑、终止口径与全局任务看板。
- AI 分析（需求完善）产出说明文档与可交互 UI Demo（单文件 html），支持完善后自动转入计划（默认手动，可配置）。

### 讨论模块

- Oncall 咨询看板演进为**开放式讨论**：讨论单创建、富文本与截图、批量 / 单条派单回复（zcode 与 codex）。
- 讨论逐轮持久化、文档资产展示、跨会话续聊；纪要一键生成需求或 Bug。
- 需求 / Bug 文档（说明、设计、测试用例）右键「讨论」生成带上下文的提示词；支持就单一需求与 Agent 讨论。

### 构建与发布

- 新增**构建模块**（位于需求与任务模块之间）：BLD 版本计划管理、关联已完成条目与提交（去重、全选、已纳入版本不再重复出现）、AI 完善版本信息（可修改后保存）、版本删除、合并入 main。
- 合并策略定案：不采用 rebase，逐条 `--no-ff` 合并，main 观感用 `--first-parent`；人工确认完成与版本合并后自动提交管理文件，失败明确提示可重试。
- 新增分支浏览：分支列表、和远端同步（先 fetch 后 push）、当前分支提交记录搜索、main 缺失时兼容 master。
- 产品发布流水线（PREL 六阶段）：从已合并版本计划发起跨仓库发布并跟踪结果；官网目标适配 Vite + Vue 新站点架构；新增仓库根 `index.html` Web App 静态落地页。
- 构建发布与旧发布模块解耦（独立执行与事实源）；构建和发布流程整体整改。

### 桌面端（Electron）

- 新增 Electron 桌面壳（内嵌 Status Board 服务）：窗口交通灯避让、标题栏拖动、Cmd+R 刷新后回到刷新前界面、app 布局优化。
- 支持 electron-builder 打包 macOS dmg / Windows nsis。

### 国际化

- 新增英文界面资源：文案集中词典 + 运行时 DOM 翻译；中英同步列为硬性质量基线，AI 开发提示词内置中英资源校验要求。

### 安全与状态守卫

- 看板 API 增加 Origin / Host 校验，封堵任意网页跨站代替人工「接受 / 确认完成」（CSRF）。
- 状态守卫封堵多类绕过：引号拆词、解释器内联写入（node -e 等）、find 删除、符号链接路径、file 模式新建文件；同时消除多类只读命令误拦。
- 认领锁治理：过期清理、claim / report 生命周期收紧；根 README.md 纯文档豁免认领锁；放行文档讨论轮对条目目录的 git 提交（带 pathspec + 主题含单号）。

### 数据架构与工程化

- 用户数据与应用数据物理分离：`agent-team-board/data/`（进 git）与 `agent-team-board/runtime/`（本地留存）；确认留痕迁至 runtime。
- 新增 `atb rebuild`：clone 后从 git 历史重建看板状态；旧目录布局一键迁移（`atb migrate` 与设置页入口）。
- README 双语化（README.en.md 章节一一对应）；按四仓库规范整理源码仓库入口文档（根 AGENTS.md）。
- 服务稳定性：SIGTERM 退出与端口占用处理、serve 轮询 git 扫描的 index.lock 冲突消除。

### 测试与稳定性

- 修复多类偶发失败（端口探活、时间边界、负载下超时、全量运行顺序敏感）与集成测试进程泄漏；收口 detail-close-btn 等契约测试的多轮回归。
- 确认闭环全量测试超时上限修复，长套件可通过确认。

- 回退 CI 看板与批量 Commit（保留已完成条目的提交号显示）。
- 隐藏文件看板（File Board）、营销与旧发布视图；发布能力重构并入构建模块。
