# REQ-20260907-002 批量实施批次关联开发人员：调度会话命名与看板展示

- 状态：submitted（待人工接受）
- 创建：2026-09-06T16:24:21.648Z

## 描述

## 背景与目标

单条派发提示词已要求会话改名为单号（REQ-20260904-001），但批量实施的主调度会话没有命名约定：在 Zcode 会话列表和看板批次面板中看不出批次由哪位开发人员发起/负责，多人使用同一项目时无法区分。本需求让批次关联开发人员，调度会话名称写上开发人员。

## 期望行为

1. 创建批次时提供「开发人员」：看板批量实施抽屉创建区增加开发人员输入框（记忆上次使用值，首次可从项目 git user.name 预填，具体 design 定）；CLI 提供 --dev 参数。创建后写入批次账本（受控入口维护，如 batch.json 的 developer 字段）。
2. 批次主调度提示词增加会话命名指令：「将当前会话名改为：<batchId>-<开发人员>」，与 REQ-20260904-001 单条派发的命名风格一致；复制提示词时可见该指令。未填开发人员时按现有提示词输出，不加指令或用缺省名（design 定，需明确不回归）。
3. 看板批次面板、批次记录与批次摘要（batch summary）展示开发人员；存量批次无该字段时显示「未指定」，不要求迁移。
4. 开发人员名称仅用于展示与会话命名（长度限制如不超过 30 字符），不参与任何权限判断。

## 验收要点

- 填写开发人员创建批次：提示词含命名指令、批次卡片显示名字、账本记录 developer 字段。
- 不填写时创建、batch check/next/summary、看板展示均正常，显示「未指定」。
- 现有 batch-cli / batch-serve / batch-ui 测试无回归。

## 关联

- 扩展 REQ-20260906-002（Zcode 批量实施）的提示词与账本；命名思路沿用 REQ-20260904-001（会话改名单号）、REQ-20260901-005（会话名约定）。

## 验收标准

- [ ] 看板创建区可填开发人员（记忆上次值，首次可预填 git user.name），CLI `atb batch create --dev <名称>`；创建后 batch.json 记录 developer 字段
- [ ] 填写开发人员时主调度提示词含「请将当前会话名改为：<batchId>-<开发人员>」指令；未填时提示词与既往一致（不加指令/缺省名）
- [ ] 看板批次面板（含排队批次）与 batch summary 展示开发人员；存量批次无字段显示「未指定」，账本不迁移
- [ ] 开发人员超 30 字符或含换行/控制字符被拒（CLI die / API 400），拒绝不产生批次副作用
- [ ] 不填写时 create / batch check / next / summary 与看板展示均正常；现有 batch-cli / batch-serve / batch-ui 及全量测试无回归
