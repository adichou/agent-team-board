观察要点

  2. 图标化：调整后全选 / 全不选仅保留 ☑ / ☐ 图标，悬浮有完整语义提示（title / aria-label 保留）。
  3. 仅作用当前档：已接受档勾选两项 → 切到已计划档再切回，勾选保留；「全不选」只清当前档。

  5. 状态反馈：正常（计数 / 显隐即时同步）、空（全选禁用 + 空态卡）、加载（防误触 + 「接受中…」进度）、失败（失败清单保留）。
