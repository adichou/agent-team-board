# REQ-20260901-001 详情页支持上一条/下一条快速浏览

- 状态：submitted（待人工接受）
- 创建：2026-09-01T03:17:35.619Z

## 描述

在看板中点开 Bug 或需求卡片进入详情后，提供「上一条 / 下一条」导航，无需关闭再点另一张卡片，便于连续浏览与复核。验收要点：1) 详情视图显示上一条/下一条（含目标单号与标题），点击直接切换详情；2) 遍历顺序与看板排序一致（如创建时间/列内顺序），顺序对用户可见或可预期；3) 首条/尾条对应方向禁用并给视觉反馈；4) 切换后详情内容、状态按钮（接受/确认完成等）随新条目正确刷新，不残留上一条的编辑状态；5) 键盘左右方向键切换（不干扰表单输入时）；6) 深浅色正常，状态视图与详情的既有功能不受影响。
