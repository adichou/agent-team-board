# REQ-20260906-010 文件栏支持 md、图片的渲染展示。并支持复制目录和行号到剪贴板以便在讨论对话框中讨论

- 状态：submitted（待人工接受）
- 创建：2026-09-06T03:39:07.580Z

## 描述

Status Board 的文件视图（File Board，顶栏「文件」Tab）目前把所有文件一律按源码
`<pre><code>` + highlight.js 展示，有两类体验缺口：

1. **Markdown 只见源码不见渲染**：项目里大量文档（本看板自身的 README/design
   等）需要阅读排版后的效果；详情抽屉已有 `renderMd`（marked + 轻量 sanitize），
   文件视图却未复用。
2. **图片完全无法预览**：`/api/fs/file` 检测到 NUL 字节即按「二进制文件」拒绝，
   png/jpg 等图片点开只有报错。
3. **讨论引用不便**：在讨论对话框（聊天窗口）里讨论某段代码时，需要手打
   「某某文件第几行」；文件视图没有一键复制路径或「路径:行号」的入口。

### 界面与交互（UI 需求，接受即视为设计认可）

- **查看器工具条**：打开任意文件后，文件查看器顶部出现一条工具条，展示当前
  文件相对路径，右侧有「复制路径」按钮（点击复制相对路径，toast 反馈）。
- **md 渲染**：`.md` / `.markdown` 文件默认以渲染视图展示（复用抽屉 `.md`
  排版样式）；工具条提供「源码 / 渲染」切换（仅 md 文件出现），源码态即现有
  语法高亮视图，切换不改变当前打开的文件。
- **图片预览**：png / jpg / jpeg / gif / webp / svg / ico / bmp / avif 后缀的
  文件点开后直接居中显示图片（`max-width: 100%`，不放大位图），工具条照常可
  复制路径；加载失败给出错误提示。
- **行号与复制**：源码视图（含 md 的源码态）带行号槽；点击任一行号把
  `相对路径:行号`（如 `scripts/web/app.js:123`）复制到剪贴板并 toast 反馈，
  便于直接粘贴进讨论对话框讨论。

## 验收标准

- [ ] md 文件默认渲染展示，可在「源码 / 渲染」间切换，源码态保留语法高亮
- [ ] png/jpg 等图片后缀文件在文件视图内直接显示为图片，超大（>8MB）给出明确提示
- [ ] 打开文件后工具条显示相对路径，「复制路径」一键复制
- [ ] 源码视图点击行号复制 `路径:行号` 到剪贴板，有成功反馈
- [ ] 图片原始字节走独立只读端点：沿用路径防穿越/排除规则，仅图片后缀白名单，
      响应带 nosniff 与收紧的 CSP 头
- [ ] 既有行为回归：非 md 文本文件高亮、目录横幅浏览、1MB 文本上限不受影响
