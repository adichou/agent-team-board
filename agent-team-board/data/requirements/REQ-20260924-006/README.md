# REQ-20260924-006 文档编写流程优化

## 描述

发布模块「文档编写」按 **AI 总结 → 二次编辑 → AI 校对 → AI 翻译 → 提交** 组织主要操作，让默认语言先形成初稿、经人工编辑和逐条校对处理后，再成为其他语言的翻译基准。

### 项目现状与范围

已核对 `scripts/web/build.js` 的 `renderDocsPane`、审查与校对事件，以及 `scripts/lib/build-store.mjs` 的 `recordDocsFinalize`：当前已有 AI 总结/翻译提示词、文档编辑审查、AI 校对入口、逐文件审核和整体审查完结门禁；整体完结记录关联语言集和文档内容。本需求是流程与校对建议交互的优化，不将现有能力描述成未实现。

文档清单使用当前版本实际清单，包含标准文档、自定义文档及既有不分语言文档规则；默认语言取版本语言集首项，不固定为中文。总结的 REQ 列表指当前版本关联需求，需结合实际关联提交和代码核对，不能把尚未进入版本或已回退的功能写成已发布。Bug 与其他已有发布取材规则保留。

### 五步操作

1. **AI 总结**：提供可查看、复制的提示词，要求依据本版 REQ 列表及对应实际变更编写默认语言初稿，明确版本、文件清单、语言和事实来源。任务完成后逐文件回显结果；复制提示词本身不代表编写完成。
2. **二次编辑**：打开默认语言文档编辑弹窗，沿用现有审查界面的文件切换、刷新、编辑、预览与保存能力，移除其他语种对照列。保存后显示成功反馈；有未保存内容时刷新、换文件、关闭须提示保存或放弃，失败不得丢失输入。
3. **AI 校对**：提供校对默认语言文档的提示词，覆盖超链接有效性、错别字、语法及行文规范。结果按文件展示在文档区域右侧，包含问题类型、位置、原因和建议。点击建议展开修改前后对比，删除与新增用不同高亮色并辅以文字标识；用户逐条接受或拒绝。接受才修改对应文档，拒绝保留原文；成功持久保存才显示已接受。建议基于的文本已变化时标记过期，不得盲目覆盖人工修改。网络不可达或需要登录的链接标为「待确认」，不能判成有效或确定失效。
4. **AI 翻译**：以保存后的最新默认语言文档为基准，提示词列明目标语言和文件，翻译为版本语言集内其他语言，不扩写新功能；默认语言再次变化时提示重新校对/翻译。未处理建议显示数量并阻止误以为校对结束。单语言版本显示无翻译目标并可跳过翻译。
5. **提交**：集中展示文件与未满足条件；成功展示真实提交结果，失败显示原因并可重试。沿用现有本地提交边界，不能把提交当作合并或发布成功。

### 边界与待确认

- 本次原始描述未说明是否取消现有逐文件审核与整体审查完结；其移入五步流程后的具体入口和是否调整门禁 **待确认**。本需求不据此授权删除既有校验，演示保留最终人工核对动作；开发前如需改变门禁须人工确认。
- 校对建议的生产/回执字段、粒度、存储和并发冲突检测实现 **待确认**，不在完善阶段提前编写 design/test-cases。
- 外链验证的超时、重定向与登录态判定策略 **待确认**；必须区分确定失效与无法验证。

## 界面展示

可交互演示：[ui-demo.html](./ui-demo.html)。单文件内联 CSS/JS，无外网依赖、无需构建，可直接在浏览器打开；数据与提交均为模拟，不操作真实文档。

### 界面布局

顶部显示版本与默认语言及五步操作条；中部左侧文件清单，中间默认语言正文，右侧当前文件的校对建议和待处理计数。二次编辑使用单语言弹窗，顶部文件选择及刷新按钮，中部编辑/预览切换，底部保存/关闭。建议展开后分栏展示修改前后，在窄屏纵向排列并保留前后标签。

### 交互行为

演示可生成初稿、切换文件、打开编辑弹窗、修改并保存、预览与刷新、生成校对建议、展开差异并接受/拒绝、模拟翻译、完成最终人工核对并模拟提交。按钮禁用时在状态区解释条件；用户在建议产生后改写原文，再接受该建议，会收到过期提示。操作只修改内存中的演示数据。

### 状态反馈

- 正常：显示已保存正文、建议待处理/接受/拒绝状态及下一步条件。
- 空：没有初稿提示先总结；校对无问题显示「未发现问题」，不显示空白侧栏；无翻译目标明确可跳过。
- 加载：读取或 AI 操作期间显示进度并禁用冲突操作；复制提示词与完成回执区分。
- 失败：显示失败原因和重试入口，保留已有正文；保存失败不得显示已保存，提交失败不得显示已提交。
- 变化：未保存提示、建议过期、默认语言变化导致翻译需更新均有明确反馈。

## 验收标准

- [ ] 页面按五步顺序提供入口；文档、语言和版本均来自当前版本实际配置，支持自定义文档与默认语言非中文。
- [ ] 总结提示词包含本版关联需求及实际变更核验要求，只编写默认语言初稿；复制与任务完成状态分别展示。
- [ ] 二次编辑弹窗只显示默认语言，支持文件切换、刷新、编辑、预览、保存；未保存切换/关闭/刷新有保护，保存失败保留输入。
- [ ] 校对覆盖链接、错别字及行文规范；每个文件右侧均可查看自身建议，无建议有明确空态，读取/任务失败有原因与重试。
- [ ] 打开建议可查看带新增/删除高亮及文字标签的前后差异；接受只应用所选建议并在保存成功后确认，拒绝不改变原文，两种结果可区分。
- [ ] 过期建议不能覆盖已变化的文本，重复点击不会重复应用，保存失败不误标接受；无法验证的链接显示待确认。
- [ ] 翻译使用处理完建议并保存的最新默认语言，列明所有目标；单语言可跳过。后续源文变化使旧翻译不能直接作为最新结果提交。
- [ ] 提交前显示完整文件清单与缺口，现有审核/整体完结校验未经确认不移除；失败保留内容可重试，成功显示实际结果且不冒充发布成功。
- [ ] 正常、空、加载、失败及未保存/过期状态均有可读反馈；新增界面文案同步中英文，键盘可操作按钮与弹窗。
- [ ] 本目录演示可离线直接打开并完成编辑、建议处理与流程切换；演示明确标注模拟，不发送网络请求或修改真实文件。
