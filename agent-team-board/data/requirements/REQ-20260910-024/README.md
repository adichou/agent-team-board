## 描述

将独立部署或已有 Umami 作为首个只读数据源。连接配置包含服务地址、凭据引用、网站标识、项目映射和时区。实施前核验目标 Umami 版本的实际 API、授权方式及指标能力，记录版本与字段映射；仅展示已验证支持的流量、来源或事件指标，不能假称具备社交平台粉丝数据。

第一期提供测试连接和手动同步指定日期范围，不部署 Umami、不增加定时服务。凭据存放系统凭据库或本机 Git 外配置，营销档案只留引用，界面及日志不回显密钥。网站映射修改需明确展示当前项目和目标网站，历史记录保持原来源。

同步按站点、指标、期间、维度及来源建立幂等键，分页全部完成并校验后提交快照；重复同步更新同一来源记录的修订，不累计重复数据。来源存在手工记录时分源显示，只有用户建立明确替代映射后用于同一主指标。

失败保留最后成功快照，展示401/403、超时、限流、版本不兼容或字段缺失等可操作原因；限流遵守服务端重试提示。断开连接停止后续请求、清理凭据引用并保留历史指标；第一版没有隐式后台重试。

## 界面展示

布局：营销效果页“数据来源”面板显示 Umami 卡片、服务地址、网站映射、凭据状态、测试连接、日期范围与同步按钮，下方同步历史。
交互：配置→测试→选择网站→保存映射→手动同步；同步中禁同一任务重复触发；完成可跳到本次导入指标。
反馈：区分未连接、连接成功、同步中、上次成功及失败；失败显示历史数据时间，不将旧值置零或伪装为最新。

```text
数据来源 / Umami
服务地址 [          ] 凭据 [已配置 / 未配置]
当前项目 A -> 网站 [选择] [测试连接] [保存]
[日期范围] [同步]
上次成功：…  本次失败：限流  [查看记录]
```

当前为创建阶段线框；进入完善阶段后，本条目需补单文件、可交互、无外网依赖的 ui-demo.html，并在此链接。

## 验收标准

- [ ] 测试连接、网站映射和只读同步经目标版本 API 验证，不支持字段明确标注。
- [ ] 凭据不写入 Git、Markdown、日志及导出；不同项目映射不串站点。
- [ ] 分页中途失败无部分快照，重复同步不重复计数，手工来源不被静默覆盖。
- [ ] 未授权、限流、超时、版本不兼容均可诊断，保留上次成功数据和时间。
- [ ] 断开后无后台请求；历史观察与来源仍可追溯。
