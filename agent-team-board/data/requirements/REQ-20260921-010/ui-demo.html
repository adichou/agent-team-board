演示要点
  • 「文档」标题行新增语言集输入框（默认 cn,en）：回车或失焦确认；改成如 cn,en,fr,jp 后，语言下拉、下方文档 chips、门禁清单与 README 链接提示全部联动展开。
  • 文件命名规则：第一个语言不带后缀（README.md），其余带后缀（README_en.md、README_fr.md…）；调整语言顺序后默认语言随之改变。
  • 非法输入演示：清空后确认、或输入 cn,,en、cn,en,cn、中,en 等会被拦截并提示，界面保持上次有效状态。
  • 保存 / 提交：加载中按钮禁用；保存已提交文档会转「需重新编写」；全部提交后门禁变绿；勾选顶部「模拟失败」可体验失败与重试反馈；全部未编写时提交按钮禁用（空态）。
  • 底部「文档内多语言切换行」演示需求第 3 点：切换行涵盖语言集全部语言，点击语言链接跳到对应文档。
  • 后缀分隔符（下划线 vs 存量点号 .en.md）、语言缩写口径（cn / zh）等仍为「待确认」项，本演示按需求原文口径呈现。
