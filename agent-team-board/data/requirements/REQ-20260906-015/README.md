# REQ-20260906-015 支持全局搜索，可以任意搜索需求，bug 和文件数中的文件。在需求看板界面就是搜索需求、bug，设计文档，在文件看板就是搜索文件

- 状态：submitted（待人工接受）
- 创建：2026-09-06T04:00:53.025Z

## 描述

Status Board 增加全局搜索：顶栏一个搜索框，行为随当前视图解释——需求看板视图搜需求、Bug 与条目文档，文件看板视图搜项目文件。

**界面布局**

- 顶栏 `.top-actions` 内、视图切换栏（需求/文件）左侧新增全局搜索输入框：圆角胶囊、左侧放大镜图标、宽度约 220px，输入时可清空（type=search 自带 ✕）。
- placeholder 随视图切换：需求视图显示「搜需求 / Bug / 文档…」，文件视图显示「搜文件…」。
- 需求视图的「文档命中」条带显示在看板四列上方、通栏宽度；文件视图的「文件搜索结果」条带显示在文件横幅上方、通栏宽度。
- 窄屏（≤640px）沿用顶栏换行降级，搜索框随行动作组流式换行。

**交互行为**

- 输入即搜（250ms 防抖），调用 `GET /api/search?q=<关键词>`；切换项目后关键词保留并对新项目重新解释；切换视图保留关键词并按新视图解释。
- 需求视图：`items`（id 或标题命中，大小写不敏感）命中的需求/Bug 卡片保留、其余隐藏，各列计数同步为过滤后数量，2 秒轮询不重置过滤；`docs`（条目 .md 文档内容命中）在看板上方「文档命中」条带列出（单号 · 文档名 · 行号 · 行摘要），点击打开该条目抽屉并直接定位到该文档。
- 文件视图：`files`（文件名命中）以 chip 列表显示在「文件搜索结果」条带（路径升序），点击 chip 直接打开该文件预览（复用现有 openFile，md 渲染/图片预览/语法高亮行为一致）。
- 清空输入、点击输入框 ✕ 或在输入框内按 Esc：清除关键词并恢复全量视图。
- 文件搜索忽略 `node_modules`、`.git` 与隐藏文件/目录；文档搜索跳过每篇文档首行 H1 标题（避免搜单号时把所有 README 顶行全量顶出）。

**状态反馈**

- 搜索请求进行中输入框显示 loading 态（aria-busy + 右侧 ⋯ 指示）。
- 三类结果均有命中数为 0 时，对应视图显示「无匹配」空态提示条。
- 每类结果最多 50 条；超限时条带尾部提示「已显示前 50 条，请换更精确的关键词」。
- 服务端/网络错误走现有 toast 报错，输入内容保留。

## 验收标准

- [ ] 顶栏有全局搜索输入框，placeholder 随视图切换（需求/文件两种文案）。
- [ ] `GET /api/search?q=` 返回 `items` / `docs` / `files` 三类结果；q 为空或缺失时返回三个空数组、HTTP 200。
- [ ] 需求视图：id/标题命中的需求与 Bug 卡片保留、其余隐藏，列计数同步，清空恢复全量；轮询刷新不重置过滤。
- [ ] 需求视图：文档内容命中显示「文档命中」条带（单号 · 文档名 · 行号 · 摘要），点击打开抽屉并定位到该文档；H1 标题行不算内容命中。
- [ ] 文件视图：文件名命中显示「文件搜索结果」条带，点击打开文件预览。
- [ ] 搜索大小写不敏感；文件搜索不进入 node_modules/.git/隐藏目录；未初始化看板的项目也能搜文件（items/docs 为空）。
- [ ] 每类结果上限 50 条并提示截断。
- [ ] 输入框内 Esc 清空搜索；搜索请求竞态以最后输入为准（旧响应不覆盖新输入）。
