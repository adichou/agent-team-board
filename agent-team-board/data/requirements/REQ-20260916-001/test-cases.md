# 测试用例 — REQ-20260916-001

> 待实施；以下为验收用例，不代表已运行或通过。以隔离 Git 仓库及模拟批次验证，真实 UI 验收另行记录。

| 编号 | 场景与操作 | 预期 |
| --- | --- | --- |
| T01 | 批次结束含两个 blocked 条目，其中一条有多次运行 | 概括显著显示仍有 2 项阻塞，展开可看全部轮次，无重复计数 |
| T02 | 无阻塞、加载、读取失败再重试 | 分别显示 0、加载及错误；错误不显示 0 或成功 |
| T03 | 项目/批次切换后旧请求返回 | 计数、原因及文件不串项目或批次 |
| T04 | 查看正常/缺失/权限失败 blocker；请求 ../ 或符号链接越界 | 正常只读展示，其余明确失败；拒绝越界，重试可用 |
| T05 | 多问题部分回答保存草稿，刷新，再取消确认 | 草稿可恢复；未完整不能确认；取消不改文档或提交 |
| T06 | 完整回答预览并确认，design 原不存在 | 仅所审阅 README/design 和必要审计文档更新，其他要求保留，提交号真实 |
| T07 | 预览后另一会话修改文档/问题版本 | 冲突可见，旧确认拒绝，原改动保留并需重新审阅 |
| T08 | 已暂存无关源码、其他条目文档，同目标文档含原有未提交改动 | commit 差异仅批准文档变更；原索引及工作区改动保留，不能隔离则停止并提示 |
| T09 | 文件写入失败或仅写入一个文件后中断 | 显示保存失败/部分落盘，恢复事务后只补缺失步骤，不重复追加 |
| T10 | Git 身份缺失、hook 拒绝或仓库不可用 | 文档已保存与提交失败分开反馈，保留答案，修复后可重试，不绕过 hook |
| T11 | commit 成功后记录前服务重启，重复点击确认/重试 | 根据事务核实原提交并补回执，只有一次提交，无重复答案 |
| T12 | 提交期间 HEAD/索引被外部修改 | 不夹带改动或强推引用；重核验或显式冲突，用户改动保留 |
| T13 | 提交成功且存在未满足环境依赖 | 决策已确认可见，依赖仍阻塞；不自动接受、完成、置计划或启动 |
| T14 | Agent 调确认入口及人工独立复工 | Agent 确认被权限守卫拒绝；人工复工按现有机制核对，不借确认绕过状态机 |
| T15 | 窄屏/长路径/键盘/阻塞列表为空 | 布局不溢出、按钮可操作、状态有文字，空态有明确说明 |
| T16 | 仅历史 blocked 无 hold，刷新及服务重启 | 阻塞仍可查；不能因缺少 hold 隐藏或误报已解决 |
| T17 | 重复确认无新差异 | 关联可核实已有提交；无证据不生成假 OID、不冒称完成 |
