# REQ-20260915-003 构建模块的产品发布区域需要移到左侧列表的按钮区域。关联条目支持分页和搜索

- 创建：2026-09-15T13:40:51.472Z
- 状态以系统维护的 status.json 为准。

## 描述

1. 将「创建发布」「查看发布记录」移至左侧每张版本卡片已有的按钮区域，与 AI 完善、合并入 main、删除集中展示。右侧详情不再重复显示产品发布操作区域。
2. 右侧「关联条目与 commit」列表支持分页，在该标题右侧放置搜索组件，便于在大量关联单中定位条目和提交。
3. 将「新建版本」上移至「版本计划」「分支浏览」页签同一行的右端，取消单独占用一行的工具栏。

### 已核对的现状与范围

现有实现位于 `scripts/web/build.js`：`renderVersionList` 已在版本卡片内提供 AI 完善、合并、删除；`renderDetail` 将每个条目与其 commit 放在同一行，全量渲染，产品发布区域在详情底部；`render` 的新建版本按钮另占工具栏。创建发布只允许 merged 版本，查看发布记录跳转发布模块产品发布页签。

本需求中的列表按现有「关联条目与 commit」联合行处理，一条关联单及其所选 commit 为一个分页单位；搜索覆盖条目 ID、标题与完整/短 commit 哈希，忽略英文大小写并去除首尾空白，按包含关系匹配，保持原顺序。分支浏览已有的提交搜索不在本次变更范围。是否另指独立 commit 列表或新建面板候选列表：待确认；演示与本次验收采用联合列表口径。

### 界面布局

- 顶部页签靠左，新建版本靠右；版本计划页可操作，分支浏览页不提供新建入口，维持现有可用范围。
- 左栏版本卡片展示名称、编号、状态与关联单数量；按钮区域容纳既有操作及两项发布操作，空间不足自动换行，避免遮挡标题或横向溢出。
- 右栏保留版本信息和关联列表；列表标题右侧依次放搜索输入、清空和既有添加条目入口，下方展示匹配数、数据行，底部展示页码、总页数、上一页和下一页。
- 窄屏允许页签工具行与标题搜索区换行，双栏堆叠，控件仍可点击且文字可读。

### 交互行为

- 卡片发布操作必须绑定所在卡片的版本 ID，即使该卡片尚未选中也不能误操作右侧已选版本；创建发布继续打开既有核对弹层，查看记录继续进入既有产品发布页签，不新增未实现的按版本过滤承诺。
- draft、merging、failed 禁用创建发布，并可见说明「请先完成合并入 main」；merged 可创建。沿用原有发布校验、提交中防重复及结果反馈。
- 输入搜索词后过滤当前版本全部关联行，再分页；关键词变化、清空或切换版本时回到第一页，切换版本清空搜索。搜索不修改关联关系，移出等操作须绑定真实条目 ID。
- 每页数量为待确认的产品参数，演示使用每页 5 条。首末页对应按钮禁用；零结果显示 0 条、不产生可翻页的虚假页数。数据减少导致当前页失效时回到最后一个有效页。
- 搜索、翻页不能绕过合并中/已合并时禁止增删与修改 commit 的既有约束；新建版本仍打开原有侧拉面板。

### 状态反馈

- 正常：显示当前匹配数、总条目数和页码；空列表显示暂无关联条目与适当添加引导；无匹配显示搜索无结果及清空入口，区分两种空态。
- 加载：列表区域显示加载提示，禁用翻页和数据操作，避免旧数据被误认为新结果。
- 失败：列表区域显示读取失败和重试按钮；重试成功恢复当前版本与搜索条件，再校正页码。加载/失败不得伪装为空数据。
- 创建发布沿用提交中、成功或失败反馈；演示仅以模拟弹层/提示展示入口，不执行真实发布。

## 界面展示

打开 [交互界面演示](./ui-demo.html)：单文件，内联 CSS/JS，无外网依赖与构建步骤。布局为顶部页签与新建按钮、左侧版本卡片操作、右侧联合列表。可切换版本、输入搜索、清空、翻页、打开模拟新建/发布/记录弹层，并切换正常、空、加载、失败状态验证反馈。演示数据为虚构示例，不代表项目真实条目或发布结果；卡片上的既有 AI 完善、合并、删除按钮作为布局参照禁用。

## 验收标准

- [ ] 版本计划页中，新建版本与两页签位于同一工具行，点击仍打开既有新建面板；窄屏可换行，无遮挡。
- [ ] 每张版本卡片按钮区包含创建发布和查看发布记录，详情不重复显示原产品发布区域；按钮换行不破坏卡片选择。
- [ ] 点击未选中卡片的创建发布使用该卡片版本，未合并卡片禁用并提示原因；查看记录进入发布模块产品发布页签。
- [ ] 联合列表可按条目 ID、标题、短/完整 commit 搜索；英文大小写与首尾空格不影响命中；搜索覆盖所有页的数据，结果保持原顺序。
- [ ] 超过每页数量时可翻页，计数与页码准确，首末页禁用对应按钮；搜索/清空/切换版本遵循第一页重置，切换版本清空关键词。
- [ ] 零关联、无搜索匹配、加载中和读取失败四种状态有可区分提示，失败可重试，加载及失败时不允许操作失效数据。
- [ ] 过滤和翻页后移出、commit 编辑仍作用于正确条目，merged/merging 既有编辑限制不变，数据减少时不滞留空的越界页。
- [ ] ui-demo.html 可离线直接打开，交互覆盖发布入口、顶部布局、搜索分页及正常/空/加载/失败反馈，README 保留布局、交互、状态说明及相对链接。
