# REQ-20260906-005 需求单详细页面的关闭按钮要固定在单号右侧。

- 状态：accepted（已接受，待 Agent 认领）
- 创建：2026-09-06T02:57:35.497Z

## 描述

**现状**：需求/Bug 详情抽屉（drawer）顶部头部为「左块 + 右按钮」的 space-between 布局——左块内是单号行
（chip + 单号 [+ 待确认 flag]）和标题两行，关闭按钮 `✕` 固定在整个头部块的最右端，与整个左块垂直居中，
视觉上离单号很远，且位置随标题换行/窗口宽度漂移感明显。

**目标布局**：关闭按钮 `✕` 固定在**单号同一行的紧右侧**——头部第一行顺序为
`[REQ/BUG chip] [单号] [✕] [待确认 flag(若有)]`，`✕` 始终紧跟单号，不随标题长度、flag 有无、窗口宽度漂移；
标题独占第二行整行宽度。

**交互行为**（保持不变）：
- 点击 `✕` 关闭抽屉；hover 有背景高亮反馈；
- 键盘 Escape 关闭抽屉；点击遮罩关闭抽屉。

**状态反馈**：条目处于「待确认」（Agent 已上报）时，`待确认` flag 仍在单号行右端（margin-left:auto），
`✕` 保持在单号紧右侧不被 flag 挤走。

## 验收标准

- [ ] 详情页头部第一行内 `✕` 紧跟单号右侧渲染（chip → 单号 → ✕ 顺序），适用于需求与 Bug 两种类型
- [ ] 标题独占一行，头部不再保留旧的 space-between 两端布局
- [ ] 点击 `✕`、Escape、点击遮罩关闭抽屉的行为全部保持
- [ ] 有「待确认」flag 时 flag 仍在行右端，`✕` 不被挤离单号右侧
- [ ] 竖版/窄窗口下不破版（单号行不与标题重叠）
