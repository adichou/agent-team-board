# REQ-20260910-014 管理项目和新建按钮采用和全局按钮一样的侧拉面板

- 状态：accepted（已接受；以 status.json 为准）
- 创建：2026-09-10T04:53:30.822Z

## 描述

顶栏「管理项目」与「＋ 新建」目前打开的是居中模态弹窗，与「全局」按钮打开的右侧侧拉面板形态不一致。本需求把这两个入口改为与「全局」按钮一致的右侧侧拉面板呈现，统一顶栏入口的弹出形态；只改容器形态与开合交互，表单字段、功能与数据流全部保持不变。

### 已核实的现状与范围

以下现状已对照代码核实（看板页由 `scripts/server.mjs` 提供，Electron 壳 `electron/main.mjs` 加载同一页面，浏览器版与 app 版共用，改动同时作用于两端）：

- 「＋ 新建」（`#btnNew`）打开居中弹窗 `#modalWrap`（`scripts/web/index.html`）：`.modal-wrap` 全屏遮罩（`z-index: 30`）+ `.modal`（`width: min(480px, 92vw)`）居中。表单为类型（需求 / Bug / 讨论，切到讨论隐藏截图区）、标题（必填）、描述、截图（0/9 张、上传或 ⌘V 粘贴、单张 ≤ 8MB）、取消 / 创建；点击遮罩空白可关闭；提交中创建按钮禁用并显示「创建中…」，失败保留已填内容与附件。
- 「管理项目」（`#btnProjManage`）打开居中弹窗 `#projModalWrap`：`.proj-modal`（`width: min(560px, 92vw)`、`max-height: 86vh`）居中。内容为操作选择（初始化 / 导入）+ 项目根目录绝对路径 + 「解析路径」两步确认（`#projTarget` 展示将写入的目标位置）+ 状态通知 + 目录存在性检测栏（摘要 / 重新检测 / 一键移出不存在目录）+ 已注册项目列表（完整路径可换行、当前标记、检测状态、切换 / 移出）+ 单项与批量移出确认区；打开即拉取最新注册表并自动检测目录存在性。
- 「全局」（`#btnGlobal`，BUG-20260910-004）打开右侧固定面板 `#globalPanel`：`.global-panel` 贴屏幕右缘通高（`top: 0; right: 0; bottom: 0`）、`z-index: 25`、`width: min(560px, 92vw)`、左侧描边与投影、无全屏遮罩；结构为常驻头部（标题 + 说明 + ✕ 关闭，`flex: none`）+ 内容区（`flex: 1`，独立滚动）；窄屏（≤ 640px）宽 `100vw` 无左描边。打开幂等不叠加，`aria-expanded` 与入口按钮联动，打开时焦点进入面板、关闭后焦点返回入口按钮；颜色全部走 CSS 变量，深浅色随 `prefers-color-scheme` 自动适配。
- Esc 关闭链现状（`app.js`，一次只关一层）：项目管理弹窗 → 新建弹窗 → 全局面板 → 需求详情抽屉；快捷键帮助面板另有独立处理。
- 空态入口：需求模块空态卡（未初始化 / 暂无项目）内的「管理项目」按钮（`#btnOpenProjManage`）与顶栏同一入口，随本需求一并切换为侧拉面板。

本需求不改动顶栏其余按钮（全局、快捷键 ？、待处理、项目选择器）与快捷键帮助、放大图等其他弹窗；不改任何业务数据流、状态机与接口。

## 界面布局

- 「管理项目」「＋ 新建」的内容分别从居中弹窗迁入右侧固定面板，形态对齐 `#globalPanel`：贴屏幕右缘通高、`width: min(560px, 92vw)`、左侧 1px 描边 + 向左投影、`z-index: 25`；窄屏（≤ 640px）宽 `100vw`、无左描边（与全局面板同一断点）。
- 面板结构统一为：常驻头部（标题 + 一句简短说明 + ✕ 关闭按钮，任何宽度不被压缩）+ 内容区独立滚动（面板高度不足时仅内容区滚动，头部与关闭按钮始终可达）。
  - 新建面板头部：标题「新建条目」；内容区为现有表单（类型 / 标题 / 描述 / 截图 / 取消·创建），字段与顺序不变。
  - 管理项目面板头部：标题「项目管理」；内容区为现有操作表单（初始化 / 导入 + 路径 + 解析路径两步确认）+ 检测栏 + 已注册项目列表 + 单项/批量移出确认区，分区与顺序不变。
- 原全屏遮罩形态取消（对齐全局面板：无遮罩、不压暗主界面，面板下方仍可见看板内容）；移出确认、批量移出确认区作为面板内容的一部分随内容区滚动，仍为面板内的二级确认，不另开层。
- 深浅色沿用既有 CSS 变量，随系统外观自动适配；浏览器版与 Electron app 版共用同一实现。

## 交互行为

1. 打开：点击顶栏「管理项目」/「＋ 新建」（含空态卡内「管理项目」入口）从右侧拉出对应面板；重复点击幂等，不叠加面板。入口按钮带 `aria-haspopup="dialog"` 与 `aria-expanded` 开合联动（对齐全局按钮既有写法）。
2. 焦点：打开后焦点进入面板（新建聚焦标题输入框、管理项目聚焦路径输入框，沿现有弹窗首控件聚焦先例）；关闭后焦点返回各自入口按钮。
3. 关闭：点击头部 ✕ 或按 Esc 关闭；Esc 一次只关一层，沿用既有关闭链顺序（管理项目面板 → 新建面板 → 全局面板 → 详情抽屉），面板打开期间不切换当前项目模块。
4. 表单交互全部保留不变：新建的类型切换联动字段（讨论隐藏截图区）、标题必填校验、截图上传 / ⌘V 粘贴 / 删除（≤ 9 张）；管理项目的「解析路径」两步确认（先展示将写入的目标位置，确认后执行）、切换 / 移出（单项确认）、一键移出不存在目录（批量确认）。
5. 关闭面板即结束本次会话：重新打开新建面板重置表单（标题 / 描述 / 截图计数清零，沿现状）；重新打开管理项目面板重新拉取注册表并自动检测目录存在性（沿现状）。

## 状态反馈

- 正常：面板开合即时，创建成功 toast「✓ 已创建 …（待接受）」并关闭面板、跳转对应模块；管理项目初始化 / 导入 / 切换 / 移出成功后项目列表即时刷新。
- 空：管理项目面板无已注册项目时，列表区显示「暂无项目。使用上方表单初始化或导入项目。」提示（沿现状）；新建面板无空态。
- 加载：创建提交中「创建」按钮禁用并显示「创建中…」，截图增删入口同步禁用防竞态；管理项目解析 / 执行中按钮禁用、目录检测进行中各行显示检测中状态，操作均防重复提交。
- 失败：创建失败保留已填标题 / 描述 / 截图，toast 错误信息供重试；带截图时服务版本过旧的预检拦截提示（BUG-20260909-010 口径）不变；目录检测失败 / 目录不存在在列表行与检测摘要中如实展示，批量移出单项失败不回滚其余项。
- 深浅色：面板颜色全部走既有 CSS 变量，随系统外观自动适配，无硬编码色值。

## 界面展示

布局：顶栏右缘「管理项目」「全局」「＋ 新建」三个入口弹出物统一为右侧贴边通高的侧拉面板（宽 `min(560px, 92vw)`、窄屏全宽），头部（标题 + 说明 + ✕）常驻、内容区独立滚动、无全屏遮罩。交互：可对照「现状 · 居中弹窗」与「目标 · 侧拉面板」两种形态，点击三个入口开合面板、切换 / 移出确认、解析路径两步确认、Esc 分层关闭。状态反馈：提供正常 / 空 / 加载 / 失败四种状态的切换，覆盖创建提交中与失败保留草稿、管理项目检测摘要与暂无项目提示。[打开可交互演示](./ui-demo.html)（单文件、内联 CSS/JS、无外网依赖，数据为内存模拟，不读写磁盘）。

## 验收标准

- [ ] 顶栏「＋ 新建」与「管理项目」（含需求空态卡内入口）打开的均为右侧侧拉面板：贴屏幕右缘通高、`width: min(560px, 92vw)`、窄屏（≤ 640px）全宽；头部（标题 + 说明 + ✕ 关闭）常驻不被压缩，内容区独立滚动；原居中弹窗与全屏遮罩形态不再出现于这两个入口。
- [ ] 两面板内容与功能较现状无增减：新建的类型联动、标题必填、描述、截图（上传 / ⌘V 粘贴 / 删除、≤ 9 张、单张 ≤ 8MB）齐全；管理项目的初始化 / 导入两步确认（解析路径 → 目标位置 → 执行）、目录检测栏（摘要 / 重新检测 / 一键移出）、项目列表（完整路径可换行、当前标记、检测状态、切换 / 移出）、单项与批量移出确认齐全可用。
- [ ] 开合行为对齐「全局」面板：打开幂等不叠加；无全屏遮罩、不切换当前项目模块；入口按钮 `aria-haspopup="dialog"` / `aria-expanded` 随开合联动；打开焦点进入面板（新建 → 标题框、管理项目 → 路径框），经 ✕ 或 Esc 关闭后焦点返回各自入口按钮。
- [ ] Esc 一次只关一层，关闭链顺序正确（管理项目面板 → 新建面板 → 全局面板 → 详情抽屉），与快捷键帮助等其他弹窗不互相干扰。
- [ ] 状态反馈符合「状态反馈」约定：创建中按钮禁用防重复提交、失败保留已填内容与截图并可重试、成功 toast 并关闭面板跳转；管理项目打开自动拉取注册表并检测目录存在性，检测失败 / 不存在目录如实展示，暂无项目时给引导提示。
- [ ] 面板颜色全部走既有 CSS 变量，深浅色随系统外观自动适配；浏览器版与 Electron app 版呈现一致，app 版顶栏交通灯让位与拖动区不受影响。
- [ ] `ui-demo.html` 单文件、无外网依赖、浏览器直接打开可交互，覆盖现状（居中弹窗）与目标（侧拉面板）形态对照、三入口开合与确认交互、正常 / 空 / 加载 / 失败状态切换。

## 待确认

- 新建 / 管理项目侧拉面板与仍为居中模态的快捷键帮助面板（`z-index: 30`）同时打开时的层级与 Esc 关闭顺序，建议帮助面板居上、Esc 先关帮助，开发阶段随实现定稿。
- 面板打开期间顶栏其余操作（项目选择器切换、模块页签切换）是否需要禁用或允许并行操作，默认允许并行（沿全局面板「打开不切换、不阻塞主界面」先例），待开发阶段确认。
- 面板是否需要滑入 / 滑出过渡动效：全局面板现状为直接显隐，本需求默认对齐（不加动效），如需动效在开发阶段统一定稿。
