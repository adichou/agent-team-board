# 设计 — REQ-20260916-006 待人工确认的任务中的文件差异对比页面没法看出来差异点，需要优化

> 由 Agent 在 /dev 开发前补充，人可随时批注。

## 背景

待人工确认（develop 类挂起）侧拉面板的「查看差异」此前把 `/api/confirms/<id>/diff`
返回的 unified diff 原文整体转义后塞进单个 `<pre>`，`+`/`-`/`@@` 与上下文同样式，
改动行淹没在等宽文本墙里；未跟踪新文件整屏平铺「原文」，无从分辨差异点。

## 方案

（技术选型、接口设计、影响面）

**纯前端展示层优化**：数据来源、服务端语义、只读 git 口径完全不变
（`scripts/server.mjs` 的 `/api/confirms/<id>/diff` 仍走 `gitFlow.fileDiffText`）。

- 新增 `scripts/web/diff-view.js`（IIFE，挂 `window.ATBDiffView`，先于 app.js 加载）：
  - `parseDiff(text)`：解析 unified diff（文件头元信息 / hunk 头 / 上下文 / 新增 / 删除 /
    `\ No newline` 注记；hunk 计数缺省按 1；多文件节按 `diff --git` 重置行号）与
    未跟踪新文件格式（「（新文件，未纳入版本控制）」+ 分隔行 + 全文），行号与 git 原文一致；
  - `foldSegments` / `renderUnified` / `renderSplit`：长段未变更上下文默认折叠
    （连续 ≥8 行收中段，头尾各留 3 行；折叠中段不渲染，DOM 随折叠缩减），改动行始终可见；
    统一视图每行「旧行号 · 新行号 · 标记列 · 内容」，并排视图左删右增、成对行同行对齐；
  - `pairRuns` / `highlightPair`：紧邻删除段+新增段按位配对，公共前后缀外的中段做
    字符级高亮（`dv-ch` 色块）；纯增删 / 一致 / 中段过长不配对，保持整行着色；
  - `mount(box, {path, diff})`：事件委托（视图切换 / 折叠段就地展开），切换保持展开状态
    与滚动位置；换文件重置折叠状态、保留视图偏好。
- `scripts/web/app.js` `loadConfirmDiff` 成功路径改调 `ATBDiffView.mount`；渲染层缺失时
  回退原纯文本 `<pre>`（优雅降级）；加载「正在读取差异…」/ 失败「差异读取失败：…」+ 重试、
  空差异「（与 HEAD 一致…）」语义与文案保持不变。
- `scripts/web/i18n.js`：新增键 `统一` / `并排` / `视图切换` / `（新文件，未纳入版本控制）` 与
  动态键 `⋯ 展开 ◇ 行未变更上下文 ⋯`；现有差异相关键沿用不改。行内容置于 `CODE`
  （翻译层跳过用户数据），界面文案由 MutationObserver 翻译层接管。
- `scripts/web/style.css`：`dv-*` 样式（行背景 / 行号列 / 标记列 / 折叠操作行 / 分栏分隔 /
  字符级色块），颜色走 `--dv-*` 变量，浅色 + `prefers-color-scheme: dark` 两套；长行
  `white-space: pre` + 容器横向滚动，不撑破面板。
- 测试：`scripts/tests/req-20260916-006.test.mjs`（解析 / 折叠 / 新文件 / 两视图 / 字符高亮 /
  vm 假 DOM 挂载行为 / i18n / 接线与样式契约），并扩展 `i18n-coverage.test.mjs` 把
  diff-view.js 纳入中文片段覆盖卡点。

**待确认项的落地取舍**（README「待确认」未获人工批复，按验收标准取全覆盖实现）：
并排视图与字符级高亮**纳入本期**（默认统一视图、高亮默认开启，无开关）；折叠保留行数
头尾各 3、触发阈值 8 行（与 ui-demo.html 一致）；超长 diff 不截断不分页（折叠 + 横向滚动
兜住，服务端口径不变）；复制入口不新增（行号 / 标记列 `user-select: none`，选内容不带行号）。

**开源选型（REQ-20260909-015）**：自研。理由（三选一之「无合适库」）：成熟 diff 渲染库
（如 diff2html，BSD-3-Clause）要求输入为标准 unified diff，无法表达本项目「新文件 = 提示行 +
分隔行 + 全文」的服务端格式，且不支持 hunk 内长段上下文折叠与折叠状态跨视图保持，也不含
本项目所需的字符级配对口径；以依赖方式引入还需为无构建步骤的纯脚本前端另建打包链，
覆盖度不足且引入成本高于约 300 行的自研渲染层。未引入开源库，不创建 licenses.md。

## 风险与边界

- 服务端零改动：不新增接口、不改 diff 文本来源；失败 / 空 / 加载三态语义与文案保持。
- 旧浏览器：可选链与 WeakMap 已在现有代码使用，无新增兼容面；渲染层缺失时回退 `<pre>`。
- 翻译层：行内容全部在 `CODE` 内（跳过翻译），仅界面文案入词典；i18n 覆盖测试已扩到新文件。
- 超长 diff：折叠段不渲染中间行，DOM 规模受折叠控制；后续若需分页 / 截断属服务端口径变更，
  另立条目。
