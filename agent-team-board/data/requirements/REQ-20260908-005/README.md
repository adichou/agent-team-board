# REQ-20260908-005 详情页面高度不要超过列表，要低于状态筛选行

- 状态：in-progress（已认领实施）
- 创建：2026-09-08T01:53:01.626Z

## 描述

**问题**：需求模块在窄屏（≤1020px，含桌面端内置浏览器面板）以覆盖式抽屉打开「详情页面」时，
抽屉为 `position: fixed; top: 0; right: 0; bottom: 0` 的全视口高度覆盖层——比左侧列表区域更高，
并把顶栏、模块导航、模块副标题与「需求状态筛选条」（第四行 `#filterBar`）全部盖住；配套遮罩
`#mask` 同样 fixed 全视口，把状态筛选行压暗并拦截点击。

**期望**：详情页面（含其遮罩）只覆盖状态筛选行之下的工作区：

- 详情抽屉顶边位于状态筛选行下方（与列表区顶对齐），底边与列表区底对齐，高度不超过列表；
- 状态筛选行及其以上的四行保持可见、可点击（详情打开时可直接切换筛选档）。

宽屏（>1020px）列表与详情并排、等高，不受影响；讨论单详情抽屉（`#oncallDrawer`）是独立
「讨论单详情」页面，不在本条范围（如需同规则另行登记）。

## 验收标准

- [ ] 窄屏（≤1020px）详情抽屉定位基准为需求工作区（`.req-view`），顶边低于状态筛选行，高度与列表区一致，不再全视口高。
- [ ] 窄屏遮罩 `#mask` 与详情同域（工作区内），状态筛选行及其以上不被压暗、不被拦截点击。
- [ ] 宽屏列表 + 详情并排布局、滑入动画与「← 返回」入口行为不变。
- [ ] 现有布局契约测试（layout / workbench-layout 等）不回归。
