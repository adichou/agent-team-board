# REQ-20260829-001 看板页面自适应布局，铺满整个窗口

- 状态：submitted（待人工接受）
- 创建：2026-08-29T15:35:31.712Z

## 描述

Status Board 页面（`scripts/web/index.html` + `style.css`）当前布局问题：

- 四列高度只按内容收缩（`.col { min-height: 200px }` 且 `.board { align-items: start }`），空列只有 200px 高，视口下方约 2/3 是空白背景，看板没有铺满窗口；
- `.board { overflow: auto }` 让整个看板区纵向滚动，而不是列内滚动；
- 窗口尺寸变化（桌面拖拽 resize、内嵌浏览器面板宽度变化）时，布局没有"占满可用空间"的自适应行为。

期望：看板铺满整个窗口（顶栏 + 四列占满视口高度与宽度），列内滚动，窗口任意尺寸下自适应、无大片空白。

## 验收标准

- [ ] 任意窗口尺寸下，页面无纵向页面级滚动条，看板区域（四列背景）铺满视口，无大片空白
- [ ] 列高 = 视口高度 − 顶栏高度；卡片超出列高时仅该列内部滚动，列头保持可见
- [ ] 窗口宽度拖拽变化时布局即时跟随：≥ 四列最小宽度（约 980px）时无横向溢出
- [ ] 窄窗口下不破版：允许降级（横向滚动或收窄列距），顶栏内容不错行、抽屉与新建弹窗仍可用
- [ ] 空看板（0 卡片）与多卡片两种数据下均满足上述表现
- [ ] 深色 / 浅色模式下均正常
