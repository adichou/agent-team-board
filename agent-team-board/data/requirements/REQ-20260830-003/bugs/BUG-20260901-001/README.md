## 修复方案（待对齐）

1. **恢复失败跳过条款**（兼容两阶段语义）：在 dev.md 循环模式一节加回——「阶段一出方案或阶段二实施中失败

   （待对齐 / in-progress）交人工处置」；SKILL.md 调度规则的 loop 条目同步补「失败跳过」语义（当前也缺失）。

   表述「全部出完方案（或没有 accepted）即终止」保留在正文，测试断言改为语义匹配（`没有 accepted|全部出完`），
   避免措辞微调再误报。
3. **测试**：loop-mode.test.mjs #2/#3 断言按上述语义修订后跑绿；其余 5 条不动；全部八套既有测试回归。
