# REQ-20260911-001 修改需求的对话框改为使用侧拉框，参考新建条目界面

- 创建：2026-09-11T00:42:31.941Z
- 流程状态以系统维护的 status.json 为准。

## 描述

把需求卡片及需求详情中的「修改」入口打开的居中编辑对话框改为右侧侧拉面板，外观和开合体验参考现有「新建条目」。用户可在保留看板上下文的同时修改标题与描述，避免同类表单容器形态不一致。

### 已核实的现状与范围

- `scripts/web/app.js` 的 `editItem` 为卡片和详情共用入口，仅允许 submitted（待接受）条目编辑；先经 `/api/item/{id}/doc/README.md` 读取 README，由 `extractDocSection` 截取描述节，再交给 `uiEditForm` 打开居中弹窗和遮罩。卡片入口由 `bindRenameButtons` 以 `data-rename-id` 绑定并 `stopPropagation`，避免触发卡片点击打开详情。
- 当前字段为标题（最长 120 字，`maxLength=120`，Enter 发起保存）和描述（多行，Enter 仅换行）；保存走现有 content 接口，标题与文档首行同步，描述整体替换需求「## 描述」节（Bug 口径为「## 现象」，见 `descHeadingOf`）。空标题拒绝提交；描述可空；无变化提示且不写入；保存异常由 `uiEditForm` 捕获并保持弹窗内容可重试。
- 现状读取失败或 README 缺描述节时仅以 toast 提示且不打开任何编辑容器；保存成功后 toast 提示并 `poll()` 刷新看板、`refreshDrawer()` 刷新打开中的详情；同屏输入弹窗由 `promptActive` 保证至多一个。
- `scripts/web/index.html` 的新建条目 `#modalWrap` 已采用 `.side-panel`：右侧贴边通高、常驻头部（标题/说明/✕）、内容区独立滚动、无遮罩；`scripts/web/style.css` 中宽度为 `min(560px, 92vw)`，640px 及以下全宽。
- 本项明确交付需求的两处修改入口，保留权限、字段、接口与状态规则，不增加新建表单的类型选择、截图或创建按钮。现有 `uiEditForm` 保存中仅禁用保存按钮、仍允许 Esc/取消/点遮罩关闭，本项「保存中暂时禁止修改字段与关闭」为新增交互。Bug 使用同一编辑函数，其是否同步迁移为侧拉面板待确认；开发时至少保证 Bug 编辑不回归。design 和 test-cases 留待开发阶段。

## 界面布局

右侧贴屏幕边缘通高，宽度及窄屏断点对齐新建条目，主界面不压暗、不新增全屏遮罩。头部常驻，显示「编辑 REQ-…」、仅待接受可编辑的简短说明和有可访问名称的关闭按钮。内容区独立滚动，顺序为标题、描述、反馈消息、取消与保存操作；沿用新建条目的字段间距、按钮、边框、投影和深浅色变量。长编号可换行，关闭按钮不被挤出，窄屏不横向溢出。

## 交互行为

1. 卡片修改按钮不触发详情打开；详情修改按钮打开同一面板。重复点击同一入口不叠加面板，读取完成预填标题和描述并聚焦标题。
2. 点击关闭、取消或 Esc 放弃本次未保存输入，不发写请求；点击面板外不关闭。重新打开读取当前已保存内容。关闭后焦点返回发起按钮，详情入口关闭编辑后仍保留详情；Esc 一次仅关闭最上层面板。
3. 标题输入 Enter 发起保存，描述输入 Enter 换行；空白标题提示「标题不能为空」，无变化提示「标题与描述均无变化」并保持面板。描述允许为空且提供可后续补充的提示。
4. 保存中禁止重复提交并暂时禁止修改字段与关闭，避免未完成请求被误认为取消；失败恢复操作且保留草稿，用户可重试或取消。成功关闭面板、提示已更新并刷新卡片和详情。此处为本需求目标交互，不表示现有弹窗已经实现全部行为。
5. 打开面板不切换当前模块。读取请求和保存请求必须绑定打开时的项目与条目；项目或条目切换时不可把旧响应写入新面板。跨面板打开时草稿取舍策略待确认，不能静默覆盖正在保存的数据。

## 状态反馈

- 正常：展示预填内容和可用保存按钮，成功后显示条目编号及更新提示。
- 空：描述章节存在但内容为空，显示可留空提示；标题为空时校验拦截。缺少描述章节属于错误，不能当空描述覆盖文档。
- 加载：读取期间面板内显示「正在读取描述…」，禁用表单与保存，保留关闭入口；保存期间显示「保存中…」，阻止重复操作。
- 失败：读取失败或缺少章节显示原因和重试/关闭入口，不展示可提交的伪空表单；保存失败显示错误、保留原输入并允许重试。若条目已非待接受，由既有服务端权限校验拒绝并提示，不改变条目状态。

## 验收标准

- [ ] 待接受需求的卡片和详情修改入口均打开右侧面板，不再出现原居中对话框及全屏遮罩；其他状态的编辑限制不变。
- [ ] 面板宽度、常驻头部、滚动内容区、字段样式及窄屏布局对齐新建条目；640px 及以下全宽，长内容和长编号不遮挡关闭入口。
- [ ] 正确预填标题与描述，标题最长 120 字且空白不可提交；描述支持多行和清空；无变化不写入，README 其余章节保持不变。
- [ ] 点击卡片编辑不误开详情；重复打开不叠加；关闭、取消及 Esc 不保存且焦点返回入口；点击外部不关闭；从详情打开时 Esc 只关闭编辑层。
- [ ] 读取中禁用提交但可关闭；读取失败/缺节明确报错且能重试；保存中禁止重复提交与关闭，失败保留草稿可重试，成功刷新展示并提示。
- [ ] 所有读写绑定正确项目和条目，迟到响应不污染其他面板；服务端拒绝非待接受条目的修改时可见错误且不丢草稿、不越权变更状态。
- [ ] 深浅色及键盘操作可用，标题 Enter 保存、描述 Enter 换行，表单有标签、反馈可被辅助技术读取；共用编辑入口的 Bug 功能不回归。
- [ ] ui-demo.html 可离线直接打开，具有正常/空/加载/失败的可交互状态，以及保存成功、失败重试和关闭行为。
