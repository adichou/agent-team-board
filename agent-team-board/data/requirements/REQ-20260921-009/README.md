# REQ-20260921-009 需求和 bug 电子流和 Github Issue 同步管理

- 状态：submitted（待人工接受）
- 创建：2026-09-21T01:32:36.101Z

## 描述

1、创建需求或 bug，同步创建 github 上的一条 issue，并标上创建者账号
2、需求或 bug 进入已接收，已计划和开发中，待测试和已完成的话，均同步状态到 issue 中，已完成就是关闭 issue，其他状态看看有什么方案。同步状态要采用超时机制，不能因为 git 长时间不响应就暂停队列。同步失败的条目要记录下来，并在任务模块中通过Github 同步失败任务页签显示每个失败同步的条目和原因，并提供一键批量重试。
3、在需求模块中提供拉取其他创建者创建的 issue的状态，并在本地展示，要跟当前用户创建的隔离。展示时除了展示 issue 的信息和状态，还要展示 issue 创建者的账号及邮箱，方便联系沟通。
4、提供 AI 对比提示词，可以对比其他创建者的 issue 和当前创建者的有没有重复的。该功能需要在创建需求或 bug 的时候提示用户触发同步和 AI 对比，以免重复提需求或 bug。对比结果可以通过发给对应的创建者，通知其不要重复开发，或将需求尽快开发。
5、本地已经创建的需求或 bug，在设置模块中提供一键同步到 Github Issue 的功能，失败的在任务模块中显示，参考前面的 2 中提及的机制。
