# REQ-20260909-001 任务设置中仅保留对 Agent 隐藏的配置，其他的全删掉

## 描述

精简「任务设置」入口指向的「设置 → 批量任务」区域，只允许用户配置执行 Agent 是否在任务启动选项中隐藏。删除该区域的子代理模型输入框、推理强度选择框、默认智能档建议及相关说明；保留必要的分组、Agent 名称、隐藏开关与保存反馈，减少启动任务前的配置负担。

本需求中的「隐藏」是从对应任务启动选项中隐藏 Codex 或 Zcode，不是对 Agent 隐藏配置内容。按现有代码中的批量完善、批量开发两个类别分别保存；不删除任务、历史批次或讨论记录，也不扩大为删除整个设置页面的其他独立设置。

### 已核实的项目依据

- `scripts/web/app.js` 的 `taskSettingsHtml` 当前按批量完善、批量开发展示执行 Agent、子代理模型、推理强度、是否隐藏四列，`taskSettingsGo` 跳转此设置区域。
- `scripts/lib/task-settings.mjs` 支持分别保存两个任务类别的可见 Agent 列表，并允许全部隐藏；保存接口支持只更新 `agents`，保留其他已有字段。
- 现有启动区在所有 Agent 被隐藏时禁用启动并提示取消隐藏，历史任务不受影响。

### 范围及待确认事项

此次明确删除的是任务设置中的其他可编辑配置及其界面文案。是否进一步移除底层模型/档位存储字段、已有派发提示词中的参数以及改为完全使用执行端默认值，原始需求未明确，标记为**待确认**。在确认前，保存隐藏配置不得清空或重置现有模型/档位，也不得改变进行中任务的配置快照。开发阶段需核对该问题，不凭空选择新的执行参数。

### 界面布局

保留现有「任务设置」入口与「批量任务」分区标题。正文使用一句说明「隐藏后，该 Agent 不出现在对应任务的启动选项中」。下面纵向排列「批量完善」「批量开发」两个分组；每组固定 Codex、Zcode 两行，仅包含 Agent 名称和「隐藏」复选框。底部提供「保存」及就近状态反馈。窄屏保持两列可操作，不需要横向滚动。删除原入口提示中模型、推理强度的描述。

### 交互行为

勾选表示隐藏，取消表示可见。编辑为草稿，点击保存成功后才作用于后续任务启动选项；不同任务类别互不影响。加载已有配置时复选框正确回显。允许一个类别全部隐藏，保存后该类别无可选 Agent、启动不可用，并提供返回任务设置取消隐藏的提示。隐藏某 Agent 不删除历史任务、运行记录，也不停止当前执行。用户可重新取消隐藏并保存恢复启动选项。

### 状态反馈

- 正常：显示保存值，修改后提示「有未保存的更改」，保存成功显示「已保存」。
- 加载：显示「正在加载任务设置」，禁用编辑与保存，避免未加载完成覆盖配置。
- 空状态：尚无保存配置时按现有默认两个 Agent 均可见展示；某类别全部隐藏时明确显示该类别无可用 Agent，避免与读取失败混淆。
- 失败：加载失败显示错误及「重试」；保存失败保留用户草稿，显示错误且允许重试，不误报成功。
- 保存中：按钮显示「保存中…」并禁用重复提交，完成后恢复。

## 验收标准

- [ ] 任务设置只剩两个任务类别的 Agent 隐藏配置及必要保存操作；模型、推理强度控件和相关提示均移除。
- [ ] Codex、Zcode 名称清晰，勾选隐藏的语义明确，两个类别独立保存并正确回显。
- [ ] 未保存变更不改变启动选项；保存成功后新增任务只显示对应类别可见的 Agent。
- [ ] 允许全部隐藏，相关启动入口禁用并提示取消隐藏；恢复任一 Agent 后可重新选择。
- [ ] 保存隐藏设置不重置原模型/档位字段、不改写运行中任务配置、不删除历史记录。
- [ ] 加载及保存中禁止重复操作；加载失败可重试，保存失败保留草稿且不报成功。
- [ ] 无历史设置时两个 Agent 默认可见；全部隐藏与加载失败有不同提示。
- [ ] 任务设置入口说明同步精简，页面内不残留被删除配置的空列或占位区域；窄屏无需横向滚动。
- [ ] README 的演示链接可直接打开，离线完成隐藏切换、保存、恢复和正常/空/加载/失败状态演示。
- [ ] 底层模型与档位策略的待确认事项在开发前核实并记录；不将未确认推测写成既有事实。
