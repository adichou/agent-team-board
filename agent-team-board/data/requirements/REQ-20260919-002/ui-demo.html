本演示覆盖点（点击展开）
  • 布局对照：现状卡片问题全平铺、四按钮同权重 vs 优化后信息分层、主次操作分组、已答折叠、区头计数强调。
  • 侧拉面板：现状无进度徽标、固定 2 行答复框 vs 优化后常驻「未答 x/y」进度、答复框随内容增高。
  • 交互链路：补决策 → 草稿保存（可只答部分）→ 决策齐备 → 复工；未答 > 0 复工禁用；确认完成二次确认防呆。
  • 状态反馈：正常 / 空 / 加载中 / 加载失败（错误条 + 重试）四态切换；面板读取中 / 失败 / 表单三态；保存失败输入保留。
  • 深浅色切换；窄屏（≤640px）面板全屏——可直接缩小浏览器窗口体验。
