# REQ-20260910-017 新建条目中支持对截图进行双击放大查看

- 创建：2026-09-10T07:26:52.045Z
- 状态以系统维护的 status.json 为准。

## 描述

用户新建需求或 Bug、上传或粘贴截图后，应能在提交前双击缩略图查看大图，核对截图文字和内容，再回到原表单继续填写。预览仅查看本次表单已添加的图片，不创建条目、不新增附件、不改变顺序或文件内容。

### 已核实的现状与范围

`scripts/web/index.html` 的新建表单在描述下方设置截图区，包含上传入口、计数、缩略图和移除按钮；`scripts/web/app.js` 的 `renderShots()` 当前只绑定移除事件，尚未绑定双击预览。文件上传与剪贴板路径共享 `newShots`（含文件名与 dataUrl）。需求与 Bug 提供截图，讨论类型隐藏截图。当前最多 9 张、单张 8MB 的限制保持现有口径。

已有条目文档的 `linkupDocImages()` 支持点击放大，但本需求针对创建前的本地截图。新建面板最终外观与同期侧边栏需求的集成结果待确认；本需求要求无论采用弹窗或侧栏，大图均覆盖在创建表单之上。不要求新增缩放倍率、图片编辑、下载或上一张/下一张功能。

### 界面布局

截图区继续放在描述下方、创建操作上方。缩略图保留文件名及独立移除按钮，补充“ 双击查看大图 ”提示，提供可用键盘触发的“查看大图”入口。预览层采用全屏遮罩，顶部显示当前文件名与关闭按钮，中心按原比例完整展示图片，宽高不超出可视区域；窄窗口下文件名可截断，但关闭按钮始终可见。

### 交互行为

- 双击某张缩略图，打开对应图片；单击不提交表单。上传与粘贴的截图均适用，多图时必须与被双击的图片一致。
- “查看大图”按钮通过点击或 Enter/Space 打开，预览打开后焦点进入关闭按钮；焦点在预览内循环。
- 点击关闭按钮、遮罩空白处或按 Escape 仅关闭大图，恢复原表单和触发点焦点；点击图片本身不关闭。Escape 不应继续关闭新建表单。
- 关闭后标题、描述、类型、附件数量与顺序均保持。移除按钮不触发预览；预览中的背景表单不可操作，不允许误触创建。
- 关闭/切换图片时忽略旧加载结果，避免再次打开后显示上一张图片。退出整个新建表单时同步清理预览。

### 状态反馈

正常显示目标大图与文件名；读取或解码期间显示“图片加载中”，保留关闭入口；无法加载时显示“图片无法加载”及重试、关闭按钮，重试仅重载当前图片，不重复添加附件。无截图时保留添加提示，不展示无效预览入口。失败和关闭都不清空用户填写内容。

## 界面展示

[打开可交互演示](./ui-demo.html)。单文件演示采用内联 CSS/JS 和内嵌示例图，无网络或构建依赖。表单依次展示类型、标题、描述和缩略图；双击图片或使用“查看大图”打开遮罩，关闭/Escape 返回表单；顶部演示控件可切换正常、空、加载和失败状态，失败可重试。演示为本需求的交互示意，不代表新建面板最终集成外观；示例截图为虚构演示内容。

## 验收标准

- [ ] 新建需求及 Bug 时，文件选择与粘贴得到的截图均可双击放大；讨论类型不出现截图入口。
- [ ] 至少两张不同截图分别双击时，预览图片与文件名一一对应；单击和移除操作不误开预览或提交表单。
- [ ] 大图保持比例并适应视口，窄窗口下关闭按钮可见，背景表单不可操作。
- [ ] 关闭按钮、遮罩空白处、Escape 均只关闭预览，图片本身不关闭；表单字段、附件数量及顺序保持不变。
- [ ] 可用键盘入口打开大图，焦点进入预览且不会落到背景，关闭后回到触发入口。
- [ ] 正常、无截图、加载中、加载失败均有明确反馈；失败可重试及关闭，加载中关闭后不会被迟到结果重新打开。
- [ ] 关闭整个新建面板后不存在遗留遮罩或图片；重新打开遵守现有表单初始化行为。
- [ ] 不更改既有截图格式/大小/数量校验与提交内容；已有条目文档的图片查看行为不受影响。
- [ ] ui-demo.html 可直接离线打开，双击、键盘入口、关闭、状态切换和失败重试均可操作。
