# 测试用例 — REQ-20260910-017 新建条目中支持对截图进行双击放大查看

> TDD 流程：先在这里列出用例并跑红，再实现代码跑绿。
> 前端测试：`node scripts/tests/new-shot-preview-20260910-017.test.mjs`（vm + 模拟 DOM，参照 item-shot-ui.test.mjs）。

| # | 用例 | 优先级 | 结果 |
| -- | ---- | ------ | ---- |
| U1 | 静态契约：预览层节点（role=dialog / aria-modal / 名称 / 关闭按钮 / 内容区）常驻 index.html；样式覆盖新建侧拉面板（z-index 更高、fixed 全屏）、文件名截断、关闭按钮不收缩、图片等比不超视口；缩略图渲染「查看大图」按钮（type=button）与「双击查看大图」提示 | 高 | ✅ |
| U2 | 双击打开与一一对应：双击第 N 张缩略图打开第 N 张（文件名与 dataUrl 对应）；双击落在移除 / 查看按钮上不触发；单击不开预览不提交；文件选择与粘贴入列共用同一列表均可预览 | 高 | ✅ |
| U3 | 键盘入口与焦点：「查看大图」按钮 click 打开（原生按钮 Enter/Space 可达）；打开后焦点进入关闭按钮；Tab / Shift+Tab 在预览内循环不落背景；关闭恢复触发点焦点 | 高 | ✅ |
| U4 | 关闭行为：关闭按钮 / 遮罩空白 / Escape 只关预览且点击图片本身不关闭；Escape 不连带关闭新建面板（一次只关一层）；关闭后标题 / 描述 / 类型 / 附件数量与顺序不变 | 高 | ✅ |
| U5 | 迟到结果忽略：关闭或切换图片后，旧加载的 load / error 回调不回写新预览（token 失效机制） | 中 | ✅ |
| U6 | 加载与失败反馈：打开即显示「图片加载中」且保留关闭入口；加载失败显示「图片无法加载」与重试；重试仅重载当前图，不新增附件 | 中 | ✅ |
| U7 | 表单退出清理：closeModal / openModal 同步关闭预览，重开面板无遗留遮罩与图片 | 中 | ✅ |
| U8 | 空态与既有口径：无截图时不渲染预览入口；讨论类型隐藏截图区（既有行为不回退）；提交请求体 attachments 仍按顺序携带（预览不影响数据） | 中 | ✅ |
