# REQ-20260906-016 创建完需求和 bug 单后，要自动导航到对应单

- 状态：submitted（待人工接受）
- 创建：2026-09-06T04:01:29.942Z

## 描述

需求 / Bug 创建完成后（网页「＋ 新建」弹窗，或终端 /req、/bug 由 Agent 执行 `atb new`），Status Board 应自动导航到该单：打开其详情抽屉，人无需在四列卡片里再找。界面与交互设计见 design.md（纯前端：弹窗路径创建成功即 openDrawer；CLI 路径由 2 秒轮询检测新条目 id 并跳转，带「已定位新建条目」提示；首轮加载/切换项目/初始化只播种基线不跳转）。

## 验收标准

- [ ] 网页新建弹窗创建 REQ/BUG 成功后，自动打开该单详情抽屉；失败时弹窗保留并提示错误。
- [ ] 看板打开期间，CLI（/req、/bug）创建新单后，看板在一个轮询周期内自动跳到该单详情并提示。
- [ ] 页面首轮加载、切换项目、初始化看板不触发跳转；一次出现多条新单只跳最新一条。
- [ ] 新建弹窗或批量实施抽屉打开期间不抢跳，关闭后也不补跳。
