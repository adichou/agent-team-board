# REQ-20260908-012 Bug 单的说明文档中，针对引入来源单的描述需放置开头

- 状态：submitted（待人工接受）
- 创建：2026-09-08T02:56:04.286Z

## 描述

参考 BUG-20260907-017 的做法，类似 BUG-20260908-001 这样是不对的。

**现状**：REQ-20260830-004 确立的引入来源规范口径是「修复时把来源写入 Bug README **末尾**『关联（引入来源）』节（样式见 BUG-20260830-001）」，该口径同时落在三处流程文档并由静态契约测试守护：

- `skills/agent-team-board/SKILL.md`「数据规范」节（「写入 Bug README 末尾『关联（引入来源）』节」）；
- `commands/bug.md` 末尾提示（「修复时在 Bug README 末尾『关联』节补写 `- 引入来源：…`」）；
- `commands/dev.md` TDD 第 4 步（「写入 Bug README『关联』节」）；
- `scripts/tests/traceability.test.mjs` R2/R4/R5 断言（要求 /dev 与 SKILL.md 含「关联（引入来源）」表述、样例 BUG-20260830-001 有 `## 关联` 节）。

**问题**：按此口径，来源归因被压在 Bug 说明文档（README.md）的最后——人工在 Status Board 详情抽屉的「说明」页或编辑器里复核时，必须读完全文（现象/复现/期望行为/根因）才能看到该缺陷由哪个条目引入。BUG-20260908-001 即按现行口径把来源只写在末尾 `## 关联（引入来源）` 节，打开文档第一屏完全看不到归因。

**期望做法（正例）**：BUG-20260907-017（位于 `docs/agent-team-board/requirements/REQ-20260907-003/bugs/BUG-20260907-017/README.md`）——头部元信息区紧跟「归属需求」行放置来源行，打开即见：

```
- 状态：in-progress（已上报，待人工确认）
- 归属需求：REQ-20260907-003
- 引入来源：REQ-20260907-003（经 `atb list` 核验存在；排查过程见「根因」）
- 创建：2026-09-07T15:36:59.950Z
```

**需求**：把「引入来源描述放置 Bug README 开头」确立为新规范——修复阶段归因时，来源行写入 README 头部元信息区（「归属需求」行之后、「创建」行之前，样式同 BUG-20260907-017），并在 SKILL.md、commands/bug.md、commands/dev.md 与 `scripts/tests/traceability.test.mjs` 中同步改口径。REQ-20260830-004 的其余规则全部保留不变：登记阶段（/bug）不填引入来源、修复阶段三选一（REQ-/BUG-/未定位）、来源 ID 经 `atb list/show` 核验、未定位须附排查过程、禁止编造、根因分析与 test-report 同样写明来源。

## UI（Status Board 详情抽屉「说明」页）

### 交互行为

- 既有动线不变：列表点 Bug 卡片 → 抽屉打开（「加载中…」占位）→ 点「说明」tab → `loadDoc('README.md')` 拉取原文并整页渲染，滚动位置停在顶部。来源行随头部元信息一起出现在首屏，无需滚动、无需点击锚点。
- 复核动线（本需求要优化的点）：打开 Bug 抽屉「说明」页 → 第一屏头部列表读到「引入来源」→ 需要核查排查过程时，按来源行括号内指引（如「排查过程见『根因』」）向下读对应章节；末尾「关联」节仅在有其他补充关联时才出现。
- 在编辑器里直接打开 README.md 时同理：来源行位于头部元信息区第 4 行（「归属需求」之后、「创建」之前），打开文件第一屏可见。
- 不新增任何按钮、接口、事件与快捷键。

### 状态反馈

- 既有反馈全部保持：抽屉打开时「加载中…」占位；文档读取失败时 `toast(e.message)`（`loadDoc` catch 分支）；2 秒轮询按签名比对刷新抽屉，内容未变不重渲染、不打断阅读。
- 来源行无独立加载态/错误态：它与头部其余元信息行同属一次 `renderMd` 输出，文档加载成功即整组出现。
- 来源行的三态取值直接以文本呈现于头部：`REQ-…（引入了什么…）` / `BUG-…` / `未定位（排查过程：…）`；「未定位」的排查过程较长时该行允许折行，仍保留在首屏头部列表内，不折断为独立小节。
