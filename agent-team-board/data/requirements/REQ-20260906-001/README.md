# REQ-20260906-001 需求和文件的切换栏要换个样式和颜色，以便和下方的需求分类切换栏区分

- 状态：已接受，实施中
- 创建：2026-09-05T16:20:01.519Z

## 描述

### 界面布局与现状问题

页面共有两组「切换栏」：

1. **视图切换栏**（顶栏，`nav.view-tabs` > `button.view-tab`，项：需求 / 文件）：
   桌面端（>1020px）是顶栏中的分段控件（灰底圆角槽 + 激活项白色胶囊）；
   ≤1020px 窄屏下竖排固定在左缘顶部、顶栏正下方。
2. **需求分类切换栏**（看板左缘竖排条，`nav.board-tabs` > `button.board-tab`，项：待接受 / 已接受 / 开发中 / 已完成，
   即按状态列快速切换；仅 ≤1020px 显示）：
   竖排钉在看板左缘，位于视图切换栏下方，二者构成一条统一的左侧工具栏。

> 说明：登记时猜测的分类切换栏是「全部/需求/Bug」筛选栏，代码中并不存在；
> 看板内实际的需求分类切换栏即上述状态列快速切换条 `.board-tabs`。

问题：≤1020px 下两组切换栏上下相邻，成员按钮样式**完全相同**——同为 26px 宽、
面板底色、灰边框、9px 圆角竖排按钮，激活态都用主题蓝 `var(--primary)` 填充白字，
无法一眼区分「上面一组是视图切换、下面一组是状态分类」。

### 期望的区分方式（克制、最小改动）

- 视图切换栏换用**专属强调色**（靛蓝，取自现有 REQ 徽章色系，浅色 `#4f46e5` / 深色 `#818cf8`，
  以新 CSS 变量 `--viewrail-accent` 承载，深浅色主题各定义一份）；
- 造型上视图切换栏改用**胶囊（stadium，全圆角）**风格：未激活项透明底 + 靛蓝描边靛蓝字，
  激活项靛蓝填充白字；分类切换栏**保持不动**（面板底、灰边、9px 圆角矩形、激活态主题蓝）。
- 桌面端分段控件同步换色：底槽染淡靛蓝、激活项由白胶囊改为靛蓝填充白字、未激活项靛蓝字。

### 交互行为（不变）

- 点击「需求 / 文件」切换视图，激活态高亮跟随当前视图（`data-view` 匹配）；
- ≤1020px 时视图切换组仍钉在顶栏正下方左缘（`top:100%` 包含块机制），分类条按
  `--viewrail-h` 让位，两组不重叠——本需求不改任何布局与 JS 行为，只改颜色与圆角/描边样式。

### 状态反馈

- 视图切换栏：当前视图项 = 靛蓝填充 + 白字；非当前项 = 透明底靛蓝字（桌面）/ 透明底靛蓝描边（窄屏）。
- 分类切换栏：维持原样（当前列 = 主题蓝填充白字）。
