# REQ-20260924-002 AI 总结与 AI 翻译任务面板增加终止任务功能

- 状态：submitted（待人工接受）
- 创建：2026-09-23T16:35:24.090Z

## 描述

AI 开发与 AI 分析任务面板已有「终止任务」（/api/batch/abort、/api/refine/abort），但 AI 总结（docs-summary）与 AI 翻译（docs-translate）面板进行中状态没有终止入口：人工停止执行子代理会话后，仍需手动执行 atb summary fail / atb translate fail 才能收尾释放独立锁（summary.lock / translate.lock 无超时自动接管，不收尾即悬挂、无法启动新一轮）。需求：两类面板进行中状态增加「终止任务」按钮（红色危险样式）与二次确认，确认后走既有 fail 收尾口径——run 置 failed、残留「正在总结/正在翻译」文件回退不悬挂、已完成文件保留可续跑、释放独立锁、全局任务面板移出该 run；终止后可立即重新启动（已回执完成的文件保留）。界面文案中英文同步（i18n.js）。

## 验收标准

- [ ] 任务模块「AI 总结」子面板：run 进行中（running）时出现红色危险样式「终止任务」按钮；已结束（done/failed）与空态不出现。
- [ ] 任务模块「AI 翻译」子面板：同上口径出现「终止任务」按钮。
- [ ] 点击「终止任务」弹出二次确认（与 AI 开发 / AI 分析终止同交互形态：危险确认文案 + 确认 / 取消；取消不产生任何状态变更）。
- [ ] 确认终止后走既有 fail 收尾口径：run 置 failed 并携带「人工终止」类原因；残留「正在总结 / 正在翻译」文件回退为待处理（不悬挂）；已回执完成的文件状态保留（跨 run 可续跑）；独立锁 summary.lock / translate.lock 释放。
- [ ] 终止后面板显示既有 failed 视图（中断原因 + 中断时间 + 锁已释放），全局任务面板（跨项目聚合区）不再出现该 run。
- [ ] 终止后可立即重新「AI 总结 / AI 翻译」启动新一轮，不提示锁占用。
- [ ] 在途执行子代理会话不受远端影响，需人工到对应会话停止——确认文案中明确提示（与 AI 开发 / AI 分析终止提示口径一致）。
- [ ] 新增界面文案在 scripts/web/i18n.js 中英文同步，i18n 相关测试通过；`npm test` 全量通过。

## 界面展示

两类子面板（AI 总结 / AI 翻译）共用同一交互形态，仅文案与锁名不同。以 AI 翻译为例，进行中状态在现有进度信息下增加「终止任务」按钮：

```
┌ 任务面板 · AI 翻译 ────────────────────────────────────────────┐
│ [进行中]  AI 翻译 · BLD-… · 执行 tr-… · 创建 …                  │
│ ▓▓▓▓▓▓▓▓░░░░░░░░░░░  3/8                                      │
│ 当前：README_en.md（正在翻译）                                  │
│ 锁：translate（独立锁…） · 执行会话 translate                    │
│ 进度由执行子代理经 atb translate file 逐文件回执…               │
│                                                                │
│                                              [ 终止任务 ]（红） │
└────────────────────────────────────────────────────────────────┘
```

点击「终止任务」弹出二次确认（同 AI 开发终止确认形态，文案按总结 / 翻译各自适配）：

```
┌ 终止 AI 翻译任务？ ────────────────────────────────────────────┐
│ 确认后本轮任务中断收尾：残留「正在翻译」回退、已完成文件保留、    │
│ 独立锁释放，可立即重新启动续跑。在途子代理需在对应 Agent 会话    │
│ 人工停止。                                                      │
│                                [ 取消 ]  [ 终止任务 ]（确认）   │
└────────────────────────────────────────────────────────────────┘
```

状态反馈：确认后面板随 2 秒轮询切换到既有 failed 视图（中断原因「人工终止…」+ 中断时间 + 锁已释放），按钮消失；取消则无任何变更。AI 总结子面板同构（按钮位置、确认弹层、failed 视图口径一致，文案为「正在总结 / atb summary file / summary 锁」）。
