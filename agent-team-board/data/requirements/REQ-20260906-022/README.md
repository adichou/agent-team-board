# REQ-20260906-022 批次结束后在看板提供创建下一批入口

- 状态：submitted（待人工接受）
- 创建：2026-09-06T14:23:27.176Z

## 描述

批量实施抽屉 Zcode 批次页签：批次已结束（finished）且无待处理项时，运行视图提供「创建下一批」按钮，复用现有创建流程（勾选范围、复制提示词）；未结束批次不显示，避免幂等返回旧批造成误导

## 验收标准

- [ ] 批量实施抽屉 · Zcode 批次页签：批次状态为已结束（finished）且待处理数为 0 时，运行视图显示完成通知与「创建下一批」按钮
- [ ] 点击「创建下一批」复用现有创建流程：以当前勾选集合为候选范围（未勾选时为全部可实施条目），创建成功后复制主调度提示词并自动切换到新批次（待启动）
- [ ] 未结束批次（待启动/执行中/已暂停/待核对，或已结束但仍有待处理项）不显示该按钮
- [ ] 极端并发下若接口幂等返回未结束旧批（created=false），提示如实说明「未新建批次」，不显示「已创建」造成误导
- [ ] 无可实施候选时点击按钮给出明确错误提示（先在看板接受条目），不创建空批次
