# REQ-20260922-005 AI 总结 LICENSE.md 时，要弹框让用户选择开源协议，提供一个表格罗列主流开源协议的定义，官网网址和优劣

## 描述

（dev-8 按需求标题补全，口径对齐 REQ-20260922-002 定稿）

### 背景与现状（代码事实）

- REQ-20260922-002 已合入：LICENSE.md 为单文件类发布文档（A1，不随语言集、不进 AI 总结 / AI 翻译——口径 B），仅人工在审查对话框编写，参与门禁计数（口径 C 必选）。选择哪种开源许可证由人工决定，002 明确不自动生成 LICENSE 内容——人工只能从零手打或从外部复制标准文本。
- 需求标题「AI 总结 LICENSE.md 时」在 002 口径 B（LICENSE 永不被 AI 总结）下无字面触发点；本单按「点击『AI 总结』按钮的时点」解读：用户发起 AI 总结（文档编写动作的起点）时，若 LICENSE.md 仍「未编写」，弹框引导选择开源协议——不推翻 002 口径（AI 仍不生成许可证文本），弹框写入的是内置标准文本（SPDX 权威文本），其后仍走人工「待审核 → 已审核」。

### 需求要点（原文落定）

1. 点击「AI 总结」时若 LICENSE.md 未编写：弹框「选择开源协议」，表格罗列主流开源协议的**定义、官网网址、优劣**（含宽松 / 著佐权属性标注）；
2. 选中协议 → 确认：以该协议标准文本写入 LICENSE.md（复用既有 `/api/build/docs/save` 白名单通道），LICENSE.md 转「待审核」，随后继续启动 AI 总结；
3. 「暂不选择」：不写盘、关闭弹框、照常启动 AI 总结；✕ / Esc / 遮罩关闭 = 不写盘也不启动总结；
4. LICENSE.md 已在盘（待审核 / 已审核）时点击「AI 总结」不弹框（行为与现状一致）。

### 范围边界

- 不改 REQ-20260922-002 定稿口径：LICENSE 仍不进 AI 总结 / 翻译提示词与账本；状态机（未编写 / 待审核 / 已审核）与门禁不变；写入后的审查 / 提交路径完全复用。
- 写入的标准文本含占位符（如 MIT 的 `<year> <copyright holders>`）：弹框明确提示需在审查时人工确认 / 填写，本单不做占位符自动填充。
- 协议目录（含标准文本）为内置静态数据，不联网获取；协议选型范围（MIT / Apache-2.0 / BSD-2 / BSD-3 / ISC / 0BSD / Unlicense / MPL-2.0 / LGPL-3.0 / GPL-3.0 / AGPL-3.0 共 11 项主流协议）见 design.md。
- 依赖引入的开源协议白名单（`OSS_LICENSE_WHITELIST`，REQ-20260909-015）是另一条线，本单不涉及。

## 界面展示

本需求涉及 UI（「AI 总结」触发的新弹框）。界面布局与交互：

- **布局**：模态弹框（与整体审查完结核对框同型）= 标题「选择开源协议（LICENSE.md 尚未编写）」+ 说明行 + 表格（列：协议 / 定义 / 官网 / 优势 / 劣势；行 = 协议名 + SPDX 标识 + 宽松或著佐权标注，单选；官网列超链接新窗口打开）+ 底部操作（「写入 LICENSE.md 并继续总结」主按钮（未选中禁用）、「暂不选择，继续 AI 总结」、✕ 关闭）。
- **交互**：点击「AI 总结」且 LICENSE.md 未编写 → 弹框打开并加载协议目录；选中行高亮、主按钮解锁；确认 → 写入 LICENSE.md（标准文本）→ toast 反馈 → 关闭弹框 → 继续 AI 总结启动流程；「暂不选择」→ 直接继续；✕ / Esc / 点遮罩 → 关闭不继续。
- **状态反馈**：正常（目录加载完成可选用）；加载中（「正在加载协议目录…」）；失败（错误提示 + 重试 + 「暂不选择」仍可用）；写入中（按钮「写入中…」禁用）；写入失败（toast 报错、弹框保留可重试）。

## 验收标准

### 协议目录与 API

- [ ] 服务端内置主流开源协议目录（11 项，见 design.md）：每项含 SPDX 标识、协议名、官网网址、定义、优势、劣势、著佐权属性；标准文本为 SPDX 权威文本（含占位符原样保留）。
- [ ] `GET /api/build/doc-licenses` 返回完整目录（元数据 + 标准文本）；目录为静态数据，读取不依赖网络与看板状态。

### 弹框触发与写入

- [ ] LICENSE.md「未编写」时点击「AI 总结」：弹框打开（表格含定义 / 官网 / 优劣），不立即启动总结；选中协议确认后 LICENSE.md 以标准文本落盘（经 `/api/build/docs/save` 白名单与 2 MiB 上限口径），状态转「待审核」，随后继续原 AI 总结启动。
- [ ] 「暂不选择，继续 AI 总结」：不写盘，弹框关闭，AI 总结照常启动；✕ / Esc / 遮罩点击：关闭弹框且不启动总结。
- [ ] LICENSE.md 已编写（待审核 / 已审核）时点击「AI 总结」：不弹框，行为与现状一致。
- [ ] 目录加载失败 / 写入失败：明确错误反馈（加载失败给重试、写入失败弹框保留可重试），「暂不选择」路径不受影响。
