## 描述

看板与 CLI 当前把两类批量任务称为「批量完善」「批量开发」，并衍生出「▶ 开始完善」「▶ 开始开发」等入口按钮。本需求做一次全面文案整改，统一改名为：

- 「批量完善」→「AI 分析」
- 「批量开发」→「AI 开发」
- 衍生入口按钮「▶ 开始完善」→「▶ 开始 AI 分析」、「▶ 开始开发」→「▶ 开始 AI 开发」（含 title / aria-label 等同源文案）

整改范围是**用户可见文案**（按钮、页签、徽标提示、弹窗、toast、空态、CLI 帮助与日志、i18n 中英文对照），不改变任何交互逻辑、布局结构、命令名、API 路径与状态机字段。任务模块（「任务」页签）的文案必须同步修改；需求模块中「开始完善」「开始开发」入口的文案也要同步修改；其余出现旧词的界面与输出一并全面排查整改。
