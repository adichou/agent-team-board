# REQ-20260906-021 文件模块支持文件切换自动换行模式

- 状态：accepted
- 创建：2026-09-06T14:03:25.665Z

## 描述

（本节由实施 worker 依据标题与现状补充：Status Board 文件视图（File Board）的
源码视图目前永远不换行——`.file-code pre` 按默认 `white-space: pre` 水平滚动，
行号槽 sticky 跟随（见 style.css「行号与代码两栏同字体行高对齐」注释）。遇到
长行文件（如未压缩的 JSON、长 URL 的 md 源码）时需要反复横向拖动滚动条阅读。

本需求：源码视图增加「自动换行」开关，且**换行设置在切换文件后保持**
（会话级记忆，不随换文件回退——即标题中的「文件切换」），与 md 的
「源码 / 渲染」记忆（`state.banner.mdSource`）同一模式。

### 界面与交互（UI 需求，接受即视为设计认可）

- **入口位置**：查看器工具条 `.file-viewer-acts` 内、「复制路径」左侧新增
  「自动换行」按钮；仅源码视图（含 md 的源码态）出现，渲染态 md 与图片
  预览不显示（与 md 切换按钮的出现规则一致）。
- **按钮状态**：按钮显示**目标态**（与 md 切换按钮「源码/渲染」同一惯例）：
  当前不换行时显示「自动换行」，已换行时显示「不换行」，并用
  `aria-pressed` 与选中态样式标识当前开/关；`title` 说明「设置在切换文件
  后保持」。
- **换行表现**：开启后长行在查看器宽度内软换行（`white-space: pre-wrap` +
  `overflow-wrap: anywhere`，超长无空格串也可断行），不再出现横向滚动。
- **行号取舍**：软换行下独立行号槽无法与折行后的代码保持 1:1 对齐，开启
  换行时行号槽整体隐藏（「路径:行号」复制暂不可用）；关闭换行即恢复行号
  槽与行号复制，两栏对齐关系不变。
- **跨文件记忆**：开关状态存于文件横幅状态（`state.banner.wrap`），切换
  文件 / 目录后新打开的源码文件沿用当前设置；切换项目或刷新页面重置为
  默认「不换行」（与现状一致，不引入持久化存储）。

## 验收标准

- [ ] 源码视图（含 md 源码态）工具条提供「自动换行 / 不换行」切换按钮，
      带 `aria-pressed` 状态与选中态样式
- [ ] 开启后长行软换行（含超长无空格串），无横向滚动；关闭恢复现状
      （不换行 + 行号槽 sticky 水平滚动）
- [ ] 换行设置在切换文件后保持（同一 `state.banner` 生命周期内），
      渲染态 md / 图片视图不受影响、不显示该按钮
- [ ] 开启换行时行号槽隐藏，关闭换行恢复行号与「路径:行号」复制
- [ ] 既有行为回归：默认不换行、hljs 高亮、行号复制、md 渲染切换不受影响
