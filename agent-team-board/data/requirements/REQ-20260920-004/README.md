# REQ-20260920-004 提供命令模块，提供 atb 所有命令的界面按钮下发

- 创建：2026-09-20T15:15:23.068Z
- 状态以看板实时记录为准；本文只描述需求，不改变条目状态。

## 描述

在看板（Status Board）新增「命令」模块：把 `atb` CLI 的命令以按钮形式分组呈现（不含 Oncall 咨询 / 讨论 / 增长三组，见「已核实的现状与范围」），用户在网页上选择命令、按提示填写参数后点「执行」，由服务端对当前选中的项目下发同一 CLI 入口（`node scripts/atb.mjs <子命令与参数> --dir <项目根>`），并在界面回显完整输出（stdout / stderr、退出码、耗时）。目的：不依赖终端也能使用命令面——尤其是各专用界面尚未覆盖的命令（如 `migrate`、`rebuild`、`pack`、`prune-locks`、`commit which` 等）——并为后续新增通用 CLI 命令提供统一的人工触发入口。

本模块是**通用兜底入口**，不替代已有专用界面：需求页的接受 / 计划 / 确认完成按钮、任务页批量面板、设置页 Git 工作流等保留不动；同一能力两处入口的行为与结果一致。

### 已核实的现状与范围

- 命令面以 `node scripts/atb.mjs help` 为唯一事实源，本模块覆盖的分组：数据与分发（`init` / `migrate` / `rebuild` / `pack`）、条目生命周期（`new req|bug` / `claim` / `rename` / `delete` / `status` / `report` / `move` / `prune-locks`）、批量开发（`batch create|next|check|summary|pause|records|delete`）、执行回执（`run receipt|release|autocommit`）、人工决策（`hold declare|list|show|answer|resume|cancel`）、挂起确认（`confirm list|show`）、批量完善（`refine create|next|done|fail|release|check|summary|pause|abort|records`）、查询（`list` / `show` / `commit log` / `commit which`）、服务（`serve`）、终端命令（`cli install|uninstall|status`）。
- Oncall 咨询（`oncall new|list|show|ask|answer|dispatch`）、讨论（`disc show|round|minutes`）、增长（`growth receipt|show|list`）三组**不纳入本模块范围**：Oncall / 营销（growth）已有专用深链视图，讨论经看板只读展示，均由专用界面或专用回执流程承载，不经通用命令模块下发；本模块命令清单的生成与校验须恒定排除这三组。
- 看板顶栏现有页签为 需求 / 发布 / 任务 / 设置（`scripts/web/index.html`，REQ-20260910-012 页签并入顶栏），另有 release / marketing / oncall / files 深链视图；当前没有任何通用命令入口。
- `scripts/server.mjs` 目前**没有**「执行 atb 命令」的通用 API——各界面操作分别走专用端点（`/api/init`、`/api/batch/*`、`/api/git/*` 等），服务端只在自动派发等内部链路以 `ATB_CLI_ABS` 绝对路径调用 CLI。本单需新增通用下发端点，具体接口设计留开发阶段（design.md）。
- `atb` 的 `--dir` 是全局旗标（进入子命令解析前剥离），指定看板项目根；命令模块按顶栏当前项目下发，与 `?project=` 数据源一致。
- 服务默认绑定 `127.0.0.1:8888`（`ATB_HOST` / `ATB_PORT` 可覆盖）；命令模块是本地人工入口，不新增远端暴露。

### 安全与权限边界

- **白名单下发**：服务端仅接受 `atb help` 已注册的子命令，未注册命令一律拒绝；参数以数组逐个传递给子进程（不经 shell 字符串拼接），本模块不得成为任意命令执行通道。
- **状态铁律不变**：网页是人工入口，经本模块执行人工专属命令（如 `atb status <ID> accepted|done`、`hold answer/resume`）等同人工在终端执行；Agent 侧权限边界（PreToolUse 状态守卫、认领锁）不因本模块放宽，也不为 Agent 提供任何绕行通道。
- **高危命令二次确认**：不可恢复或大范围影响的命令（`delete`、`status`、`batch delete`、`refine abort`、`migrate`、`rebuild`、`prune-locks`、`pack` 等）执行前必须弹确认框，展示完整命令与参数；取消则返回表单且参数保留。
- **不适合界面下发的命令**：`serve`（命令模块本身运行在 serve 启动的看板服务里，能打开界面即服务已在运行：版本一致时重复执行只是「复用现有实例」的空操作；磁盘代码较新时更会 kill 正在承载本次请求的服务进程并自动重启，导致响应丢失、界面断连）与 `cli install/uninstall/status`（面向本机终端 PATH 的安装操作）在界面中标注原因并禁用执行，引导用户去终端；完整禁用清单待确认。
- **并发与时长**：同一项目同一时间仅允许一个命令在途，执行期间禁用重复下发；长耗时命令（`pack`、`rebuild`、`run autocommit` 等）异步执行并给出进行中反馈，不得阻塞看板 2 秒轮询与其他模块操作。

## 界面布局

- 顶栏在「任务」与「设置」之间新增「命令」页签（位置可在开发阶段经人工确认微调）。
- 页面左栏：命令搜索框（快捷键 `/` 聚焦，对齐全局习惯）+ 按上述 CLI 分组折叠展示的命令按钮列表；按钮文本为命令名（如 `atb list`），保留英文原名不翻译。
- 右栏（所选命令详情，自上而下）：命令用途说明（取自 CLI help 语义）、参数表单（位置参数与常用选项逐项列出，必填项标注）、完整命令预览（等宽字体、随参数实时更新）、「执行」按钮、输出区（stdout / stderr 分区、退出码、耗时、复制入口）。
- 页面底部：本次会话的执行历史（命令、时间、结果状态），点击可回看该次输出，可一键清空。
- 高危命令按钮带醒目标识（文字标注「需确认」，不只靠颜色区分）；禁用命令按钮呈禁用态并在详情中说明原因与终端指引。

## 交互行为

- 点击命令按钮 → 右栏加载该命令说明与参数表单；必填参数缺失时「执行」禁用并就近提示；参数任何变化实时反映到命令预览。
- 点「执行」→ 高危命令先弹确认框（完整命令 + 影响说明）→ 确认后按钮禁用、显示「执行中…」→ 完成后回显输出：退出码 0 为成功态，非 0 为失败态并完整显示 stderr；带 `--json` 的命令输出提供格式化与原文切换（可选增强）。
- 执行失败可就地「重试」：以同命令同参数重新下发，表单参数不丢失。
- 搜索框实时过滤命令名与说明（分组内无匹配时该分组隐藏），清空恢复全部；键盘可访问命令列表、表单与执行按钮。
- 输出区与执行历史支持复制；切换命令或项目后，上一次输出保留在历史中可回看。
- 中英文：命令名与参数保持 CLI 原文；分组名、说明、按钮与状态反馈文案集中在 `scripts/web/i18n.js` 中英同步（BUG-20260912-001）。

## 状态反馈

- 正常：分组完整呈现本模块覆盖范围的全部命令（`atb help` 命令面，不含排除三组）；执行完成显示输出、退出码与耗时。
- 加载：进入模块读取命令清单时显示加载态；执行中显示进行中并禁用重复下发与页内其他执行入口。
- 空：搜索无匹配显示「无匹配命令」并给清除入口；命令本身无输出时明确显示「（无输出）」及退出码，不呈现为空白。
- 失败：清单读取失败显示原因与「重试」；命令执行失败显示退出码、stderr 原文与重试入口；服务不可达时提示并保留表单内容；高危确认被取消不算失败，回到表单原状。
- 项目态：当前项目未初始化看板时，依赖看板数据的命令给出先初始化引导（对齐设置页「初始化」能力），不静默报晦涩错误。

## 验收标准

- [ ] 顶栏出现「命令」页签；命令清单覆盖 `atb help` 全部分组与子命令（Oncall 咨询 / 讨论 / 增长三组除外，恒不出现），无虚构命令、无遗漏；分组结构与 help 一致，命令名不翻译。
- [ ] 每个命令展示用途说明；参数表单对必填项做校验（缺失时禁止执行并提示）；命令预览与实际下发内容一致。
- [ ] 服务端为白名单执行：仅 atb 已注册子命令可通过本模块执行，未注册命令被拒绝；参数以数组传递，不经 shell 拼接。
- [ ] 下发以 `--dir` 绑定顶栏当前项目；未初始化项目对依赖看板数据的命令给出初始化引导。
- [ ] 高危命令（至少含 `delete` / `status` / `batch delete` / `refine abort` / `migrate` / `rebuild` / `prune-locks` / `pack`）执行前有二次确认，确认框展示完整命令；取消后参数保留。
- [ ] `serve` 与 `cli install/uninstall/status` 不提供可执行入口，显示原因与终端指引（其余禁用项以待确认清单为准）。
- [ ] 执行期间同项目防重复下发；完成后 stdout / stderr / 退出码 / 耗时完整回显；失败可重试且参数不丢；无输出命令明确显示「（无输出）」。
- [ ] 长耗时命令不阻塞看板轮询与其他模块；执行异常中断（如进程被杀）有失败反馈，不悬挂在「执行中」。
- [ ] 清单加载中 / 失败、搜索无匹配、执行中 / 成功 / 失败各状态可验证；状态不只靠颜色区分。
- [ ] 既有专用界面按钮与行为不受影响；同一命令经本模块与终端执行结果一致。
- [ ] 界面文案中英文同步（`scripts/web/i18n.js`）；`ui-demo.html` 可独立打开并覆盖布局 / 交互 / 状态反馈演示。
