## 描述

在现有「讨论 / 需求 / 任务 / 文件 / 设置」模块导航中新增「营销」。沿用当前项目选择器，在营销内设置「概览 / 定位与定价 / 渠道与行动 / 效果与复盘」四个页签，后两页由关联需求交付，尚未实现时明确标注暂不可用。刷新恢复项目及营销页签。

定位档案包含产品简介、产品阶段（探索/验证/上线/增长）、目标市场与语言、目标受众、使用场景、痛点、替代产品、差异点、产品链接、阶段目标、主指标、预算和每周可投入工时。读取 README 仅形成草稿，不能把代码能力推断成市场需求已被验证。

证据条目包含类型（事实/假设/待确认）、内容、来源链接或访谈引用、采集日期。定价方案包括收费模式（免费/买断/订阅/按量/混合）、币种、周期、套餐权益、候选价格、成本与竞品依据、验证方法。未知价格留空，不生成无依据的确定价格。保存新版本保留历史；人工明确选择后成为当前方案，旧活动仍引用创建时绑定的版本。本模块记录方案，不修改商店或支付系统实际价格。

交互：首次显示「建立营销档案」；保存进行中禁重复提交，成功展示保存时间；切项目前有未保存内容时提供保存并切换/放弃/取消。选择历史版本只读查看；应用候选版本需要显式操作。营销档案的初始化由用户点击触发。
反馈：未配置显示引导；读取中显示加载态；验证错误定位字段；保存失败保留编辑内容和重试入口；并发冲突提示重新载入并保留本地草稿，不静默覆盖。

## 验收标准

- [ ] 无营销目录的项目可正常打开；显式初始化后保存并刷新，档案、页签和版本均可恢复。
- [ ] 同名但不同路径项目分别保存；切换项目、刷新、直接链接均不串数据。
- [ ] 定位、预算、证据类型、来源及定价字段可编辑；非法金额、缺少币种或订阅周期时给出字段错误。
- [ ] 候选方案不会自动成为当前定价；版本历史保留，活动历史引用不随当前价格改变。
- [ ] 并发修改返回冲突，失败不损坏旧文件、不丢弃编辑内容；历史项目不需强制迁移。
- [ ] 宽窄屏、深浅色、键盘操作和未保存切换行为符合界面约定。
