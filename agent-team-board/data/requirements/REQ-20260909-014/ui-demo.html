说明 / 设计 / 测试用例文档右键复制引用（路径 + 源行 + 原文）——仅演示，不连看板后端

当前文档状态模拟

作用于当前激活的文档页签；「加载中」1.2 秒后自动变为正常。

演示开关

操作指引

  1. 在右侧「说明 / 设计 / 测试用例」页签的文档内容上选中一段文字，右键 → 「讨论」：复制 原文 + 文档路径 + 源行范围。
  2. 不选中任何文字直接右键 → 「讨论」：复制 文档路径 + 右键落点段落的源行范围。
  3. 在列表 / 表格内选择文字：无法精确映射源行，按整段行范围降级复制并提示。
  4. 菜单打开后点外部 / Esc / 滚动 / 切页签 → 收起且不执行。
  5. 用左侧状态模拟切换 正常 / 加载中 / 失败 / 未创建，观察右键不再弹菜单。
