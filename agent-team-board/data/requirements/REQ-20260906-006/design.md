# 设计 — REQ-20260906-006 单号复制能力要通过一个“复制”按钮提供出来，去掉点击单号复制按钮的能力，太隐晦了。

## 背景

原先点击单号文字复制缺少明确提示，且反馈替换单号文字。本次改为可见的独立按钮。

## 方案

`itemIdHtml` 统一渲染单号文本和原生复制按钮，在卡片、详情标题和下属 Bug 三处使用。`bindCopyIdButtons` 仅绑定 `data-copy-id` 按钮，通过 dataset 获取单号并停止冒泡；单号文字不再具有复制监听器。

沿用 Clipboard API 和 execCommand 降级。等待写入及成功反馈期间禁用按钮，1200ms 后恢复；失败提示手动框选并立即恢复可点击，异常时也清理临时文本域。反馈始终在按钮内，单号保持不变。

单号与按钮组成不压缩、不换行的控件组，卡片头部与 Bug 行允许换行，Bug 标题弹性占用剩余空间。按钮使用现有主题变量、原生键盘语义、明确的 aria-label 和焦点轮廓。

开发接续：后台运行 `run-20260906-183630-bb3a` 已创建会话并认领，随后 CLI 因额度限制退出。用户要求继续后，当前主会话以同一条目 owner 续认并完成实现。保留后台失败结果，报告说明本次人工指示的接续，不冒充 CLI 正常完成。
