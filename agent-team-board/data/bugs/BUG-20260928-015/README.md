# BUG-20260928-015 发布运行失败后确认锁不回滚：计划被误锁为已发布、无法调整范围与重新提交

- 归属：独立 Bug（引入来源见 design.md）

## 现象

现象：BLD-20260927-001 点击发布并二次确认后，发布运行 BPUB-711ea71f 在 site-deploy 阶段失败（官网 content/ 双语成对文件缺失，即 BUG-20260928-013 所修检查），发布实际未成功；但 release.confirmedAt 已在运行启动时固化（recordReleaseConfirm，幂等不回滚），isReleased 判定为真，条目增删/换 commit/文档范围全部被按「已正式发布」口径锁定，拦截文案也误称「版本已正式发布」。后果：发布失败后计划范围被锁死，只能按原范围重试发布或新建版本，无法解除确认、调整范围后再发布；且文案与实际状态（未发布成功）矛盾。期望：发布运行失败时确认锁应回退（计划回到确认前可编辑状态），发布成功才不可逆；对存量 BLD-20260927-001（confirmedRunId 指向失败运行且无成功运行）需提供修复路径。
