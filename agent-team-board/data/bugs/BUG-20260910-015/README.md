# BUG-20260910-015 全局任务中的副标题精简，同时将搜索框和副标题放在同一行

- 归属：独立 Bug；状态以系统记录为准。
- 创建：2026-09-10T07:28:04.896Z

## 现象

全局任务面板的副标题为「跨项目：全部注册项目的批量任务，不随顶栏项目选择变化」，说明较长；搜索框独占下一工具行，挤占任务列表的纵向展示空间，与标题要求的紧凑布局不符。

![登记截图](attachments/paste-1789025246693.png)

代码依据：`scripts/web/index.html` 的 `#globalPanel` 中副标题位于 `.global-panel-title`，搜索位于独立 `.global-panel-tools`；`scripts/web/style.css` 将这两个区域分别设为有内边距和底边框的块，面板宽度为 `min(560px, 92vw)`。截图与现有结构一致；实际浏览器版本、截图缩放比例及首次引入提交待确认。

## 复现步骤

1. 启动项目看板，在顶栏点击「全局」打开右侧全局任务面板。
2. 观察标题下的跨项目副标题及搜索框：副标题为上述完整长句，搜索框在独立下一行。
3. 在搜索框输入项目名、批次号或条目编号，观察搜索区域仍独占一行；清空后恢复原列表。搜索并不是触发缺陷的必要条件。
4. 缩窄窗口观察副标题换行和列表可见空间。缺陷主要复现于默认面板宽度；极窄窗口的具体最小支持宽度待确认。

## 期望行为

- 标题「全局任务」与右上关闭按钮保持首行。下一行左侧放精简副标题「跨项目批量任务」，右侧放搜索框，默认 560px 面板中同一行展示；取消搜索独占工具行造成的重复留白及分隔。
- 「跨项目批量任务」为本条建议文案，最终文案待确认；必须保留跨项目与批量任务两层含义。原有「不随顶栏项目选择变化」语义可通过辅助说明保留，不影响聚合范围。
- 搜索框保留项目 / 批次号 / 条目编号提示及独立搜索语义，获得焦点、输入、清空、键盘操作与当前功能一致；轮询和内容状态刷新不重建输入框、不丢失焦点及关键字。
- 默认宽度优先保证副标题与搜索同排。窄屏空间不足时允许这一行内部自然折为两行，保证输入、关闭按钮可达，无横向溢出或文字覆盖；具体断点待开发验证。
- 布局调整不改变列表聚合、筛选、打开/关闭与 Esc 行为，不增加业务操作。
