# BUG-20260911-008 已完成的文案需要精简，确保和开始 Commit 能在同一行。

- 状态：submitted（待人工接受）
- 归属：独立 Bug（引入来源见 design.md）
- 创建：2026-09-11T05:54:12.007Z

## 现象

![截图](attachments/paste-1789106016575.png)

需求列表头单行工具栏（`#reqCaption`，`.req-caption`）中，切到「已完成」档且默认截断生效时（未搜索、已完成条目总数 > 100），条件提示 `#reqCount` 显示长文案：

> 100 / 241 个条目（已完成默认仅显示最新 100 项，更早请用搜索获取）

该文案约 38 个全角字符，与工具栏右组 `#captionActions`（`nowrap` 不拆组，内含已完成档快捷入口「▶ 开始 Commit」，BUG-20260911-005）合计宽度超出列表列可用宽度，右组被整体挤到第二行——「▶ 开始 Commit」单独成行，出现在提示文案下方（见截图）。

涉及代码（只读定位，修复时以实际行号为准）：

- 文案拼装：`scripts/web/app.js`（`renderBoard` 内 `hintText`，`REQ_DONE_LIST_LIMIT = 100`）
- 工具栏结构：`scripts/web/index.html`（`#reqCaption` / `#reqCount` / `#captionActions` / `#laneQuickEntry`）
- 布局规则：`scripts/web/style.css`（`.req-caption` 单行工具栏、`.caption-actions` 整组 `nowrap` 靠右、宽度不足按组换行兜底；列表列宽为内容区 1fr:2fr 分轨的约 1/3，宽屏下限 1021px 时约 324px）

## 复现步骤

1. 启动看板 Web 界面（`scripts/web/`），打开一个「已完成」条目总数 > 100 的项目（截断阈值 `REQ_DONE_LIST_LIMIT = 100`）。
2. 进入「需求」模块，确认顶部搜索框为空（默认截断仅在未搜索时生效）。
3. 左侧状态筛选栏切换到「已完成」档。
4. 观察列表头工具栏的排布。

实际结果：提示文案「100 / 241 个条目（已完成默认仅显示最新 100 项，更早请用搜索获取）」占据首行剩余宽度，「▶ 开始 Commit」被挤到第二行单独成行。

## 期望行为

- 精简已完成档截断提示文案：保留「显示数 / 总数」「默认仅显示最新 100 项」「更早条目用搜索获取」三要素语义，去掉冗余字词（具体措辞由开发阶段定稿，量级参考「100 / 241 项，仅列最新 100，更早请搜索」），使提示与「▶ 开始 Commit」在工具栏同一行显示。
- 列表列宽处于既有保底口径（宽屏下限约 324px）时应仍能同行；宽度极端不足时维持既有「按组整体换行」兜底规则，不裁切、不横向滚动。
- 其余提示场景文案不受影响：普通档无提示、搜索命中「搜索命中条目 N 项（当前档可见 M 项）」维持现状。

## 验收说明

1. 已完成档（未搜索、总数 > 100）：列表头截断提示与「▶ 开始 Commit」在同一行；可用下方 ui-demo.html 的「同行检测」对照验证口径。
2. 精简后文案仍完整承载三要素：显示数 / 总数、默认仅列最新 100 项、更早用搜索获取。
3. 其他档位（待接受 / 已接受 / 已计划 / 开发中 / 待测试）与搜索命中提示的显示逻辑、文案不变（开发中 / 待测试 / 已完成档选择按钮仍整体隐藏）。
4. 既有断言旧文案的测试需同步更新并通过：`scripts/tests/caption-toolbar-20260910-008.test.mjs`（L140–L156 对「100 / 150 个条目」「仅显示最新 100 项」等原文的匹配）；其余涉及 `#reqCount` / 快捷入口的测试（`caption-two-row-20260909-009`、`lane-quick-entry-commit-20260911-005` 等）不回归。

## 界面展示

- 界面布局：还原需求列表头单行工具栏——左侧条件提示 `#reqCount`，右侧整组靠右的 `#captionActions`（已完成档仅含「▶ 开始 Commit」）；外层用宽度可调容器模拟列表列（约 1/3 视口的窄列）。
- 交互行为：「文案方案」开关在「缺陷现状（现长文案）」与「期望修复（精简文案）」间切换；「档位/状态」切换覆盖已完成截断（>100 项）、已完成未截断（≤100 项，无提示）、搜索命中三种状态；宽度滑杆模拟不同列表列宽。
- 状态反馈：工具栏下方实时「同行检测」徽标（提示与按钮是否同行）及当前状态说明；演示页随系统深浅色自适应，并提供手动主题切换。
