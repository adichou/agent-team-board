# BUG-20260921-010 刷新后，最近执行的命令看不见了，请修复。

- 状态：in-progress（zcode-batch-060-1 认领实施中）
- 归属：独立 Bug（引入来源见 design.md）
- 创建：2026-09-21T07:18:29.458Z

## 现象

命令模块「最近执行」页签中的命令列表在浏览器刷新（F5 / 重开页面）后消失，
回到「暂无最近执行」空态；此前成功执行过的命令与参数回填入口全部不可见。
会话内不刷新则显示正常（页签往返 / 离开再进入模块均正常，该口径由
BUG-20260921-009 修复并保持）。

## 复现步骤

1. 看板进入命令模块，切「全部命令」页签选择命令（如带参数的 `atb show`），执行成功；
2. 「最近执行」页签出现该命令条目，点击可回填参数；
3. 浏览器刷新页面，再次进入命令模块「最近执行」页签；
4. 列表回到空态，此前执行的命令不可见。

## 期望行为

刷新页面后，「最近执行」列表仍显示此前成功执行的命令（按命令去重前 10，
按项目隔离），点击仍可回填该次参数快速再执行；浏览器禁用 localStorage 时
降级为会话内行为，不报错不阻塞执行。
