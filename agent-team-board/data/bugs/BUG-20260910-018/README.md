# BUG-20260910-018 排序下拉组件没有和搜索框平齐，请修复

- 状态以本条目 status.json 和看板为准。
- 归属：独立 Bug（引入来源见 design.md；相关条目见下「相关条目与范围界定」）
- 创建：2026-09-10T13:04:26.684Z

## 现象

用户对「平齐」的定义（原话，第 2 条「高度要一直」按「高度要一致」理解）：

1. 两个组件在左右相邻的位置上，排序下拉组件在左，搜索框在右；
2. 两者高度要一致。

对应界面位置：需求模块第三行 `#pageHead`（模块副标题 + 定位控件组 `#locateGroup`），组内为排序下拉 `#reqSort`（`.sort-select`）与当前模块搜索框（`.global-search.module-search`）。

### 代码核实的现状（2026-09-10）

- `scripts/web/index.html`（第 63-84 行）：第三行结构为副标题 `#moduleSub` + 定位组 `#locateGroup`；组内顺序已是「排序下拉 → 搜索框」（REQ-20260910-016 迁入），Tab 顺序同此。
- `scripts/web/app.js` `syncReqSortVisibility`（第 1213-1216 行）：`#reqSort` 仅需求模块且看板已初始化时可见——非需求模块或未初始化时排序下拉隐藏，看不到本缺陷。
- 高度：REQ-20260910-025 已在 `scripts/web/style.css`（第 196-204 行）为定位组内 `.sort-select` 与 `.module-search` 声明显式同高 32px（该需求 2026-09-10 12:34 已上报实现、待人工确认完成）。修复前基线为 `.sort-select` 全局 `height: 24px`（style.css 第 402-411 行）对搜索组约 31-32px，同行时矮一截。
- 相邻：`.locate-group`（style.css 第 184-192 行）仍为 `flex-wrap: wrap` + `gap: 6px`——组内空间不足时排序下拉会换行到搜索框上方，两控件上下堆叠、不再左右相邻；≤720px 媒体查询（style.css 第 1668-1675 行）也只约束组独占整行、搜索可伸缩，未保证组内恒不换行。
- 本 Bug 登记时间（13:04）晚于 REQ-20260910-025 修复上报时间（12:34）：用户看到的是修复前页面（服务未重启 / 浏览器未刷新），还是修复后仍存在的「换行堆叠」，待确认（见「验收说明」末条）。

## 复现步骤

1. 项目根目录执行 `atb serve`（默认端口 8888，可用 `--port N` / `ATB_PORT` 覆盖），浏览器打开看板地址（默认 `http://localhost:8888/`）。
2. 选择一个已初始化看板的项目，进入「需求」模块（其他模块或未初始化时排序下拉隐藏，无法复现）。
3. 观察第三行副标题右侧的定位控件组：期望排序下拉与搜索框同一行左右相邻（排序在左、搜索在右）。
4. 现象 A（高矮不齐，修复前基线 / REQ-20260910-025 等高规则未生效时）：排序下拉 24px 明显矮于搜索组（约 31-32px），同行时高矮不齐。
5. 现象 B（换行堆叠）：逐步缩窄浏览器窗口宽度（或副标题文案较长挤压定位组可用宽度），组内空间不足时排序下拉换行到搜索框上方，两控件上下堆叠、不再左右相邻——REQ-20260910-025 附件截图（`requirements/REQ-20260910-025/attachments/paste-1789031295688.png`）即此形态（下拉矮一截叠在搜索框上方）。
6. 深浅色主题切换后重复第 4-5 步，缺陷在两种主题下均可见（待确认：用户截图主题未记录，不影响缺陷定义）。

## 期望行为

- 需求模块第三行定位控件组内，排序下拉与搜索框**左右相邻、同一行**呈现：排序下拉在左、搜索框在右（Tab 顺序保持「排序 → 搜索」）。
- 两者**高度一致**、上下边缘平齐（等高口径沿用 REQ-20260910-025 的显式同高 32px 做法，最终像素以开发实现为准）。
- 平齐调整不改变既有行为：排序五选项、默认最新更新、localStorage 记忆、切换即重排；搜索范围标签、清除按钮、Esc 清空、`/` 聚焦、防抖与反馈条均不变。
- `#reqSort` 显隐口径不变：仅需求模块且看板已初始化时可见；隐藏时搜索框位置稳定、不留占位空洞。
- 复用 `.sort-select` / `.search-input` 样式的其它位置（讨论筛选条行末排序下拉、全局面板搜索）不被破坏。

## 验收说明

- 常规桌面宽度 + 需求模块（已初始化）：排序下拉与搜索框同一行左右相邻（排序左、搜索右），高度一致、上下边缘平齐，无「矮一截」或「上下堆叠」。
- 逐步缩窄窗口宽度：两控件保持左右相邻、不换行堆叠、不裁切、不遮挡、页面无横向滚动。若确认允许极窄宽度下换行（沿用 REQ-20260910-016 既口径），须与本 Bug 期望「左右相邻」的人工裁决一致后按裁决口径验收——与 REQ-20260910-025「待确认」第 1 条联动（待确认）。
