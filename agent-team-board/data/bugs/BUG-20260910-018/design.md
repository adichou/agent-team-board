## 根因分析

- 现象 A（高矮不齐）：`.sort-select` 全局 24px（style.css 基础规则）与搜索组约 31-32px 相邻。
  **已由 REQ-20260910-025 修复**（`.page-head .locate-group` 作用域内两者同块显式同高 32px），
  本工作树已含该修复，测试守护其不回退。
- 现象 B（换行堆叠，本单根因）：`.page-head .locate-group` 为 `flex-wrap: wrap`，组内是否换行
  取决于组内 min-content 与组可用宽度的关系。基础 `.global-search` 声明 `min-width: 140px`
  （顶栏口径），使定位组内搜索组在 **>720px 宽度** 的保底为 140px——组内 min-content ≈
  排序下拉固有宽度 + gap 6px + 140px ≈ 250px；「不堆叠」仅由 ≤720px 媒体查询内
  `.page-head .module-search { min-width: 0 }` 与页头换行给组整行宽这两个** emergent 条件**保证，
  非结构性声明：任一条件变化（如媒体查询断点调整、页头行宽被挤压）堆叠即可复现，
  登记分析亦指出「未保证组内恒不换行」。
- 登记时间线核实：本 Bug 登记（13:04）晚于 REQ-025 修复上报（12:34），用户所见可能为
  修复前页面（服务未重启 / 未刷新）；但现象 B 的结构性缺口在 025 修复后依然存在（如上），
  本单予以封闭。

## 方案

**开源选型（REQ-20260909-015）**：单条作用域 CSS 声明，无成熟开源库可复用（不涉及组件库 /
布局库引入场景），引入开源库成本远高于自研，故自研。

选定方案（README 允许路径内、约束结果不预设方案）：

- `scripts/web/style.css`：新增顶层规则 `.page-head .locate-group .module-search { min-width: 0; }`
  ——定位组内搜索组**全宽度**解除 140px 保底（此前仅 ≤720px 生效），组内 min-content 收敛为
  排序下拉固有宽度（约 90px）：常规与逐步缩窄宽度下排序与搜索恒同一行左右相邻、不换行堆叠、
  不裁切、无页面横向滚动。**不动** `flex-wrap: wrap`（REQ-016/025 测试锁定的极窄退化口径原样保留，
  README「极窄是否允许换行」的人工裁决不受影响，按裁决前现状口径执行）；等高沿用 025 的 32px 块。
- `scripts/web/index.html`：pageHead 注释补 BUG-20260910-018 留痕（无结构改动）。
- `scripts/tests/bug-sort-search-flat-20260910-018.test.mjs`：新增 6 用例
  （B1 左右相邻结构保证 / B2 等高不回退 / B3 复用位置不外溢 / B4 窄屏契约不回退 /
  B5 行为契约不回退 / B6 ui-demo 离线自包含守护）。

备选与否决：

1. 组容器改 `flex-wrap: nowrap`（ui-demo「修复后」示意的简化形态）：结构性最强，但直接推翻
   REQ-016/025 测试锁定的 wrap 口径（两单均 in-progress 待人工确认），且极窄退化宽度下失去
   「不裁切、不横向滚动」的兜底，与 README 标注「待人工裁决」的口径冲突——不采纳；
   若人工裁决改为「恒不换行」，再按裁决调整。
2. 仅依赖既有 ≤720px 媒体查询（零改动）：>720px 侧 140px 保底仍在，不堆叠依赖 emergent 条件，
   结构性保证缺失，本单验收点「未保证组内恒不换行」不封闭——不采纳。

## 风险与边界

- `min-width: 0` 使搜索组在 >720px 且组宽被极端挤压时可缩至很窄：实际布局中组宽不足时页头
  先把组换到独立行（整行宽），常规桌面宽度搜索组仍按 380px 基准呈现，视觉无变化；
  仅原本会触发堆叠的挤压场景改为同行收缩。
- 极窄（<约 130px 视口）下 wrap 仍可能发生（016 口径：不裁切、不横向滚动优先），与 README
  「待人工裁决」联动项一致，留待裁决；如裁决「恒不换行」需再评估 nowrap + 裁剪策略。
- 作用域限定 `.page-head .locate-group`：顶栏 / 全局面板复用的 `.global-search` 140px 保底、
  讨论筛选条行末 `.sort-select` 24px 口径不受影响（B3 断言守护）；深浅色主题无关（纯尺寸规则）。
- 静态契约测试不渲染真实浏览器几何：换行阈值（≈排序下拉固有宽度）随字体环境浮动，
  断言锁定结构声明（min-width:0 全宽度生效）而非像素阈值，避免环境脆弱性。
