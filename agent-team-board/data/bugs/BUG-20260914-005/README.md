# BUG-20260914-005 分支浏览里面的同步远端按钮文案改为“和远端同步”

- 状态：accepted（已接受）
- 归属：独立 Bug（引入来源见 design.md）
- 创建：2026-09-14T03:46:38.899Z

## 现象

Web 看板「构建」模块 →「分支浏览」子页签中，左侧分支列表顶部工具栏的同步按钮文案为「⟳ 同步远端」，期望措辞为「和远端同步」。按钮功能本身正常，属按钮文案（措辞）问题：

- 按钮位置：`scripts/web/build.js` 的 `renderBranchesPane()`（按钮 `#bldFetchBtn`）。默认态显示 `⟳ 同步远端`，悬停提示「fetch --all --prune：拉取远端最新并清理失效引用」；
- 同一功能存在多处关联文案（现状，修复时需一并对齐参考）：
  - 执行中按钮显示「同步中…」并禁用（防重复触发），完成后恢复；
  - 成功 / 失败 toast：「✓ 已同步远端（fetch --prune）」 /「✕ 同步远端失败：<原因>」（`doFetch()`，请求 `POST /api/build/fetch`，即 `fetch --all --prune`）；
  - 远端分支为空时的空态提示「（无远端分支：先「同步远端」或推送本地分支）」——其中「同步远端」是按钮名的引用，按钮更名后指称会不一致；
- 英文界面：`scripts/web/i18n.js` 词典收录 `'同步远端': 'Sync remote'`。按钮更名后需同步补新词条，否则英文界面按「未命中保持原文（优雅降级）」规则显示中文。

## 复现步骤

1. 启动看板服务：在项目目录终端运行 `atb serve`（默认端口 8888，可用环境变量 `ATB_PORT` 覆盖），浏览器打开 `http://localhost:8888`；
2. 顶栏项目选择器选择一个 **git 仓库** 项目（非 git 仓库时整个构建模块显示引导空态，不会出现该按钮）；
3. 顶栏切到「构建」模块页签；
4. 模块内切到「分支浏览」子页签（首次进入自动加载分支列表）；
5. 观察左侧分支列表顶部工具栏：第一个按钮文案为「⟳ 同步远端」——即本 Bug 所述待改文案。

## 期望行为

- 分支浏览工具栏同步按钮的默认态文案由「⟳ 同步远端」改为「和远端同步」（保留既有 ⟳ 图标前缀，即显示「⟳ 和远端同步」）；
- 行为保持不变：点击仍执行 `POST /api/build/fetch`（`fetch --all --prune`）；执行中按钮禁用并显示「同步中…」，完成后恢复；成功 / 失败 toast 及分支列表、选中分支提交记录的自动刷新逻辑均维持现状；
- 指称一致：远端分支空态提示同步更新为「（无远端分支：先「和远端同步」或推送本地分支）」；
- 英文词典 `scripts/web/i18n.js` 为新文案补充词条（译法可沿用 `Sync remote` / `Sync with remote`），英文界面不因更名降级显示中文。

## 验收说明

1. 打开 构建 → 分支浏览：同步按钮默认态显示「和远端同步」（⟳ 图标保留），悬停提示不变；
2. 点击按钮：执行中按钮禁用并显示「同步中…」，成功后 toast「✓ 已同步远端…」，分支列表与选中分支提交记录自动刷新——功能与改前一致，无回归；
3. 构造失败场景（如远端不可达 / 断网）：失败 toast「✕ 同步远端失败：<原因>」仍正常弹出，按钮恢复可点、可重试；
4. 在无远端分支的项目查看空态提示：其中按钮指称已更新为「和远端同步」；
5. 切换英文界面语言：按钮文案正常翻译，无中文降级残留；
6. 全局检索源码确认按钮旧文案（`⟳ 同步远端`）无残留；`scripts/tests/` 目前没有引用该文案的断言，若开发过程中新增了相关断言需同步更新。

## 界面展示

可交互演示：[./ui-demo.html](./ui-demo.html)（单文件 HTML，无外网依赖，浏览器直接打开；支持「当前文案（缺陷）↔ 修复后」一键对比、模拟同步成功 / 失败、空远端空态、分支列表加载态与深浅色切换）。

- 界面布局：还原「构建 → 分支浏览」子页签——模块内子页签行（版本计划 / 分支浏览），主体左右分栏：左侧分支列表（顶部工具栏放「同步」与「刷新」两个按钮；下方按「本地 / 远端」分组，本地组含当前分支徽标与普通本地分支的「推送」按钮），右侧为选中分支的提交记录（标题栏带「刷新」）。
- 交互行为：点击同步按钮触发 `fetch --all --prune`（演示为模拟请求）；点击分支行加载该分支提交记录；本地分支「推送」、列表「刷新」等入口可用；演示页顶部提供「当前（缺陷）/ 修复后」文案模式开关，用于对照按钮旧文案「⟳ 同步远端」与修复后「⟳ 和远端同步」。
- 状态反馈：默认态按钮文案随模式开关切换；执行中按钮禁用并显示「同步中…」；成功弹「✓ 已同步远端（fetch --prune）」toast 并自动刷新列表；失败（勾选「模拟同步失败」）弹「✕ 同步远端失败：<原因>」错误 toast 且按钮恢复可点；进入 / 刷新列表时显示「加载分支中…」；勾选「空远端分支」时远端分组显示空态提示（提示中对按钮的指称随文案模式同步变化）；未选分支时右侧显示「点击左侧分支查看提交记录」引导空态。
