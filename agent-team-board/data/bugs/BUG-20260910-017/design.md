# 设计 — BUG-20260910-017 全选和全不选的图标尺寸要跟其他操作图标按钮的样式一样

> 由 Agent 在 /dev 开发前补充，人可随时批注。

## 引入来源（源单）

本 Bug 由哪个需求 / Bug 引入？登记时可暂空或写「未定位」，修复阶段必须归因（三选一，禁止编造）：

- 引入来源：REQ-20260910-026（经 `atb list` 核验存在）——该单将「全选 / 全不选」从带文字
  按钮改为仅 ☑ / ☐ 字形的图标按钮，沿用 BUG-20260910-007 的 `.btn.icon-act` CSS 盒口径
  （26×24 / 13px）但未对齐字形视觉重量，本缺陷随之引入。

## 根因分析

- 现象层：`#selectOperable`（☑ U+2611）/ `#selectNone`（☐ U+2610）与卡片操作区
  `✓（U+2713）/ ✎（U+270E）/ ⧉（U+29C9）` 的 CSS 盒规格完全一致
  （`.req-caption .btn.icon-act` 与 `.req-row .row-acts .btn.icon-act` 同为
  min-width 26px / min-height 24px / font-size 13px），视觉偏大不是盒规格差异。
- 根因层：**字形墨迹高度差异**。投票框字形 ☑ / ☐ 在系统字体回退链下按接近满 em
  见方绘制（约 0.85–0.95em 墨迹高度），而 ✓ / ✎ / ⧉ 在同一 13px 字号下实际墨迹
  高度约 0.6–0.75em。同字号时 ☑ / ☐ 的视觉高度天然比行内操作图标大 20%–40%，
  两组同屏即出现大小不统一的突兀观感。
- 为什么 REQ-20260910-026 引入：该单图标化前两按钮为「☑ 全选」「☐ 全不选」文字按钮，
  字形与文字混排时字形大小差异不显眼；去文字仅留 ☑ / ☐ 字形后，满 em 见方的字形
  在 26×24 小方格内成为唯一视觉主体，差异被放大。

## 方案

**开源选型（REQ-20260909-015）**：本修复为单条 CSS 降字号规则 + HTML 修饰类微调，
无成熟开源库可复用（不涉及组件库 / 图标库引入场景）；引入开源库的成本远高于自研，
故自研。

选型对比（README 允许三条路径，约束结果、不预设方案）：

1. **单独降字形字号（选定）**：两按钮加统一修饰类 `icon-check`，新增
   `.req-caption .btn.icon-act.icon-check { font-size: 11px; }`——仅字形视觉重量
   对齐（11px 的满 em 见方墨迹 ≈ 13px 的 ✓ / ✎ 墨迹高度），盒规格 26×24 与两条
   `.btn.icon-act` 基础口径一字不动；改动最小、语义契约（☑ / ☐ 字形、aria-label、
   title）零变化，REQ-20260910-026 的 T1/T2 断言全部原样通过。
2. 换字形（如 ✓✓ / ✕）：视觉重量可对齐，但丢掉「投票框」的语义辨识度，且仍受
   字体回退差异影响，收益不优于方案 1。
3. 内联 SVG：几何完全确定（跨环境零偏差），但需改写 REQ-20260910-026 的 T1
   「内容仅 ☑ / ☐ 字形」图标契约与断言，改动面与回归面最大；当前两条既有口径
   （工具栏 / 卡片操作区）均为字形图标，SVG 反而引入第二种图标实现体系。

实施（2 文件 + 1 测试）：

- `scripts/web/index.html`：`#selectOperable` / `#selectNone` class 追加 `icon-check`
  （两按钮 class 保持完全一致，等宽同源）。
- `scripts/web/style.css`：`.req-caption .btn.icon-act` 基础规则后新增降字号规则
  `.req-caption .btn.icon-act.icon-check { font-size: 11px; }`（11px 取条目
  ui-demo 演示的示意值并经目视校准确认）。
- `scripts/tests/bug-caption-select-icon-size-20260910-017.test.mjs`：新增 3 用例
  （T1 降字号规则与盒口径不变 / T2 语义契约零变化 / T3 负向边界——不外溢行内
  操作图标、工具栏布局口径不回退）。

## 风险与边界

- 跨环境字体回退差异：降字号基于「相对墨迹比例」的近似对齐，不同 OS / 浏览器 /
  深浅色主题下残余偏差可能存在——验收时按 README 要求记录验证环境，如仍明显
  偏差可微调 11px 数值或升级为内联 SVG 方案。
- 降字号不得外溢：规则作用域锁死 `.req-caption .btn.icon-act.icon-check`
  （class + 后代双重限定），卡片操作区 `.req-row .row-acts .btn.icon-act`
  （13px）与工具栏其他图标用法不受影响（T3 负向断言守护）。
- 语义与功能零变化：仅改 class 属性与 CSS，不改 JS 行为路径；按档显隐、全选叠
  搜索、全不选仅当前档、禁用口径、批量防误触、非选择档隐藏等契约由既有回归
  套件（caption-toolbar-icons-20260910-026 / caption-toolbar-20260910-008 /
  caption-two-row-20260909-009 / accept-ui 等）守护，全部通过。
