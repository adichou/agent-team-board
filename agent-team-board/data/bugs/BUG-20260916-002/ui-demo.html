BUG-20260916-002 · 任务记录「重新执行」无法续接已认领后 blocked 的条目

演示任务记录页对 blocked 终态记录点击「重新执行」的缺陷现象与期望修复后状态。表格行、owner 与提示词均为示意数据。

形态 记录状态
批量开发 本轮已结束 · finished 本轮执行已收尾，处理记录仍可按条目重建 / 续接
本轮处理记录 最近 2 条 / 共 5 条
续接提示词（自动复制失败时请手动选中复制）
提示词未进入剪贴板：请全选上方文本手动复制；「复制提示词」可重试（不会产生新任务 / 新运行）。
正常：受阻（blocked）记录可「重新执行」，已处理（reported）记录不可重试

缺陷链路：blocked 为终态运行但条目保持 in-progress / owner 不变 → 终态重建路径按「已计划且未认领」过滤候选 → 报「指定的条目均不可入队」。期望：识别「blocked + 仍被原 owner 认领 + 无在途运行」→ 生成续接提示词（沿用原 owner 幂等续认），不走普通新批次入队、不新建运行。
