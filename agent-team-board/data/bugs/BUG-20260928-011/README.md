2. 「双语材料」项失败：`scripts/lib/build-publish.mjs` 的 `siteMaterials`（REQ-20260916-004 口径）硬编码按**旧后缀规范**校验 `content/<产品id>/changelog/v<版本>.zh.md`、`faq/support` 中英各一、`docs/` 内中英成对文档。
