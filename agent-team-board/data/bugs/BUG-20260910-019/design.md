# 设计 — BUG-20260910-019 全选和全不选的图标要使用更标准的图标

> 由 Agent 在 /dev 开发前补充，人可随时批注。
> zcode-batch-20260910-032-06 于 2026-09-11 实施前补充。

## 引入来源（源单）

- 引入来源（经 `atb list` 核验存在）：**REQ-20260910-026**——该单将「全选 / 全不选」
  从文字按钮改为仅 `☑` / `☐` 字形的图标按钮，其遗留「待确认」中「沿用字形还是自绘 /
  内联 SVG」悬而未决，以字形先行落地。本缺陷针对该投票框字形非标准图标语汇的问题。
- 视觉尺寸先例：BUG-20260910-017（字形近满 em 见方被迫降 11px 的治标修补，本单移除）；
  图标盒口径参照 BUG-20260910-007（26×24 小方格）。

## 根因分析

1. `☑`（U+2611）/ `☐`（U+2610）是**文字字形而非图标资产**：渲染走操作系统 / 浏览器的
   系统字体回退链，线宽、方框圆角、勾形粗细随环境漂移（部分环境呈衬线或近 emoji 风格），
   同一产品跨机器观感不受控。项目 Web UI 无任何图标资产体系（无图标字体 / 无内联 SVG
   图标库），全部图标均为 Unicode 字形，两投票框字形是唯一以「投票框」语汇呈现的图标，
   与业界通用的「带勾方框 / 空方框」等线宽复选框图标形态不对应。
2. 佐证：BUG-20260910-017 已被迫对两字形单独降字号至 11px（`style.css`
   `.req-caption .btn.icon-act.icon-check { font-size: 11px; }`）来对齐视觉尺寸——
   正是「字形渲染不可控」的连锁修补，治标不治本。

## 方案

**选定：自绘内联 SVG（两枚：带勾方框 / 空方框），随页面静态 HTML 内联，无外网依赖。**

- 图标形态（与 ui-demo.html 修复示意同源）：
  - 全选 = 带勾方框：`<rect x="1.5" y="1.5" width="13" height="13" rx="2.5"/>` +
    `<polyline points="4.6 8.3 6.9 10.6 11.4 5.3"/>`（勾形）；
  - 全不选 = 空方框：仅同一 `<rect>`。
  - 公共描边口径：`viewBox="0 0 16 16"`、`width="13" height="13"`、`fill="none"`、
    `stroke="currentColor"`、`stroke-width="1.6"`、圆角端点——等线宽描边、跨平台渲染
    恒定；`stroke=currentColor` 继承按钮 `--muted/--text` 色，深浅色主题自动适配
    （含 `.btn.quiet:hover` 变色）。尺寸取 13×13：对齐行内 13px 字形图标
    （✓ / ✎ / ⧉）的视觉重量（BUG-20260910-017 成果不回退）。
  - `aria-hidden="true"` 屏蔽读屏，语义仍由按钮 `aria-label` / `title` 承载。
- 盒规格与布局零变化：`.req-caption .btn.icon-act` 沿用 26×24 定宽等高与 13px 基准，
  追加 `display:inline-flex; align-items:center; justify-content:center` 承载 SVG 居中
  （原 `text-align:center` 保留）；`icon-check` 降字号修补规则随字形一并移除。
- 行为零变化：app.js 仅注释更新，无任何逻辑 / DOM 写入改动。

**开源选型（REQ-20260909-015）评估**：Lucide / Bootstrap Icons 等开源图标库的
`check-square` / `square` 即目标形态，但：

- 项目 Web UI 为 `scripts/web/` 静态文件、`scripts/server.mjs` 直接伺服，无 npm 前端
  构建 / 打包管线（package.json 仅 electron 依赖与 node 测试脚本）；以依赖方式引入
  图标库需要新建构建链或引入远端 CDN 脚本（违反离线自包含口径，ui-demo / Electron 壳
  均要求无外网依赖）。
- 实际只需 2 枚、共 ~10 行的极简 path（方框 + 勾），自绘成本远低于引入整库；
  vendor（内嵌整库源码）更不成比例。
- 自研理由（三选一之「引入成本高于自研」）：为 2 枚基础几何图标引入整套图标库
  依赖 / 构建链 / 体积，成本显著高于 2 段内联 SVG path；且无构建管线可走依赖分发。
- 未引入开源库，不创建 licenses.md。

## 风险与边界

- **视觉重量回退风险**：SVG 13×13 需与行内 13px 字形图标（✓ / ✎ / ⧉）观感一致——
  已按 1.6/16 线宽（≈1.3px 实际描边）贴近字形笔画，测试断言盒口径与 SVG 尺寸契约；
  最终观感仍需人工验收（验收项 3）。
- **既有静态断言同步**：`caption-toolbar-icons-20260910-026`（T1）、
  `bug-caption-select-icon-size-20260910-017`（T1/T2）、`selection-lane-scope`
  （S1 `>☑` 正则）三处 ☑ / ☐ 字形断言按新 SVG 方案同步修正（README 已列为开发阶段
  事项）；026 的 T5 检查的是 REQ-20260910-026 条目自身 ui-demo（历史记录，保留 ☑ / ☐
  对照），不改。
- **零功能回归边界**：全选叠搜索、全不选仅清当前档、禁用口径、非选择档隐藏等行为
  由 026 T4 / selection-lane-scope S2-S4 既有用例继续守护，本单不触碰 app.js 逻辑。
- **无障碍**：SVG `aria-hidden` + 按钮 `aria-label` 双保险，读屏不重复念出；
  键盘 Tab / 焦点轮廓沿用原生 button，无变化。
