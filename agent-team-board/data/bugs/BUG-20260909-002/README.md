## 现象

设置页和任务页仍显示本单标题要求删除的配置入口及重复文案。2026-09-09 核对当前源码，确认以下渲染内容存在；本次未运行浏览器复现，具体浏览器、窗口尺寸及用户截图待确认。

| 位置 | 当前可核实的表现 | 用户要求 |
| --- | --- | --- |
| 设置 →「模型与推理强度」 | 包含配置方式、继承模型信息或指定模型/强度控件及刷新等配套展示 | 去掉设置中的模型、强度配置 |
| 设置 →「运行环境」 | 显示「检查运行环境（静态）」按钮及检查结果容器 | 去掉运行环境检查 |
| 任务页头部 | 显示「任务设置」按钮，点击切换到设置模块 | 删除该按钮 |
| 设置页模块副标题和正文开头 | 副标题为「当前项目的派发默认值」，正文也以该文案开头 | 删除此文案及对应的派发默认值说明 |
| 设置 → 批量任务 → 两类任务的「是否隐藏」列 | Codex、Zcode 每个复选框后再次显示「隐藏」文字 | 保留复选框和列标题，删除框后的重复文字 |

以上属于界面精简要求。尚无证据说明其导致任务执行失败或配置数据损坏，不将此类问题计入现象。

### 核实依据

- `scripts/web/app.js`：`MODULE_SUB.settings` 定义副标题；`renderSettingsView` 渲染派发默认值说明、模型配置和运行环境检查；`taskSettingsHtml` 渲染两类任务、四个隐藏复选框及其尾随文字。
- 同文件 `renderBatchDrawer` 渲染 `taskSettingsGo`，`bindBatchDrawer` 将其绑定到设置页；主导航仍有独立设置模块。
- `scripts/lib/task-settings.mjs`：隐藏配置按批量完善、批量开发分别保存，可只更新 `agents`，允许全部隐藏且保留既有 `models` 字段。
- `scripts/tests/settings-title-removed.test.mjs`、`scripts/tests/tasks-panel-26.test.mjs` 仍有保留旧文案、配置区和任务设置入口的断言；它们是现有行为依据，开发修复时需按新口径调整，不能当作本 Bug 已修复的证据。

## 复现步骤

前置：启动本项目 Status Board，选择已初始化且能正常读取设置的项目。无需启动任务、触发真实模型验证或改写配置即可观察前四项。

1. 点击主导航「设置」，观察模块副标题与正文首段，均可找到「当前项目的派发默认值」。
2. 在同页向下查看「模型与推理强度」区域，观察配置方式及当前模式对应的模型/强度内容；继续查看「运行环境」区域，可见「检查运行环境（静态）」按钮。复现只需确认入口存在，不必点击检查。
3. 回到「批量任务」分区，分别观察「批量完善」「批量开发」表格中的 Codex、Zcode 行；四个「是否隐藏」复选框后均有重复的「隐藏」文字。
4. 点击主导航「任务」，观察页头的「任务设置」按钮；点击后进入设置页，确认该冗余入口仍可用。
5. 刷新页面并在任务、设置模块之间切换，重复观察上述内容。缺陷是否在用户实际环境中稳定复现、是否与特定版本有关，待开发阶段确认；当前源码渲染不以任务正在运行作为这些入口的显示条件。

## 期望行为

1. 设置页移除模型和推理强度的配置控件及只服务于这些控件的说明、刷新/验证入口和状态展示；移除运行环境检查区域的标题、按钮与结果容器。删除后不保留空卡片或不可操作的占位区域。
2. 任务页删除「任务设置」按钮及其占用的空间。用户仍通过主导航「设置」进入配置；任务类别切换、任务启动、历史记录和返回需求操作继续可用。
3. 删除设置模块副标题中的「当前项目的派发默认值」及正文对应说明。没有替代文案要求，不自行补充同义派发文案；其他模块的副标题不受此项影响。
4. 「是否隐藏」保留列标题与原有复选框，四个框后的可见「隐藏」文字删除。勾选仍表示在对应任务启动选项中隐藏，取消表示显示；保存、生效范围、默认值、两类任务互不影响及全部隐藏时禁止启动的语义保持一致。每个复选框仍须有包含任务类别、Agent 和隐藏含义的可访问名称，键盘可聚焦并切换。
5. 删除配置界面不等于清空底层配置、改写执行快照或移除运行前必要校验。保存保留项不得用已删除输入框的空值覆盖既有模型和强度；历史记录中的模型信息不属于本单要求删除的配置入口。

### 界面展示与状态反馈（文字说明）

- 正常：任务页头部不再显示「任务设置」；设置页不再显示派发默认值副标题/说明、模型强度配置和运行环境检查。批量任务的隐藏列呈现为列标题「是否隐藏」及各行复选框，框后没有可见尾随文字。
- 初始无配置：按现有默认值显示两类任务的 Codex、Zcode 均未勾选；不会因已删除的控件缺少值而生成模型字段重置。
- 全部隐藏：允许保存，任务启动区明确提示无可用 Agent，并指向仍存在的「设置 → 批量任务」路径；不再依赖已删除的按钮。
- 加载/保存中：保留项的进度反馈清晰，避免未完成加载时覆盖配置及重复提交；已移除区域不在加载后或刷新时重新出现。
- 失败：保留设置读取失败的错误及重试操作；保存失败保留当前输入并允许重试，不报保存成功。删除区域的失效事件绑定不得导致整页无法操作；仍显示的错误提示不得引导到已删除控件。

## 验收说明

- [ ] 在正常加载、刷新、切换项目并返回设置后，设置中均无模型/强度配置及运行环境检查区域；没有残留空标题、空卡片或失效按钮。
- [ ] 模块副标题和正文不再出现「当前项目的派发默认值」及其对应说明，其他模块文案保持正常。
- [ ] 任务页在无任务、有进行中任务和历史任务场景下均无「任务设置」按钮；主导航设置入口、任务类别切换及既有任务操作仍正常。
- [ ] 批量完善、批量开发的 Codex、Zcode 四个隐藏复选框均无尾随「隐藏」可见文字，保留「是否隐藏」列标题；键盘和可访问名称仍能明确定位、操作各项。
- [ ] 勾选一个 Agent 后保存，刷新可正确回显，仅影响对应类别的新任务启动选项；取消隐藏可恢复。全部隐藏可保存且启动不可用，并提示有效的设置路径。
- [ ] 保存保留设置不清空现有模型/强度、不改写运行中任务配置或历史记录；涉及运行参数的删除边界已按待确认项核对并记录。
- [ ] 加载或保存失败时可见错误且可重试，保存失败不丢失草稿；无配置与全部隐藏能区分，窄窗口无删除后遗留的横向空白或错位。
- [ ] 页面无已删除元素引起的交互异常，保留提示没有指向已删除控件的死入口；旧界面断言按本单与关联需求核对后的范围更新。
