# BUG-20260928-010 所有的界面时间显示需要以本地时区来显示，不能显示 UTC 时间。

- 状态：submitted（待人工接受）
- 归属：独立 Bug（引入来源见 design.md）
- 引入来源：REQ-20260913-001（构建模块以 ISO 字符串截取展示 UTC）；发布旧入口未定位至单一源单，见 design.md。
- 创建：2026-09-28T09:57:41.392Z

## 现象

例如推送远端的完成时间为完成时间 2026-09-28 09:56，基准 05bc454c，而当前时间是 17:56。

## 复现步骤

1. 浏览器时区设为 Asia/Shanghai，进入构建版本详情，查看推送远端完成时间。
2. 当接口时间为 2026-09-28T09:56:07Z 时，旧界面显示 09:56，本地实际为 17:56。

## 期望行为

所有业务时间按浏览器本地时区显示。构建时间保留分钟，发布记录保留秒；UTC 持久化数据保持不变。空值与非法值显示 —。
