# BUG-20260911-005 增加了批量 commit 功能后，要在已完成列表中添加“开始 Commit”按钮，布局和已接受和已计划的一样

- 归属：独立 Bug（引入来源登记于 design.md，开发阶段归因）
- 创建：2026-09-11T01:42:29.073Z
- 当前状态以系统记录为准；本文不维护状态。

## 现象

需求模块的列表标题行有一个与勾选无关、仅导航的「档位快捷入口」按钮（`#laneQuickEntry`，REQ-20260909-007，位于 `scripts/web/index.html` 列表标题行 `#captionActions` 内、空间足够时靠右）：切到**已接受**档显示「▶ 开始完善」，切到**已计划**档显示「▶ 开始开发」，点击分别一键进入任务模块的批量完善 / 批量开发面板。

批量 Commit 能力上线后（CLI 命令组来自 REQ-20260910-013；任务模块「批量 Commit」面板与已完成条目「未提交 / 已提交 + 提交号」徽标来自 BUG-20260910-014），**「已完成」档列表标题行没有对应的「▶ 开始 Commit」快捷入口**：

- 已核实的代码依据：`scripts/web/app.js` 的 `syncAcceptance()` 中快捷入口配置仅覆盖 `accepted` / `planned` 两档（约 2444-2458 行，`done` 档配置为 null，按钮保持 hidden）；`#laneQuickEntry` 的点击处理器（`scripts/web/app.js:6690`）也只有 `accepted → refine`、其余 → `develop` 两个分支。
- 影响：在已完成档要启动批量 Commit，只能手动切到「任务」模块、再点「批量 Commit」页签，相比已接受 / 已计划档的一键直达，入口层级不一致、操作路径更长。

## 复现步骤

1. 启动 Status Board（`node scripts/server.mjs`，端口 8888；或 Electron `npm run app`），浏览器打开看板。
2. 进入「需求」模块，切到「已接受」档：列表标题行右侧显示「▶ 开始完善」按钮；切到「已计划」档：同一位置显示「▶ 开始开发」按钮。
3. 切到「已完成」档：同一位置没有任何快捷入口按钮（`#laneQuickEntry` 处于隐藏态）。
4. 此时若要启动批量 Commit，需点击顶部导航进入「任务」模块，再点击「批量 Commit」页签——对比步骤 2 的一键直达，确认入口缺失且不一致。

## 期望行为

- 「已完成」档列表标题行右侧显示「▶ 开始 Commit」按钮，布局、位置、样式与已接受档「▶ 开始完善」/ 已计划档「▶ 开始开发」**完全一致**：复用同一 `#laneQuickEntry` 常驻节点与 `#captionActions` 布局（同行、空间足够时靠右、`btn small primary` 样式），仅按当前档切换显隐与文案。
- 点击后进入任务模块并激活「批量 Commit」面板（即 `gotoRuns('commit')`）；**仅导航**：不创建任务、不复制提示词、不执行任何 Git 操作，任务创建仍由面板内「启动」承接（无已完成候选时「启动」保持禁用并说明原因，沿用 BUG-20260910-014 现有逻辑）。
- 按钮 `title` / `aria-label` 与文案同步，说明进入任务模块批量 Commit 面板：对已完成条目批量归因提交到本地 Git（与勾选无关；只 commit 不 push）。
- 其余档（待接受 / 开发中 / 待测试）不显示该按钮；已接受 →「开始完善」、已计划 →「开始开发」的既有映射不回归。
- 切档即时切换显隐；2 秒轮询只改控件态、不重建按钮，无闪烁；批量操作进行中按钮不禁用（仅导航，与现有快捷入口口径一致）。

## 界面展示

[打开交互演示](./ui-demo.html)（离线单文件，全部数据为模拟，不调用服务、不执行 Git）。

- 布局：模拟需求模块——状态筛选条（六档 chips 带计数）、列表标题行（左侧标题与计数、右侧 `#captionActions`：批量动作组按档显隐 + 档位快捷入口按钮）、条目列表（已完成条目带「未提交 / 已提交」徽标）；点击快捷入口进入模拟任务模块（批量完善 / 批量开发 / 批量 Commit 一级页签 + 概况面板）。
- 交互：「缺陷现象 / 期望修复」模式对照切换；六档 chips 切换，观察快捷入口随档显隐与文案变化（缺陷模式已完成档按钮缺失并标注缺陷点，期望模式显示「▶ 开始 Commit」）；点击按钮直达任务模块对应面板并高亮激活页签；「正常 / 空 / 加载 / 失败」场景切换；深浅色主题切换。
- 状态反馈：正常——已完成档一键直达批量 Commit 面板，toast 提示「仅导航，未创建任务」；空——无已完成条目时列表空态、面板「启动」禁用并提示暂无候选；加载——切档与进入面板时显示加载态，快捷入口按钮不消失、不闪烁；失败——面板数据加载失败显示「提交状态加载失败」错误条与「重试」入口，不伪装成空状态。
