## 根因与方案

命令与主技能只要求 report 和最终回复，没有明确本单 Git 提交、实际待测试核验、异常交付边界。新增 skills/agent-team-board/dev-closeout.md 单一规则源，由 commands/dev.md 与主技能链接；同步 loop 顺序与失败行为，避免两处维护重复长说明。

规则涵盖本单差异核对、真实 report、逐路径 Git 提交、同轮 agentCompletedAt/lastReport 核验、非 Git 与提交失败边界、例外授权范围。不自动 push 或 done，不代替 BUG-020 人工提交确认。用户已明确授权本单例外开发；使用 status in-progress 与 report 完成合法工具状态收尾，不修改 status.json。

本次为指令文档修复，不引入运行时库；原生 Node assert/临时 Git 仓库足以验证指令中的工具顺序，引入其他依赖成本更高。

## 验证方式
