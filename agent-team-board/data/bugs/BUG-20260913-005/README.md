# BUG-20260913-005 版本提示词与回答回填中的提示词复制，要增加批量任务类似的去 XX 会话的功能

- 状态以本条目 status.json 和看板为准。
- 归属：独立 Bug（引入来源见 design.md；被参照的既有设计为任务模块头部「去新建 XX 会话」入口——BUG-20260910-005 引入、REQ-20260911-008 升级为先复制后跳转；涉及功能由 REQ-20260913-001 建立）。
- 创建：2026-09-13T12:18:58.999Z。

## 现象

构建模块「版本计划」页签的「提示词与回答回填」弹窗（`scripts/web/build.js` `renderAnswerModal`，约 635–667 行；入口按钮 `#bldAnswerBtn`，约 629 行）为两段式：上段只读文本框展示版本提示词（`buildPrompt(v)`，约 84–94 行）+「复制提示词」按钮（`copyPrompt`，约 346–364 行），下段粘贴 Agent 回答解析回填。

复制成功后 toast 为「✓ 提示词已复制，去 Agent 粘贴执行后把回答粘贴到下方」（约 356 行）——话说到「去 Agent」为止，之后的一切都由用户自己完成：

1. **缺少会话入口**：弹窗内（乃至整个构建模块，`build.js` 全文无 `zcode://` / `codex://` 深链）没有任何打开 Zcode / Codex 会话的入口。用户复制后须自行切换应用、自行定位到当前项目、自行新建会话再粘贴。
2. **与批量任务同类场景体验不一致**：任务模块批量完善 / 批量开发面板头部早已有成熟设计——「去新建 Zcode 会话」「去新建 Codex 会话」文字链接（`scripts/web/app.js` `newSessionLinksHtml`，约 5949–5981 行），点击先自动复制当前面板最新提示词再请求打开深链（`copyPromptAndOpenSession`，约 6482–6519 行），并带完整的客户端探测与失败状态口径（`refreshWorkspaceApps`，约 5988–6004 行）。同为「复制提示词 → 去会话粘贴」场景，版本回填弹窗缺了后半段。

## 复现步骤

1. 启动 Status Board（`/board` 或 `node scripts/server.mjs`），打开一个 git 仓库项目，进入「构建」模块「版本计划」页签，选中一个版本（无版本可先「＋ 新建版本」从 done 条目创建），点详情底部「提示词与回答回填」打开回填弹窗。
2. 点上段「复制提示词」：toast 提示「✓ 提示词已复制，去 Agent 粘贴执行后把回答粘贴到下方」，随后流程中断——
3. 观察弹窗与整个构建模块：除「复制提示词」外没有任何「去 XX 会话」入口，也没有深链跳转；切到 Zcode / Codex、定位项目、新建会话全部靠用户手动完成。
4. 对照组：进入「任务」模块批量完善或批量开发面板，头部页签旁有「去新建 Zcode 会话」「去新建 Codex 会话」链接，点击即自动复制提示词并请求打开对应客户端——版本回填弹窗与之相比缺少同等入口。

## 期望行为

参照任务面板头部入口口径（BUG-20260910-005 / REQ-20260911-008），在版本回填弹窗上段补「去新建 XX 会话」入口：

1. **位置与形态**：弹窗上段提示词文本框旁（「复制提示词」附近）增加「去新建 Zcode 会话」「去新建 Codex 会话」入口，文案与任务面板一致（i18n.js 第 207–208 行已有对应英文词条，直接复用）；弹窗内横向空间有限，具体排布 design.md 定稿。
2. **点击行为与任务面板同口径——先复制后跳转**：
   - 自动复制的是**本弹窗当前版本提示词**（`buildPrompt(v)`，即文本框内容），不是批量调度提示词；复制完成后才触发深链；
   - 深链：`zcode://workspace/open?path=<项目路径>`（只打开工作区，会话需手动新建）或 `codex://threads/new?path=<项目路径>`（落在新会话输入框，不传 prompt、不自动发送）；项目取当前顶栏选中项目；不宣称自动新建会话 / 自动发送；
   - 复制成功 toast 说明「已复制提示词并请求打开…请在新建会话中粘贴发送（回答仍粘贴回本弹窗）」，具体文案 design.md 定稿。
3. **状态口径沿用任务面板探测状态机**（`state.workspaceApps` / GET `/api/workspace/apps` 只读存在性检查）：
   - 探测中 / 首帧未知：显示「正在检测」，不把未知当未检测到；
   - 探测失败（通道故障 ≠ 未安装）：说明 + 「重新检测」+ 手动打开指引，不砍功能入口；
   - 未检测到宿主 app：该端入口禁用 + 可见「（未检测到）」说明（留非默认路径余地）；
   - 未选择项目：两端禁用，title 说明先选择项目。
4. **失败不静默、深链照常打开**（与 `copyPromptAndOpenSession` 同策略）：复制失败有明确 toast 与「复制提示词」按钮的手动复制补救指引；深链打开不依赖复制成败；busy 防重复点击（在途点击直接忽略）。注：任务面板的「提示词获取失败」分支（服务端取提示词失败）在本弹窗理论不适用——版本提示词为前端本地生成，无额外请求。
5. **既有行为零回归**：「复制提示词」按钮保留（单复制场景仍需要）；「已复制 ✓」标记、下段粘贴 → 解析并预览 → 应用全流程、Esc / 点外部关闭、弹窗内其余布局均不变。
6. 弹窗打开期间探测未完成时入口区先显示检测态，探测结束自动刷出最终态，不阻断复制与回填（探测异步 fire-and-forget）。

边界（待确认）：

- 构建模块为独立前端模块（`window.ATBBuild`，自持 state），宿主探测结果目前在 `app.js` 的 `state.workspaceApps`——构建模块如何获取（复用 app.js 状态 / 共享缓存 / 自建同款状态机）由 design.md 定稿；
- 弹窗内两端链接 + 检测态的排布（同排 / 换行 / 收纳）待确认；
- 既有 toast「✓ 提示词已复制，去 Agent 粘贴执行后把回答粘贴到下方」当前在 `scripts/web/i18n.js` 无英文词条（英文界面不翻译），新增 / 调整文案时是否一并补齐待确认。

布局：模拟构建模块「版本计划」页签——顶部页签与工具条，左版本列表（卡片：名称 + 状态 chip + 元信息）+ 右版本详情（名称 / 描述、关联条目与 commit 行、底部「提示词与回答回填」「合并入 main」按钮）；回填弹窗为两段式：上段只读提示词文本框 +「复制提示词」+「去新建 Zcode / Codex 会话」入口区（修复后），下段回答粘贴框与解析预览，底部「关闭 / 解析并预览 / 应用」。演示顶部提供「演示控制台」：修复前 / 修复后对照开关、客户端探测状态切换（正常 / 检测中 / 检测失败 / 未检测到 Zcode / 未检测到 Codex / 未选项目）、深浅色主题与重置；下方「虚拟剪贴板 / 深链」提示行展示每次复制的内容与请求打开的深链。

交互：修复后模式弹窗上段有「去新建 Zcode 会话」「去新建 Codex 会话」——点击先自动复制本弹窗版本提示词（写入演示虚拟剪贴板），再模拟请求打开深链（展示 `zcode://workspace/open?path=…` / `codex://threads/new?path=…`，不真实导航、不唤起外部应用）并 toast；「复制提示词」单复制保留；下段粘贴示例回答 → 解析并预览 名称 / 描述 旧→新对照 → 应用后列表名称即时更新；Esc / 点遮罩关闭。修复前模式弹窗上段只有「复制提示词」，无任何会话入口，与修复后直观对照。

状态反馈：客户端探测状态覆盖正常 / 加载（「正在检测本机 Agent 客户端…」）/ 失败（说明 + 「重新检测」可恢复）/ 空（未检测到禁用 + 「（未检测到）」、未选项目禁用 + title）并可逐一切换；复制成功「已复制 ✓」+ toast、解析失败给出与真实实现一致的错误文案、应用成功 toast；深浅色适配。演示中的版本号、条目、commit、提示词均为示例数据，不代表真实条目；演示仅用于对照说明，不替代真实页面验收。

## 验收说明

- 修复后，版本回填弹窗上段可见「去新建 Zcode 会话」「去新建 Codex 会话」入口；点击后剪贴板内容为本弹窗当前版本的提示词（`buildPrompt(v)`），随后请求打开对应深链（zcode → `workspace/open`、codex → `threads/new`，均带当前项目路径），toast 说明已复制并已请求打开、需手动新建会话粘贴发送，不宣称自动新建 / 自动发送（可用演示页「虚拟剪贴板 / 深链」行核对复制内容与深链形态）。
- 状态口径与任务面板一致：探测中显示检测态；探测失败给说明 + 「重新检测」且入口不消失，重试可恢复；未检测到宿主 app 时对应入口禁用并带「（未检测到）」；未选项目时两端禁用并提示先选项目；探测不阻断「复制提示词」与回填流程。
- 失败不静默：复制失败有明确 toast 与手动复制补救指引；深链打开不依赖复制成败；连点有 busy 防抖，不重复触发复制 / 跳转。
- 回归：「复制提示词」按钮及其「已复制 ✓」反馈、toast、下段粘贴 → 解析并预览（含失败文案）→ 应用全流程、Esc / 点外部关闭均与现状一致；弹窗其余布局不破版——窄屏下入口换行可用，深浅色下样式正常；`scripts/web/i18n.js` 词条覆盖新入口文案（「去新建 XX 会话」已有词条可直接复用）。
- [演示](./ui-demo.html)可在浏览器直接打开，完成修复前 / 修复后对照与客户端探测五态（正常 / 检测中 / 检测失败 / 未检测到 / 未选项目）切换演示。
- 范围边界（待确认）：探测状态在构建模块的共享方式；入口在弹窗内的最终排布与 toast 具体文案；既有复制 toast 是否随本次一并补 i18n 词条。
