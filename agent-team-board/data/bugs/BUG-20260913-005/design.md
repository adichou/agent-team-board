# 设计 — BUG-20260913-005 版本提示词与回答回填中的提示词复制，要增加批量任务类似的去 XX 会话的功能

> 由 Agent 在 /dev 开发前补充，人可随时批注。

## 引入来源（源单）

- 引入来源：REQ-20260913-001（「提示词与回答回填」弹窗由该需求建立，建立时未包含「去新建 XX 会话」入口；编号已经 `atb list` 核验真实存在）。被参照的既有设计：任务模块头部「去新建 XX 会话」入口由 BUG-20260910-005 引入、REQ-20260911-008 升级为先复制后跳转。

## 根因分析

REQ-20260913-001 建立版本回填弹窗时只覆盖了「复制提示词 → 手动去 Agent 粘贴」的前半段，未把任务模块已有的「去新建 XX 会话」成熟入口（BUG-20260910-005 / REQ-20260911-008）一并带入，导致同类「复制提示词 → 去会话粘贴」场景体验不一致：复制后切应用、定位项目、新建会话全靠用户手动完成。

## 方案

> design.md 登记时未定稿，以下为实施时（BUG-20260913-005 修复）定稿口径；README 边界三问的取值在此落定。

- **开源选型（REQ-20260909-015）**：无合适开源库（浏览器深链 / 剪贴板 / 探测状态机均为项目内既有模式的小量胶水代码，引入依赖成本高于自研），自研实现。
- **探测状态共享方式**：构建模块自建同款状态机（`ATBBuild` 内部 `state.workspaceApps`，键名与语义与 `app.js` `state.workspaceApps` 一致：probing / loaded / failed / zcode / codex），模块级缓存，`enter()` 与弹窗打开时 fire-and-forget 探测 `GET /api/workspace/apps`，探测结束仅在弹窗打开时重渲染刷出最终态。不读 `app.js` 私有 state（未暴露全局接口，避免为此新增耦合）；build.js 先于 app.js 加载，也不能依赖其全局函数。
- **弹窗内排布**：`.bld-prompt-box` 内提示词文本框与「复制提示词」之下独立一行 `.bld-session-entry`（flex-wrap，窄屏自动换行），两个文字链接复用任务面板 `.ws-entry-link / .ws-entry-note` 样式与「去新建 XX 会话」文案；检测中 / 失败态说明用 `muted small` 文本，失败态附「重新检测」（`data-bld-ws-retry`）。
- **点击口径**：与任务面板 `copyPromptAndOpenSession` 同构——守卫（未选项目 / 未检测到 → toast 说明、不复制不导航）→ 复制本弹窗 `buildPrompt(v)` → 复制动作完成后才 `location.href` 深链（zcode `workspace/open`、codex `threads/new?path=`，不带 prompt）；失败不静默，深链打开不依赖复制成败；busy 防重复点击。复制用 build.js 本地 `copyText`（布尔返回），错误 toast 由调用方给完整指引（不借用 app.js `copyDispatchText` 的通用 toast，避免双重提示）。
- **toast 文案定稿**：成功「✓ 已复制提示词并请求打开 ◇（◇）：请在新建会话中粘贴发送；回答仍粘贴回本弹窗」；复制失败「复制失败：已请求打开 ◇（◇），请点弹窗内「复制提示词」手动复制后再粘贴；回答仍粘贴回本弹窗」（错误 toast）。版本提示词为前端本地生成，无「提示词获取失败」分支；版本缺失仅作防御路径。
- **i18n**：新增 / 调整文案全部入 `i18n.js`（EN / EN_DYNAMIC，◇ 插值、英文模板含 ASCII 锚点防自匹配）；既有复制 toast「✓ 提示词已复制…」「剪贴板不可用…」一并补齐词条（取「一并补齐」，消除英文界面残留中文）。
- **零回归**：「复制提示词」按钮、「已复制 ✓」标记与既有 toast 原样保留；`copyPrompt` 仅内部复用新 `copyText`，语义不变；下段粘贴 → 解析 → 应用、Esc / 点外部关闭、其余布局不变。

## 风险与边界

- 探测结束的重渲染若在用户输入回答时发生会丢草稿：刷新前先同步 `.bld-answer-input` 当前值回 `state.answer.text`（`syncAnswerDraft`），仅探测路径做此同步。
- `state.workspaceApps` 为模块级缓存且不随 `enter(project)` 重置（宿主安装是机器级事实，与项目无关）。
- 浏览器无法确认深链是否真的唤起客户端：只提示「已请求打开」，不宣称会话创建成功（与任务面板同口径）。
