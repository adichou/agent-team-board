## 根因分析

「正式发布」步的发布入口在两轮迭代中各自追加、互不复用：顶部操作条（`renderPublishActions`）与发布记录区（`renderReleasePane` 空态 / 列表分支）**各自渲染**同一 `relCreateBtnHtml`，且顶部「发布」按钮的启用条件要求先手动完成「创建并预检」（`ready = configured && run.precheck?.ok && …`，原因文案「请先创建并预检」）。结果是同一屏出现 2~3 个功能相同的创建入口 + 分散的原因 / 空态文案，发布主入口反而被前置步骤锁死——用户视角即「冗余堆叠、没有发布按钮」。

## 方案

**开源选型（REQ-20260909-015）**：自研（无引入库）。本次为既有构建模块前端交互收敛（模板收敛 + 既有 `/api/build-publish/*` 只读 / 动作接口编排），无第三方库可替代该业务语义；未引入任何依赖，不创建 licenses.md。

### 收敛形态（2026-09-28 讨论轮确认口径，与 ui-demo.html 期望态一致）

- **删除**：`relCreateBtnHtml`（全部三处入口：顶部操作条、空态区、记录列表底部）、旧创建弹层（`renderReleaseConfirm` / `openReleaseConfirm` / `doCreateRelease`）、「本版本发布」标题（随区域收敛移除，仅保留发布按钮行）。
- **新增唯一入口**：`renderPublishActions` 收敛为一行——唯一「发布」主按钮（`data-rel-publish`，加大加粗 `.bld-publish-btn`）+ 就近原因 + 未配置时「前往设置」（`goPublishSettings` 口径不变）。
- **禁用口径**：请先配置官网仓库 / 请先完成合并入 main / 发布中… / 已发布（链路执行中显示「启动中…」）；「请先创建并预检」「请重新预检并处理阻塞项」不再作为按钮前置原因，预检类提示保留在运行详情动作区。
- **一键发布链路（`openPublishConfirm` + `doOneClickPublish`）**：点击「发布」直接弹极简二次确认（仅「即将发布版本 vX.Y.Z。」；存量计划无 `version` 字段时改为在弹窗内补填发行版本号，校验沿用）。确认后链路自动执行：
  1. 目标运行：优先复用**同发行版本号**的可续跑运行（draft/failed/canceled），否则 POST `from-build` 创建新草稿；
  2. POST `precheck` 自动预检；未通过即中止（不 start），原因（首个阻塞项 label + detail）就近显示在发布条下方（`role=alert`）并 toast，不静默；
  3. POST `start` 携带预检指纹 token（服务端守卫与允许状态不变，二次确认即授权）；
  4. 成功后关闭弹窗、落点「正式发布」步并选中新运行，`refreshReleasePane()`（联动 `refresh()` 刷新版本卡「已发布」标签，BUG-20260917-001 口径）。
  - 取消 / busy 中遮罩与取消按钮不关闭不发请求；链路执行中重复确认不产生第二组请求（`rc.busy` + `rel.publishBusy` 双保险）；确认弹窗被关闭（取消 / 切项目）后链路即止不再补发。
- **已发布态从简**：存在成功运行时发布区只显示发布时间（`fmtTime`）+ 发布成功说明（标签更新 + BUG-20260920-005 锁定口径、不新增解锁路径），不再渲染记录列表 / 运行详情。
- **保留不动**：运行详情动作区（预检 / 重新冻结 / 预览发布计划（仍走完整计划确认弹窗）/ 重试失败阶段 / 取消后续阶段 / 刷新状态）按现有允许状态呈现；加载 / 读取失败（只读重试）/ 空态布局；版本与项目隔离、迟到响应丢弃（`seq` / 身份守卫）。
- **i18n（BUG-20260912-001）**：新增静态与插值词条同步 EN / EN_DYNAMIC；随旧弹层移除死词条（「✓ 已创建产品发布 ◇…」等）。

## 风险与边界

- 服务端链路、守卫与允许状态**零改动**（`build-publish-api.mjs` / `build-publish.mjs` 未动）；一键链路只是把原先手动的「创建 → 预检 → 预览计划确认 → start」编排为自动序列，start 仍须预检指纹 token。
- 不引入无确认自动发布：每次发布必经二次确认弹窗，取消不发出任何执行请求。
- 复用口径按「发行版本号一致」判定，版本号不一致（存量草稿为旧版本号）时新建草稿，避免把旧版本号发布出去；重复草稿堆积风险不高于原「创建并预检」多次点击。
- 存量计划无 `version` 字段时弹窗内补填（沿用旧创建弹层校验），不新增额外禁用原因。
- 发布中 / 已发布 / 未配置 / 未合并均禁用，不为凑入口绕过配置 / 合并门禁（守卫在按钮与 `openPublishConfirm` 双层）。
