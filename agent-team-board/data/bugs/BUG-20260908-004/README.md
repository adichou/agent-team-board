## 现象

Status Board 三处在单号旁渲染「REQ / BUG」类型徽章（chip）：需求列表行、详情抽屉头部、任务模块需求完善候选列表。单号本身已带 `REQ-` / `BUG-` 前缀（如 `REQ-20260908-004`），类型信息重复展示，白占首行横向空间。

## 复现步骤

1. 打开 Status Board 需求模块：列表每行单号前有「REQ/BUG」徽章；
2. 点击任意条目打开详情抽屉：头部单号旁同样有该徽章；
3. 任务模块 → 需求完善创建面板：候选列表每行单号前同样有该徽章。
   自动化复现：`node scripts/tests/type-chip-removed.test.mjs`（修复前 T1–T4 全红）。

## 期望行为

1. 三处均不再渲染 REQ/BUG 类型徽章，类型一律由单号前缀区分；
2. 单号完整展示（含前缀）与复制按钮、候选行跳转能力保持不变；
3. style.css 中失去引用的 `.chip.req` / `.chip.bug` 徽章配色一并清理。
