## 现象

1、例如只有中文语言集，就不需要在文首加上多语种切换的链接

## 复现步骤

1. 发布计划语言集仅保留 cn，启动 AI 总结。
2. 检查生成的提示词，仍要求每篇文档插入语言切换行。

## 期望行为

单语言总结不添加语言切换行，重写时清除旧切换行；校对不将缺失切换行视为问题。双语和更多语言继续仅按配置语言集互链。
