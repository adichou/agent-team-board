# 设计 — BUG-20260929-002

## 引入来源（源单）

BUG-20260928-009。已通过 atb show 核验，状态 done；该修复为总结和校对加入无条件切换行要求。

## 根因分析

docLangSwitchLine 单语言仍生成自链，总结与校对无条件要求该行，导致只有中文也出现多语言导航。

## 方案与实施

语言集归一化后只有一项时，切换行生成器返回空串；总结明确不添加切换行并移除既有旧切换行，同时去掉多语言翻译阶段说明及示例。校对同步免除切换行存在性要求，旧切换行只提示人工确认移除。多语言分支保留现有内容、顺序和文件名规则。

开源选型：在既有提示词生成器补条件即可，引入依赖成本高于自研，不新增依赖。

## 风险与边界

仅修复提示词，不直接修改发布文档；中文、英文、日文单语言均适用；自定义文档沿用相同规则。未修改界面文案，无新增 i18n 字符串。
