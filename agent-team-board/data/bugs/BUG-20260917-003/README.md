## 现象

现象：BUG-20260917-001 提交挂起确认时，「归属待确认」路径多达 358 个（发布产物、看板共享文件等）。面板对每个路径只提供独立的「计入本次补交 / 排除」下拉（app.js renderConfirmDoc，confirmAttrOf），无「全部计入 / 全部排除」批量操作；且存在未处理项时确认被拦截（app.js 提交前校验 + confirmPanelMsg 提示「每个路径须显式选择」），人工须逐项点 358 次才能确认。
