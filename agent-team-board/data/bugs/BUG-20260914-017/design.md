# 设计 — BUG-20260914-017 分支同步界面缺少 main 必须经过发布流程推送的规则说明

> 由 Agent 在 /dev 开发前补充，人可随时批注。

## 引入来源（源单）

本 Bug 由哪个需求 / Bug 引入？登记时可暂空或写「未定位」，修复阶段必须归因（三选一，禁止编造）：

- 引入来源：BUG-20260914-011（经 `atb list` 核验存在，状态 done）——「和远端同步」落定
  「fetch 后推送除 main 外的本地分支」范围时，main 排除规则只写入按钮 title 悬停提示与
  design.md 文档，未在界面提供常驻说明与结果反馈；BUG-20260914-012 去除 main 行推送按钮后
  缺口进一步显性化（main 行既不随同步推送、又无推送入口且无解释）。

## 根因分析

「和远端同步」排除 main 的规则是 BUG-20260914-011 在数据层（`build-git.mjs syncRemote()` 跳过
main 并返回 `skipped`）落定的，但展示层只做了一半：

1. 规则说明仅存在于 `#bldFetchBtn` 的 title 悬停提示（不悬停不可见），且该串未收录 i18n 词典，
   英文界面悬停仍是中文；
2. main 分支行（当前行 / 非当前行）无任何标识，用户无从得知 main 应经何种途径推送；
3. `doSync()` 的成功 / 部分失败 toast 不提 main 被跳过，`state.lastSync.skipped` 数据已存在但
   未在反馈中呈现，用户看不到 origin/main 时易误以为同步遗漏。

## 方案

仅展示层改动（`scripts/web/build.js` / `i18n.js` / `style.css`），不触碰数据层与服务端：

1. **常驻说明**：分支浏览工具栏下方常驻 `.bld-sync-note`（role=note）——「同步仅推送 main 以外
   的本地分支；main 必须通过发布流程推送。」；按钮 title 保留原口径（含「main 除外」，与常驻
   说明无矛盾）并补入 i18n 词典。
2. **main 行标识**：新增 `mainFlagHtml()`，本地 main 行（当前行与非当前行）渲染
   `.bld-main-flag` 徽标「通过发布流程推送」，title 详释「不随『和远端同步』推送，也无单独
   推送按钮」；徽标右对齐（与原推送按钮同位），行点击查看提交记录语义不变，不引入任何
   直接推送入口。
3. **同步结果反馈**：`doSync()` 按服务端 `skipped` 是否含 main 拼「；main 已跳过，请通过发布
   流程推送」注记（成功 / 部分失败 toast 均携带；本地无 main 不误报）；仅 main 场景 toast 为
   「✓ 已同步远端：fetch 完成，没有可推送的开发分支；main 必须通过发布流程推送」；
   `remoteSyncedEmptyHint()` 无可推分支空态同步为该口径。
4. **i18n**：上述静态串入 EN 词典（含按钮 title 补译），toast 拼接句入 EN_DYNAMIC（成功 /
   部分失败 × 有无 main 注记四种形态；长键优先匹配）；旧键「本次同步未推送任何分支：本地没有
   可自动推送的开发分支（main 由发布模块管理，不在此推送）。」随文案更新清理。
5. **样式**：`.bld-sync-note` / `.bld-main-flag` 均用现有 CSS 变量（--muted / --border），
   深浅色自适应；徽标虚线描边弱化为说明而非操作。

**开源选型（REQ-20260909-015）**：无合适库的原因——本单为纯展示层字符串 / 徽标 / CSS 微改，
不涉及任何可复用的第三方能力，引入库成本高于自研；未引入开源库，不创建 licenses.md。

## 风险与边界

- 不修改 `build-git.mjs syncRemote()` 排除 main 的行为与发布模块流程（S1 断言 + 既有 B1/B3
  测试守护）；不新增绕过发布流程推送 main 的入口。
- main 注记以服务端 `skipped` 数据为准，不前端硬编码「必有 main」：本地无 main 的仓库反馈
  维持原口径（U6 断言），避免误导。
- 既有断言同步更新：BUG-20260914-011 测试 U1/U3/U4/W1、BUG-20260914-006 测试 U2 空态句
  （README 验收 8 口径）；BUG-20260914-005 测试场景 skipped=[] 天然不受影响。
