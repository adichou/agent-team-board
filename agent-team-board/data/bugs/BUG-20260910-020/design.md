## 根因分析

`scripts/web/app.js` 5612 行（批量开发任务概况 pane）：

```js
${batchDone && !b.aborted ? `<div class="notice ok">${esc(data.notice || '本批范围已处理完毕')}</div>' : ''}
```

该表达式含 `${esc(...)}` 插值，必须以反引号模板字符串承载；行末闭合符被误写为**单引号 `'`**
（正确应为反引号 `` ` ``）。后果链：

1. 5612 行开启的模板字符串未在行末闭合，继续吞并后续源码至 5613 行 `` ${batchDone ? ` `` 的反引号
   才闭合，表达式/字符串边界连锁错位；
2. 整个 app.js 解析失败（`node --check` 于 5637 行报 `SyntaxError: Unexpected token ','`）；
3. 浏览器中 `<script src="/app.js">` 同样解析失败 → `boot()` 及全部交互逻辑不存在 → 页面只剩
   index.html 静态骨架（顶栏 / 模块导航为静态标记），所有模块视图不渲染、深链 `?view=` 不生效；
4. 服务端与数据层无恙（`/api/board`、`/api/marketing/state` 等实测正常），症状纯粹是前端入口失效。

单点验证：将 5612 行行末该单引号替换回反引号生成临时副本（/tmp，不改仓库文件）后
`node --check` 通过——**该字符为文件内唯一语法错误**。

用户「营销概览数据不出来」的观感另含叠加因素（与本 Bug 相互独立）：Electron 窗口 22:56 加载的
前端快照 + 当晚 style.css（23:12:58）/ index.html（23:13:12）持续被批次改写、窗口不热重载，
形成「旧版页面」；23:15 以最新磁盘代码（当时 app.js 未损坏）实测营销概览渲染完整
（阶段卡片 / 定位摘要 / 当前定价 / AI 入口 / 运行记录，截图留档于排查会话）。

## 方案

修复（一字符）：

- `scripts/web/app.js` 5612 行末 `</div>' : ''}` → `` </div>` : ''} ``；
- 修后 `node --check scripts/web/app.js` 必须通过，再按 test-cases / 验收标准回归
  （`layout.test.mjs`、`marketing-ui.test.mjs` 等加载 app.js 的 UI 测试会直接抓住此类错误）。

**实施注意（并发写冲突）**：RFB-20260910-023 批次仍在运行且持续改写 `scripts/web/*`（诊断期间
app.js mtime 两次变动）。实施本修复前先确认批次当前 run 已收尾或已暂停，避免修复被并发写入覆盖 /
覆盖他方更新；如批次自身先修复了同一错误（其 TDD 回归应能抓到），核验后按状态机走驳回或关闭流程。
