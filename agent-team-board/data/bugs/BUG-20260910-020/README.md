## 现象

用户入口症状：「营销」模块概览页签下数据不出来（Tab 行渲染、内容区整片空白）。
实际影响范围（2026-09-10 23:33 核实）远大于营销模块——**`scripts/web/app.js` 存在语法错误，
整个文件解析失败，`boot()` 不执行**，浏览器 / Electron 打开看板只剩 index.html 里的静态顶栏
（logo、模块导航、项目切换器均为静态标记），所有模块视图（需求 / 任务 / 文件 / 营销 / 设置）
全部不渲染、不可交互：

- `node --check scripts/web/app.js` 报 `SyntaxError: Unexpected token ','`（报错位置 5637 行；
  真实病灶在 **5612 行**——批量任务概况模板里嵌套模板字符串的闭合反引号被误写为单引号）；
- 实测打开 `http://127.0.0.1:8888/?project=…&view=marketing`：页面停留在默认态，DOM 里
  `#marketingView` 为空且带 `hidden` 类，所有 `section[id]` 均 hidden，模块页签高亮停在「需求」，
  需求列表同样不渲染（`boot()` 中 `setView()` 位于报错点之后未执行）；
- 数据层与服务端完全正常：`/api/board`、`/api/marketing/state` 等接口返回完整数据，
  `marketing.js` 自身语法检查通过（它独立加载，但入口调用链在 app.js 内）。

用户 23:18 截图时的空白营销页另有叠加因素：Electron 窗口 22:56 加载的是当时的前端快照，
当晚 style.css（23:12:58）/ index.html（23:13:12）仍在被批次迭代修改，窗口未重载持旧状态；
该路径与本案语法错误相互独立，语法错误修复 + 刷新后营销概览渲染已实测正常（见验收说明）。

## 复现步骤

1. 服务在跑（端口 8888）时，终端执行 `node --check scripts/web/app.js` → 输出
   `SyntaxError: Unexpected token ','`（app.js:5637）。
2. 浏览器打开任一已初始化项目的看板地址（如 `http://127.0.0.1:8888/?project=<项目根>&view=marketing`），
   或在已打开窗口按 Cmd-R 整页刷新。
3. 观察页面：只剩静态顶栏与搜索框骨架，下方内容区整体空白；深链 `view=marketing` 不生效，
   停在默认模块且列表为空。
4.（对照验证数据链路无恙）`curl -sf "http://127.0.0.1:8888/api/marketing/state?project=<项目根>"`
   返回 `initialized:true` 与完整 profile——空白不是数据问题。
