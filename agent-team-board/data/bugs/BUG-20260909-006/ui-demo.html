演示要点

  1. 现状：勾选已计划条目 → 列表头出现「进入批量开发」；点击后向 /api/dispatch/scope 推送隐性派发范围，之后每次勾选变化都会静默重推（见请求日志），未勾选的已计划单不会被自动派发。
  2. 现状：范围提示只出现在任务模块（「本批范围：勾选 N 项」），需求列表页无任何范围标记；「进入批量开发」tooltip 声称「未勾选时为全部候选」，但零勾选时整组按钮隐藏，该说明不可达（死文案）。
  3. 两种状态下，顶栏「任务」→「批量开发」的「已计划队列（最旧优先）」都自动涵盖全部已计划未认领单，运行中新置计划的条目自动进入队列——即列表勾选入口在能力上完全冗余。
  4. 期望（修复后）：已计划档批量操作组只保留「移出计划」，不再出现「进入批量开发」按钮，也没有任何 scope 推送请求；开发入口唯一收敛为任务模块。
  5. 「移出计划」在两种状态下均可用（确认 → 逐条流转回已接受 → 结果反馈；打开「模拟接口失败」可看单项失败分列与勾选保留）；全部移出后为空态，队列侧显示「（空，等待已计划条目）」。
  6. 任务模块切换瞬间为「加载中」骨架（模拟面板拉取），勾选执行 Agent 前「启动」保持禁用。
