# 设计 — BUG-20260921-013 文档编写界面的文件区域应该采用页签布局，每个语言是一个页签

> 由 Agent 在 /dev 开发前补充，人可随时批注。

## 引入来源（源单）

本 Bug 由哪个需求 / Bug 引入？登记时可暂空或写「未定位」，修复阶段必须归因（三选一，禁止编造）：

- 引入来源：REQ-20260921-008（已核验存在，in-progress）——文档编写页三段式布局把全部语言文件
  渲染进单个 `<ul class="bld-docs-list">` 平铺列表（`li.bld-doc-group` 分组标题行仅做视觉分隔）；
  REQ-20260921-010 语言集动态清单（4 类 × N）与 REQ-20260921-012 三阶段视图沿袭该形态，
  语言数增多后列表线性增长、跨语言对照与聚焦单语言不便，且与审查对话框的页签形态不一致。

## 根因分析

`scripts/web/build.js` 的 `renderDocsPane`：文件区域由 `groupHtml`（默认语言组 + 各剩余语言组）
把分组标题与全部文件行拼进**单个** `<ul class="bld-docs-list">`——布局本身只有「一列」这一种
呈现，语言维度没有独立的容器 / 切换机制；语言集动态化（REQ-20260921-010）后行数随语言数线性
增长，缺陷随之放大。

## 方案

**开源选型（REQ-20260909-015）**：自研——原生 HTML `role="tablist"/"tab"/"tabpanel"` 结构 +
复用本仓库既有 `.rel-tabs/.rel-tab` 页签样式（renderStepNav / renderReviewModal 同款），零新增
依赖。理由：仓库前端为零依赖静态页（仅 vendored marked），为单一页签行引入组件库的成本与
供应链面远高于十余行原生标记；且既有页签口径（class / role / aria / 事件绑定模式）可直接对齐。

1. **结构**：文件区域改为「表头（全局汇总，保留原样）→ 语言页签行 → 每语言一个面板」：
   - 页签行：`<nav class="rel-tabs bld-doc-lang-tabs" role="tablist" aria-label="文档语言页签">`，
     语言集内每个语言一个 `<button class="rel-tab" data-doc-lang role="tab" aria-selected>`，
     默认语言恒为第一个页签；
   - 面板：每语言一个 `<ul class="bld-docs-list" role="tabpanel" id/aria-labelledby 与页签互链>`，
     非激活面板 `hidden`。**全部语言面板均渲染**（仅隐藏不裁剪）：文件行七态 chip 与 AI 进度
     标注对所有语言保留在 DOM，切页签即时可见；门禁条 / 阶段条 / 表头汇总恒为语言集全局，
     不受页签切换影响。
2. **页签标签形态（本单定稿）**：`<缩写> · <显示名>`（标识，`data-i18n-skip` 豁免，BUG-20260921-004
   口径）+ 默认语言第一页签追加界面文案「（默认）」（独立文本节点可翻译）+ 该语言审核计数角标
   `x/4`（全审时绿色强调）。
3. **AI 运行中提示（本单定稿）**：AI 总结 / AI 翻译运行中的「当前文件」所在语言若不是激活页签，
   在该语言页签尾部显示 `◐` 运行角标（`st-run` + title「AI 总结/翻译进行中：当前文件在该语言
   页签」）；**不自动切换页签**（不打断浏览）。激活页签内的行内进度标注（`AI 总结 x/total` /
   `AI 翻译 x/total`）与列表上方的全局进行中说明保持不变。
4. **激活语言记忆（本单定稿）**：激活语言存 `pf.docLang`（随 pf 以 verId 归属）：点击页签切换并
   重渲染保持；语言集应用 / 刷新后若记忆语言仍在集合内则保留，不在集合内回落默认语言；切换版本 /
   项目（pf 重建）与重进页面回落默认语言页签。
5. **键盘可达**：与既有页签组件口径一致——原生 `<button>`（Tab 聚焦 + Enter / Space 触发 click），
   不引入 roving tabindex 等第二套键盘模式。
6. **i18n（BUG-20260912-001 基线）**：新增词条「（默认）」「文档语言页签」「AI 总结进行中：当前
   文件在该语言页签」「AI 翻译进行中：当前文件在该语言页签」中英同步；组头词条
   「默认语言（◇，文件不带后缀）」「剩余语言（◇ · AI 翻译）」随分组标题行删除一并清理。
7. **样式**：`scripts/web/style.css` 新增 `.bld-doc-lang-tabs` / `.bld-doc-tab-count`（复用
   `.rel-tabs` 的 `flex-wrap`，窄屏换行不横向溢出）；删除 `.bld-doc-group` 分组标题行样式。

**不改动**：文件行结构（`bld-doc-row` / 七态 chip / 行内进度）、表头汇总计数、阶段条、门禁条、
六按钮、语言集输入框、审查对话框、`normalizeFlowEval` 求值口径（纯展示层改版，无服务端改动）。

## 风险与边界

- 既有测试断言平铺形态的条款（req-20260921-012 的组头断言 / 组头词典键）随形态有意变更同步
  更新；「语言分组信息可见、七态 chip、全局汇总计数」等保留能力断言不动。
- 全部语言面板常驻 DOM（4×N 行，N 为语言数，通常 ≤5）：DOM 规模可忽略，换取切页签零延迟与
  测试 / DOM 断言稳定。
- `hidden` 属性控制显隐：`display` 由浏览器默认接管，无 JS 状态漂移；重渲染由既有全量 render
  机制完成，与审查对话框页签同模式。
