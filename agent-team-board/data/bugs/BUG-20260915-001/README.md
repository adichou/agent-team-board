# BUG-20260915-001 挂起确认面板首次打开因消息节点尚未创建而一直显示正在读取详情

- 状态：待测试（以 status.json 为准）
- 归属：独立 Bug（引入来源见 design.md）
- 创建：2026-09-14T16:20:26.131Z

## 现象

BUG-020 点击查看并确认，侧栏一直显示正在读取挂起详情。已定位 openConfirmPanel 在 loadConfirmDetail 前调用 confirmPanelMsg，但 confirmPanelMsg 节点只在 renderConfirmForm 后创建，首次打开取到 null 并抛错，详情请求未发出。GET 详情接口实测正常。修复需容忍消息节点尚不存在，并验证首次打开、请求失败重试及关闭后重开。

## 复现步骤

1. 刷新看板，确保尚未打开任何挂起确认面板。
2. 在 BUG-020 卡片点击「查看并确认」。
3. 观察侧栏持续显示加载文字，原代码抛出 null.textContent 错误。

## 期望行为

首次打开应正常请求并显示详情；请求失败应显示错误及重试入口。

## 验收说明

刷新页面后首次点击「查看并确认」即可加载详情；失败可重试，关闭重开正常。该修复不代替 BUG-020 的人工提交确认。
