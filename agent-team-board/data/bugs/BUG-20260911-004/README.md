# BUG-20260911-004 营销模块的概览页面还是有问题，需要 Cmd+R 才能看到数据

- 归属：独立 Bug
- 创建：2026-09-11T00:27:52.461Z
- 流程状态以系统维护的 status.json 为准。

## 现象

用户反馈：首次进入营销模块概览有数据；切换到其他页签再返回概览后看不见数据；按 Cmd+R 刷新后数据重新出现。影响概览的连续浏览，用户无法判断是数据丢失还是显示异常。尚未在实际浏览器中复现；受影响的具体字段、浏览器版本、发生频率及是否跨项目出现均为「待确认」。

## 复现步骤

1. 打开已建立营销档案且概览有已保存数据的项目，进入营销模块「概览」，记录阶段、阶段目标、主指标、定位摘要和当前定价的可见内容。
2. 路径一（模块内页签）：切换至「定位与定价」，不修改数据，再切回「概览」，观察原有数据是否消失或整个内容区空白；再分别经「渠道与行动」「效果与复盘」返回概览，各重复至少三轮。
3. 路径二（跨模块视图）：从营销模块切换到其他模块（如需求看板），不修改数据，再切回营销「概览」，重复至少三轮。
4. 用户反馈中的「其他页签」未说明指营销模块内四页签还是应用模块切换，两条路径均需验证，记录实际触发路径、浏览器版本与发生频率（「待确认」）。
5. 异常出现后按 Cmd+R，观察相同项目数据是否恢复；记录控制台与网络请求结果供开发阶段排查，接口错误和根因目前「待确认」。

## 期望行为

有已保存数据的项目，首次进入和从任意营销页签返回概览时均正常显示同一项目的数据，无须整页刷新。若返回时需要异步读取，应给出明确加载反馈；读取失败显示错误与重试入口，不能伪装成无数据。真正没有营销档案时才显示初始化引导；已建立档案但字段未填写时保留字段标签与「未填写」等现有占位。

切换页签只改变浏览位置，不清空已保存内容、不自动初始化、不提交修改。页面展示与最新一次成功读取的当前项目数据一致，不混入其他项目内容。缓存或请求策略留待开发阶段确定。

## 界面展示

[离线可交互演示](./ui-demo.html)（示例数据，不代表真实营销结果）。

- 布局：沿用营销模块四页签；概览上方保留阶段、阶段目标、主指标卡片，下方为定位摘要、当前定价和下一步内容。演示精简为主要信息块，不替代既有其他功能。
- 交互：两条触发路径均可操作——路径 A 点击营销页签往返，路径 B 经「离开营销（去需求看板）」再「返回营销 · 概览」；用「缺陷现象/期望修复」切换对比，缺陷模式下两条路径返回概览均空白，「模拟 Cmd+R」先显示读取中再恢复示例数据。该按钮不拦截浏览器快捷键。
- 状态反馈：演示可选正常、空、加载、失败；加载状态有完成入口，失败可重试，空状态有显式初始化入口，均为本地模拟。正常模式返回概览保持内容可见。

## 验收说明

- [ ] 已有营销档案的项目首次进入概览，显示与已保存记录一致的内容。
- [ ] 经其他三个营销页签分别往返至少三轮后，概览数据仍可见，不需要 Cmd+R。
- [ ] 从其他应用模块（如需求看板）切回营销概览，数据同样保持可见，不需要 Cmd+R。
- [ ] 返回前后项目身份及阶段、目标、指标、定位和当前定价一致；没有保存动作时持久化内容不改变。
- [ ] 读取过程中有加载提示，成功后自动呈现内容；失败有明确提示与可用的重试入口，重试成功后恢复概览。
- [ ] 无档案显示初始化引导，未填写字段保留占位，不把显示故障误判为空数据。
- [ ] 单文件演示无外网依赖，无构建步骤，浏览器直接打开可操作四页签、两条触发路径、模式对比及正常/空/加载/失败切换。

## 已核实依据与待确认

静态阅读源码已核实（仅阅读，未运行验证运行时缺陷）：

- `scripts/web/marketing.js`（四页签：概览 / 定位与定价 / 渠道与行动 / 效果与复盘）：
  - `overviewHtml()` 渲染概览：阶段 / 阶段目标 / 主指标三卡片 + 定位摘要 + 当前定价 + 下一步，数据取自 `/api/marketing/state` 最近成功响应的 `profile.positioning` 与当前定价版本；未填写字段显示「未填写」等占位。
  - 模块内页签切换 `setTab()` 仅切换页签按钮 active 与各 pane 的 hidden class，不清空数据、不重绘概览；仅「渠道与行动」「效果与复盘」首次进入会各自拉取看板 / 效果数据。
  - `enter(project)`：同一项目重入且已有数据时不重新拉取；项目变化才 `hardReset()`（清空 `state.data`、状态置 loading）并经 `refresh()` 重拉。
  - 读取状态机：loading → ready（已初始化）/ empty（未建立档案）/ error（读取失败），失败保留错误信息与重试路径。
- `scripts/web/app.js`：应用级视图切到 marketing 时调用 `ATBMarketing.enter(state.project)`；切换项目时调用 `ATBMarketing.reset()`（营销档案按项目隔离，重新拉取）。

排查线索与待确认：按上述静态逻辑，模块内 `setTab` 与同项目重入 `enter` 均不应清空概览数据，而用户仍反馈返回后空白——实际触发路径、渲染竞态或状态机漏洞未定位。受影响浏览器版本、发生频率、是否跨项目出现、引入来源、根因和修复技术方案均「待确认」，留待开发阶段排查；现有 design.md 不在本次完善范围。
