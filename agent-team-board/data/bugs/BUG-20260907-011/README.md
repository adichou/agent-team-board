# BUG-20260907-011 文件横幅目录列表会话级缓存：模块切换不重新拉取，外部新增文件不可见

- 状态：in-progress（已认领实施）
- 归属需求：无（独立 Bug）
- 创建：2026-09-07T09:00:50.916Z

## 现象
文件视图横幅 entriesByPath 按 /api/fs 结果缓存，ensureBanner 里 state.banner.initialized 置位后直接 return——切走再切回文件模块不会重新拉取。项目外部（Agent 会话、编辑器、构建）新增的文件/目录在看板文件模块不可见，必须整页刷新；而整页刷新当前会触发 BUG-20260907-002（需求列表空白），两个问题叠加。

## 复现（沙盒实测）
文件视图打开后向项目根写入 tiny.png → 切「需求」再切「文件」→ 横幅无 tiny.png；整页 reload 后出现。

## 建议
模块切回时对当前层栈做后台重拉（或提供手动刷新按钮/参与低频轮询）；注释明确写了「层栈浅、不参与 2 秒轮询」，但模块切换这种低成本时机也未利用。

## 影响
看板作为「Agent 写文件、人看文件」的窗口，文件视图数据陈旧且刷新代价高（联动空列表缺陷）。

## 复现步骤

1. 打开看板文件视图，横幅加载项目根层（及默认展开层）；
2. 在项目外部（终端/Agent 会话/编辑器）向已展开目录写入新文件（如 tiny.png）；
3. 切到「需求」模块再切回「文件」模块；
4. 期望新文件出现在横幅条带；实际横幅仍为旧缓存，仅整页 reload 后可见。

## 期望行为
模块切回文件视图时，对当前层栈逐层后台重新拉取 /api/fs 并更新 entriesByPath 后重建条带；外部新增文件无需整页刷新即可见。首次初始化路径（根层 + 默认展开）与既有交互不变；重拉不参与 2 秒轮询。
