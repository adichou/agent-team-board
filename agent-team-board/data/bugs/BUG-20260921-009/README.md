# BUG-20260921-009 命令模块的最近执行没有显示，请修复

- 状态：in-progress（已认领实施）
- 归属：独立 Bug（引入来源见 design.md）
- 创建：2026-09-21T04:59:32.800Z

## 现象

命令模块（REQ-20260920-004）的「最近执行」页签不显示内容：

1. 进入命令模块时默认页签即「最近执行」，但列表区域完全空白——既不显示已产生的最近执行条目，
   也不显示空态引导提示（应为「暂无最近执行：…」文案）。
2. 命令成功执行后条目短暂出现（执行收敛路径调用了 renderRecent），但切到「全部命令」再切回
   「最近执行」、或离开命令模块再进入后，条目消失，列表回到空白。

## 复现步骤

1. 打开看板进入「命令」模块（默认落在「最近执行」页签）→ 列表空白，无空态提示。
2. 切到「全部命令」任选一命令执行成功 → 「最近执行」出现该命令条目。
3. 切到「全部命令」再切回「最近执行」（或离开模块再进入）→ 条目消失、列表空白。

## 期望行为

- 每次进入命令模块，「最近执行」默认页签正确显示：无记录时显示空态引导提示；有记录时按命令
  去重展示最近 10 条（仅成功执行计入）。
- 切换页签往返、离开再进入模块（render 重建 DOM）后，最近执行条目保持显示（会话内留存口径不变）。

## 修复记录

- 根因：`scripts/web/commands.js` 的 `render()` 整体重建 `#commandsView` DOM（含「最近执行」列表
  容器），但只调用 renderList / renderDetail / renderOutput / renderHistory，漏调 `renderRecent()`；
  renderRecent 仅在点选命令（bindCmdPick）与执行收敛（withDone）时触发。
- 修复：`render()` 中补调 `renderRecent()`（一行）。
- 测试：`scripts/tests/bug-20260921-009.test.mjs`（vm 沙箱驱动真实 commands.js，T1 空态提示 /
  T2 页签往返保留 / T3 再进入保留 / T4 控制零回归），修复前 3 红 1 绿、修复后 4 绿。
