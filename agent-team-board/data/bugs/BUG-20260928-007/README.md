# BUG-20260928-007 发布文档 AI 总结 / 翻译 / 校对提示词的版本号仍用计划编号派生，未取计划 x.y.z 版本号

- 状态：submitted（待人工接受）
- 归属：独立 Bug（引入来源见 design.md）
- 创建：2026-09-28T05:26:28.286Z

## 现象

与 BUG-20260928-006（官网提示词版本号不对）同构：publish-flow.mjs 的 buildDocSummaryPrompt / buildDocTranslatePrompt / buildDocProofreadPrompt 均只收 planId 并在函数内以 versionNumberOf(planId) 派生 YYYYMMDD-NNN，server.mjs / atb.mjs 各调用点未传 v.version，提示词内「版本号」与计划 x.y.z（REQ-20260922-006 同源口径）不一致；存量计划（无 version 字段）不受影响。本单由 BUG-20260928-006 排查中发现登记，引入来源待修复时归因。

## 复现步骤

1. 创建版本计划，版本号留空自动分配或手填 x.y.z（如 `BLD-20260927-001` → `1.0.0`，
   REQ-20260922-006 创建时分配），推进到发布模块「文档编写」页；
2. 点击「① AI 总结」：提示词已复制到剪贴板，页面下方展开「AI 总结提示词」预览折叠盒
   （readonly 文本框），其中「发布计划号：`BLD-20260927-001`（版本号 `20260927-001`）」
   一行为计划编号派生的 `YYYYMMDD-NNN`，而同屏发布列表卡片 / 详情头部的版本号优先取
   `version` 字段显示 `1.0.0`（web/build.js 两处显示逻辑）——同屏两套版本号口径不一致；
3. 默认语言文档全部人工审核后点击「④ AI 翻译」：提示词首行「负责『BLD-…』（版本号
   `20260927-001`）的翻译派发」与「发布计划号」行同为派生值；
4. 点击「③ AI 校对」：复制到剪贴板的校对提示词「发布计划号」行同为派生值（校对提示词
   不落页面预览，仅复制 + toast 回执）；
5. CLI 口径同样复现：`node scripts/atb.mjs summary start --id BLD-20260927-001`
   （`translate start` / `docscheck start` 同）打印的提示词版本号同为派生值；
6. 存量计划（version.json 无 `version` 字段）不受影响：派生值即回退口径，界面与提示词一致。

## 期望行为

- 三个发布文档提示词（AI 总结 / AI 翻译 / AI 校对）中的版本号与计划 x.y.z 版本号同源
  （REQ-20260922-006 验收口径「发布文档 AI 总结 / 翻译 / 官网提示词中的版本号同源」；
  校对提示词为 REQ-20260924-001 后引入的同构问题，随本单一并同口径）：新计划显示 x.y.z，
  与同屏列表 / 详情头部一致；
- 存量计划（无 `version` 字段）沿用计划编号派生 `YYYYMMDD-NNN` 回退口径（旧数据不迁移、
  不报错）；
- 修复形态与 BUG-20260928-006 已修的 `buildSiteWritingPrompt` 同构：三个提示词函数新增
  `version` 参数并优先取用（`version || versionNumberOf(planId) || planId`），
  `server.mjs` / `atb.mjs` 各三个调用点传 `v.version`；
- 提示词内完整计划号 `BLD-…` 保留（进度回执与提交消息匹配依据不变），提示词其余内容
  （角色说明、文档清单、翻译 / 校对约束等）不变。

## 验收说明

- 单测（`scripts/tests/bug-20260928-007.test.mjs`，TDD 先红后绿）：
  - 三个提示词函数传入 `version` 时，提示词内版本号（首行与「发布计划号」行）为 x.y.z；
  - 未传 `version` / 存量计划（无 `version` 字段）时回退 `YYYYMMDD-NNN` 派生口径，与既有
    提示词形态兼容（调用点未传参不破坏既有测试与缓存口径——运行参数区形态仅值变化）；
  - 完整计划号 `BLD-…` 仍原样出现在提示词中。
- 调用点核验：`scripts/server.mjs` 三处（docs-summary / docs-translate / docs-proofread
  start）与 `scripts/atb.mjs` 三处（summary / translate / docscheck start）均传 `v.version`，
  与 `server.mjs` 官网提示词调用点（已传 `version: v.version || null`）同构。
- UI 核验：文档编写页点「① AI 总结」/「④ AI 翻译」展开的提示词预览与「③ AI 校对」复制的

- 回归：REQ-20260922-006 验收项「提示词中的版本号同源」自此补全（含校对提示词）；
  `npm test` 全量通过。
