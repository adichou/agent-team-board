# BUG-20260921-008 main 分支的提交历史只显示 main 分支的，不要和 dev 分支的合并显示

- 状态：submitted（待人工接受）
- 归属：独立 Bug（引入来源见 design.md）
- 创建：2026-09-21T04:19:29.532Z

## 现象

看板 Web 界面「发布」模块 →「分支浏览」页签，左侧选中 main（本地与 dev 两支并存）后，右侧
提交记录为「并集视图」——同时显示 main 与 dev 的提交（含 dev 尚未合并入 main 的开发提交），
并附「并集视图：同时显示 main 与 dev 的提交（含未合并提交）」提示、双分支头标签与
Merge-base 汇聚标注（BUG-20260920-002 引入的口径）。

## 复现步骤

1. 启动看板 Web 界面，顶部导航进入「发布」模块，切到「分支浏览」页签。
2. 左侧「本地」分组点击 main：右侧显示并集视图（dev 独有提交混入 main 提交历史）。

## 期望行为

选中 main 只显示 main 分支可达的提交（等价 `git log main`），不与 dev 分支的提交合并显示；
已通过合并提交并入 main 的 dev 提交仍正常出现（其属 main 可达历史）。dev 及其余分支维持
各自单支口径（BUG-20260921-006）。
