# BUG-20260922-006 创建版本的版本号和版本计划名称输入框要移到上方，便于输入

- 状态：submitted（待人工接受）
- 归属：独立 Bug（引入来源见 design.md）
- 创建：2026-09-22T14:19:11.019Z

## 现象

构建页「＋ 新建版本」打开的创建面板（`scripts/web/build.js` 的 `renderPanel`）中，
「版本名称」「版本号」两个输入框渲染在候选条目清单（全选 / 全不选 + 条目复选列表）之后，
即面板 body 的最底部。done 条目较多时清单很长，输入框被挤到折叠线以下，
用户每次都要先滚过整个清单才能看到 / 填写版本号与名称。

## 复现步骤

1. 构建页点「＋ 新建版本」打开创建面板；
2. 项目内已完成（done）条目较多（例如 10+ 条）时，面板内候选清单占满可视区；
3. 「版本名称」「版本号」输入框位于清单下方，需要滚动才能到达。

## 期望行为

创建版本面板中「版本名称」「版本号」两个输入框上移到面板 body 顶部（候选清单之前），
打开面板即可见、可直接输入；候选清单、全选 / 全不选与提交按钮位置与行为保持不变，
「添加条目」面板（addPanel 共用同一渲染函数）不出现这两个输入框的口径保持不变。
