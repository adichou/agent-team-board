# 测试用例 — BUG-20260912-004 操作提示出现多个已

实现于 `scripts/tests/bug-toast-i18n-selfmatch-20260912-004.test.mjs`（node:assert/strict，随 npm test 聚合执行）。

## B1 词典防线（结构不变量）

动态词条（EN_DYNAMIC）英文模板必须含 ASCII 字母锚点；无锚点的反向模式无法区分「英文渲染文本」与「中文原文」，必然自匹配叠字。此用例防止泛化词条 `'✓ ◇ 已◇'` 回归。

## B2 核心缺陷回归（对应验收 1）

zh 模式对「✓ BUG-20260912-003 已确认完成」连调 `t()` 12 次（模拟每 2 秒轮询整页重翻），结果恒等于原文，不叠「已」。修复前：每调一次多一个「已」。

## B3 zh 幂等（对应验收 1/2）

下列文案在 zh 模式反复 `t()` 均幂等不变形：

- `✓ REQ-… 已接受` / `已移出计划` / `已移入计划` / `已驳回完成（退回开发）` / `已驳回接受（退回待接受）` / `✓ REQ-1 标题与描述已更新`
- 曾受害形态：`✓ 已初始化并切换到 <项目>（<路径>）`、`✓ 已复制完整提交号 abc12…`（修复前同样被泛化反向模式补「已」）

## B4 中英往返（对应验收 3）

- en：`✓ … 已确认完成` → `✓ … confirmed done`；`已接受` → `accepted`；`已驳回完成（退回开发）` → `rejected completion (back to development)`；`已驳回接受（退回待接受）` → `rejected acceptance (back to pending)`
- zh 回译逐一还原原文，往返一致。

## B5 DOM 幂等（对应验收 1）

同一文本节点在 zh 模式反复 `translateTree`（模拟轮询重渲染），节点值恒定不变。

## B6 回归（对应验收 4/5）

- `↩ 已撤销 …，状态已回退`、`进展记录读取失败：…` 行为不变；
- en 动态翻译正常（`已选 5 项` → `5 selected`）、未命中保持原文（降级策略不变）；
- app.js 零改动（i18n-wiring 既有约束继续成立）。
