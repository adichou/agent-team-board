Agent Team Board智能体团队看板 v1.0.0 English

产品介绍

Agent Team Board（智能体团队看板）是一个 ZCode 插件：把需求与 Bug 做成 文件化管理，配合 Agent TDD 开发流程与本地网页状态板， 让人与智能体在同一份事实源上协作开发。

Project Board需求 / Bug 条目与验收标准
Discussion Board设计与澄清的讨论留痕
Status Board本地网页实时看板

核心能力

文件化事实源

看板数据全部落在 docs/agent-team-board 目录，随 git 一起提交、评审与回溯。

单向状态机人机分工

状态只能沿单向流转；「接受条目」「确认完成」仅人工可操作，PreToolUse 钩子拦截越权写入。

认领即实施的 TDD 两阶段流程

Agent 认领条目即开始实施：先补用例「测试跑红」，再实现「跑绿」，最后 report 等待测试与人工确认。

批量开发 / 批量完善

把队列里的条目批量派发给子代理逐项实施，互斥锁保证同一时间只有一个实施任务。

构建 → 版本计划 → 发布流水线

从构建产物到版本计划再到发布执行与回验，一条流水线走完本地发布闭环。

待人工决策（hold）闭环

智能体遇到分歧可把条目置为 hold 并说明原因，人工决策后继续流转，全程留痕。

快速启动 · Status Board 服务

  1. 初始化看板（在目标项目根执行）：
    node <插件>/scripts/atb.mjs init
  2. 启动本地状态板服务，然后浏览器打开 http://127.0.0.1:8888：
    node <插件>/scripts/server.mjs

  3. 可选：安装终端命令，之后可直接用 atb：
    node <插件>/scripts/atb.mjs cli install

Electron 桌面 App

在仓库根安装依赖后即可运行桌面版；打包分发支持 mac dmg 与 win nsis。

npm install npm run app

打包分发：

npm run dist

English Summary

What. Agent Team Board is a ZCode plugin that manages requirements and bugs as versioned files, drives an agent TDD workflow, and renders a local web status board with three pillars: Project Board, Discussion Board, and Status Board.

Capabilities. File-based single source of truth (committed with git); a one-way state machine where accepting items and confirming completion are human-only actions (enforced by PreToolUse hooks); claim-and-implement TDD (tests red, then green, then report); batch development and batch refinement; a build → version plan → release pipeline; and a hold loop that defers disputed decisions to humans.

Run. Initialize with node <plugin>/scripts/atb.mjs init, serve the status board via node <plugin>/scripts/server.mjs and open http://127.0.0.1:8888. For the desktop app, run npm install then npm run app; package with npm run dist (mac dmg / win nsis).
